# meeting-minutes

회의 기록을 받아 실행 가능한 회의록으로 바꾼다. 전사·요약은 이미 도구(클로바노트·Zoom·Teams)가 처리하므로, 이 스킬은 그 결과물을 받아 결정사항과 액션아이템을 뽑아내는 하류 작업에 집중한다.

## 입력

- 회의 메모 (불완전한 키워드·약어 허용)
- 녹취·자동 전사 텍스트
- 회의 안건·참석자 정보 (있으면)

입력이 없거나 불충분하면 회의 일시·참석자·핵심 안건을 1개 질문으로 먼저 확인한다.

## 워크플로우 (4단계)

1. 입력 정리 — 발언을 안건 단위로 묶고 잡담·중복을 제거한다
2. 결정·액션 분리 — 확정된 것(결정사항)과 해야 할 것(액션아이템)과 보류된 것(논의 메모)을 분류한다
3. 액션아이템 구조화 — 항목마다 담당자·기한을 매칭한다. 회의에서 언급되지 않았으면 "미정"으로 표기하고 임의 생성하지 않는다
4. 출력·검증 — 4블록 포맷으로 출력하고 완성 조건을 점검한다

## 출력 포맷 (4블록 고정)

```
# {YYYY-MM-DD} {회의명} 회의록

## 1. 회의 개요
- 일시:
- 참석:
- 안건:

## 2. 결정사항
- (확정된 것만. 미결 항목은 제외)

## 3. 액션아이템
| 담당 | 할 일 | 기한 |
|---|---|---|
| | | |

## 4. 논의 메모
- (결정되지 않은 쟁점·보류 항목)
```

## 규칙

- 결정사항과 논의 메모를 섞지 않는다. 확정만 2번 블록, 미결은 4번 블록
- 액션아이템 담당·기한은 회의 내용 근거로만 채운다. 근거 없으면 "미정"
- 입력에 없는 내용을 추론으로 채우지 않는다 (근거·불확실성 처리 원칙)
- 종결어미 ~합니다체, 축약형 금지

## 완성 조건 (자가 점검)

- 결정사항에 미결 항목이 섞이지 않았는가
- 액션아이템에 담당·기한 열이 모두 채워졌는가 (없으면 "미정" 표기)
- 입력에 없는 내용을 임의 생성하지 않았는가
- 금지어 위반 0건

## 저장

- 단독 회의: `_Inbox/` 또는 해당 프로젝트 폴더
- 강의·컨설팅 미팅: 해당 강의·컨설팅 폴더 하위
- 최종본은 .md, 요청 시 .docx 변환
