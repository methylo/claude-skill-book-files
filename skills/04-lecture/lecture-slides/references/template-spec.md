## Quick Reference

Phase 4 시작 시 아래 값만 먼저 확인한다. 상세 좌표는 해당 유형 작업 시 참조.

```javascript
// 슬라이드 크기 (표준 16:9)
pres.defineLayout({ name: "LECTURE", width: 13.333, height: 7.5 });

// 폰트 설정 (fallback 포함)
const FONTS = {
  main: "G마켓 산스 Bold",        // 제목·강조
  body: "G마켓 산스 Light",       // 본문
  fallback: "Noto Sans KR"        // 폰트 누락 시 자동 대체
};

// 색상 팔레트
const COLORS = {
  primary: "1E3A8A",      // 네이비 (표지·강조 박스·번호 배지)
  accent: "F59E0B",       // 앰버 (포인트·구분선·하이라이트)
  textDark: "1F2937",     // 차콜 (본문 텍스트)
  textMuted: "888888",    // 회색 (캡션·부제)
  bgLight: "F9FAFB",      // 매우 옅은 그레이 (카드 배경)
  border: "E5E7EB",       // 옅은 그레이 (구분선·박스 외곽)
  white: "FFFFFF",        // 본문 배경·반전 텍스트
};

// 폰트 크기 체계
// 표지 메인: 72pt | 본문 제목: 32pt | 섹션 헤더: 22pt
// 부제: 16pt | 본문 카드: 13pt | 캡션: 11pt
```

## 3. 타이포그래피

### 폰트 패밀리

| 용도 | 폰트명 | Fallback |
|------|--------|----------|
| 제목·강조 | G마켓 산스 Bold | Noto Sans KR Bold |
| 본문 | G마켓 산스 Light | Noto Sans KR Regular |

> pptxgenjs에서 폰트는 `fontFace` 옵션으로 지정. PowerPoint 측에 폰트가 없으면 자동으로 시스템 한글 폰트로 대체된다. 외부 발표 시 폰트 깨짐 방지를 위해 .pptx 저장 시 폰트 임베드 권장.

### 폰트 크기 체계 (pt 단위)

| 용도 | 크기 | 적용 위치 |
|------|------|----------|
| 표지 메인 제목 | 72pt | 슬라이드 1 메인 제목 |
| 본문 슬라이드 제목 | 32pt | 일반 슬라이드 제목 |
| 본문 큰 제목 | 38pt | 섹션 첫 슬라이드·강조 슬라이드 |
| 섹션 헤더·강조 | 22pt | 카드 헤더·번호 박스 옆 텍스트 |
| 부제·서브 카피 | 16~17pt | 제목 아래 부제·카드 본문 |
| 본문 카드 텍스트 | 13pt | 카드 내부 상세 설명 |
| 캡션·메타 | 11pt | 상단 라벨·페이지 번호·카드 라벨 |

### 정렬 원칙

- **표지·섹션 디바이더**: 좌측 정렬 (좌측 0.65" 여백 기준)
- **본문 제목**: 좌측 정렬
- **카드 내부**: 좌측 정렬
- **페이지 번호**: 우측 하단

## 5. pptxgenjs 구현 시 참고

> pptx 스킬(`/mnt/skills/public/pptx/pptxgenjs.md`)은 pptxgenjs를 사용한다.
> 모든 좌표는 **인치(inches)** 단위.

### 슬라이드 크기 설정

```javascript
const pptxgen = require("pptxgenjs");
let pres = new pptxgen();
pres.defineLayout({ name: "LECTURE", width: 13.333, height: 7.5 });
pres.layout = "LECTURE";
```

### 표지 슬라이드 (Cover)

```javascript
let slide = pres.addSlide();

// 네이비 풀배경
```

### 본문 라이트 슬라이드 (3분할 카드)

```javascript
let slide = pres.addSlide();
slide.background = { color: "FFFFFF" };

// 상단 메타 라벨
slide.addText("AI 트렌드 · 시야  |  T-2", {
  x: 0.65, y: 0.14, w: 12.03, h: 0.22,
  fontSize: 16, color: "1F2937", fontFace: "G마켓 산스 Light",
});

// 제목
slide.addText("AI는 도구가 아니라 동료가 되었다", {
  x: 0.65, y: 0.90, w: 12.03, h: 0.44,
  fontSize: 32, color: "1F2937", bold: true, fontFace: "G마켓 산스 Bold",
});

// 앰버 구분선
slide.addShape(pres.shapes.RECTANGLE, {
  x: 0.65, y: 1.55, w: 1.20, h: 0.05,
  fill: { color: "F59E0B" }, line: { color: "F59E0B" },
});

// 부제
slide.addText("지시 · 실행 · 검수의 3단 협업 구조 정착", {
  x: 0.65, y: 1.79, w: 12.03, h: 0.22,
  fontSize: 16, color: "888888", fontFace: "G마켓 산스 Light",
});

// 카드 3개 자동 배치 (x = 0.65, 4.76, 8.52)
const CARD_X = [0.65, 4.76, 8.52];
const CARDS = [
  { num: "1", header: "BEFORE", body: "도구로서의 AI\n사람 → 질문 → AI\n한 번에 끝나는 거래" },
  { num: "2", header: "AFTER (226)", body: "동료로서의 AI\n사람 ↔ AI 에이전트\n지시·실행·검수의 협업" },
  { num: "3", header: "지금 변화", body: "내 파일·웹·도구 직접 접근\n사용자 = 방향 설정 + 검수자" },
];

CARDS.forEach((card, i) => {
  const x = CARD_X[i];
  // 카드 상단 바
  slide.addShape(pres.shapes.RECTANGLE, {
    x: x, y: 2.49, w: 3.81, h: 0.14,
    fill: { color: "1E3A8A" }, line: { color: "1E3A8A" },
  });
  // 카드 배경
  slide.addShape(pres.shapes.RECTANGLE, {
    x: x, y: 2.55, w: 3.81, h: 3.70,
    fill: { color: "F9FAFB" }, line: { color: "E5E7EB" },
  });
  // 번호 배지
  slide.addShape(pres.shapes.RECTANGLE, {
    x: x + 0.35, y: 2.90, w: 0.75, h: 0.75,
    fill: { color: "1E3A8A" }, line: { color: "1E3A8A" },
  });
  slide.addText(card.num, {
```

## 6. 슬라이드 순서 패턴

NMC 양식에서 관찰된 슬라이드 순서:

```
1. 표지 (Cover) — 네이비 풀배경 + 4개 모듈 카드
2. 강사 소개 — 본문 라이트 변형
3. 강의 개요 (Agenda) — 본문 라이트 3분할
4. 섹션 디바이더 (Part 1) — 네이비 풀배경
5~N. 본문 슬라이드 (라이트/다크 교차)
M. 섹션 디바이더 (Part 2) — 네이비 풀배경
...
Last. 마무리 — 네이비 풀배경
```

- 표지·섹션 디바이더·마무리는 모두 **네이비 풀배경 (#1E3A8A)**
- 본문은 **라이트(흰색)**가 기본, 강조 슬라이드에서 **다크(네이비)** 교차
- 상단 메타 라벨로 진행 단계 표시 (예: "AI 트렌드 · 시야 | T-2")

## 7. 색상 커스터마이징

기본 팔레트(섹션 2)는 NMC(의료·공공) 양식이다. 강의 주제에 따라 강조색을 변경할 수 있다.

### 주제별 추천 색상

| 강의 주제 | 주조색 (네이비 대체) | 강조색 (앰버 대체) | 배경 유지 |
|----------|---------|----------|---------|
| 의료·공공 (기본) | `1E3A8A` (네이비) | `F59E0B` (앰버) | 흰색 |
| IT·개발 | `0F172A` (다크 네이비) | `3B82F6` (블루) | 흰색 |
| 마케팅·콘텐츠 | `4C1D95` (퍼플 다크) | `A855F7` (퍼플) | 흰색 |
| 교육·학술 | `065F46` (포레스트) | `10B981` (에메랄드) | 흰색 |
| 금융·경영 | `1E40AF` (네이비) | `EAB308` (옐로) | 흰색 |
| 건설·산업 | `7C2D12` (브라운) | `F97316` (오렌지) | 흰색 |

### 색상 변경 규칙

1. **주조색·강조색 2가지만 변경** — 표지 배경, 섹션 디바이더, 카드 헤더, 강조 라인에 일괄 적용
2. **배경은 흰색 유지** — 본문 라이트 슬라이드의 배경은 변경하지 않음
3. **카드 배경은 옅은 회색 유지** — `#F9FAFB`
4. **본문 텍스트는 차콜 유지** — `#1F2937`
5. 사용자가 색상을 직접 지정하면 그 값을 우선 적용

## 8. Speaker Notes (발표 노트) 삽입

pptxgenjs에서 슬라이드별 발표 노트를 삽입한다.

### 코드

```javascript
slide.addNotes("발표 노트 텍스트 내용");
```

### 발표 노트 작성 규칙

각 슬라이드의 노트에 다음 3가지를 포함:

1. **무엇을 말할지** — 이 슬라이드에서 전달할 핵심 메시지 (100~200자)
2. **전환 멘트** — 다음 슬라이드로 넘어갈 때 사용할 문장 ("[전환 멘트]" 접두)
3. **예상 질문** — 수강생이 할 수 있는 질문과 답변 ("[예상 질문]" 접두, 선택)

### 예시

```javascript
slide.addNotes(
  "AI가 도구에서 동료로 진화한 핵심 변화를 설명합니다.\n\n" +
  "[전환 멘트] \"이 변화가 우리 업무에 어떤 의미인지, 다음 슬라이드에서 살펴보겠습니다.\"\n\n" +
  "[예상 질문] \"동료 수준이라는 게 구체적으로 무엇인가요?\" → 검수·전문 판단은 사람이, 반복 실행은 AI가."
);
```

### 슬라이드 유형별 노트 분량

| 유형 | 노트 분량 | 포함 요소 |
|------|----------|----------|
| 표지 | 50~100자 | 인사, 강의 소개 |
| 섹션 디바이더 | 50~100자 | 이 모듈에서 다룰 내용 예고 |
| 본문 라이트 | 150~300자 | 핵심 설명 + 전환 멘트 |
| 본문 다크 (강조) | 150~300자 | 핵심 설명 + 강조 포인트 |
| 본문 비교 | 200~300자 | 비교 의도 설명 + 결론 |
| 마무리 | 100~150자 | 핵심 정리 + Q&A 안내 |

## 9. 폰트 임베드 권장 (외부 발표 대비)

G마켓 산스는 무료 폰트지만 외부 강의장 PC에 미설치 가능성이 있다. .pptx 저장 후 다음 절차로 폰트 임베드.

### PowerPoint
1. 파일 → 옵션 → 저장
2. "파일에 글꼴 포함" 체크
3. "프레젠테이션에 사용된 문자만 포함" 선택 (파일 크기 절약)
4. 저장

### pptxgenjs 자동 처리
pptxgenjs는 폰트 임베드를 직접 지원하지 않는다. 생성 후 PowerPoint에서 한 번 열어 위 절차로 저장하는 단계가 필요하다.

### Fallback 폰트 코드 설정
폰트 누락 시 Noto Sans KR로 자동 대체되도록 코드에 반영한다. pptxgenjs는 단일 폰트만 받으므로, G마켓 산스 미설치 환경에서는 PowerPoint의 폰트 대체 메커니즘에 의존한다.
