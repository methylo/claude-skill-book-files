# lecture-research v3.1

강의 기획안을 입력받아 꼭지별로 타깃에 적합한 강의 재료를 12개 슬롯으로 정리하는 스킬. 파이프라인 2단계.

## 참조 파일

| 파일 | 내용 | 읽는 시점 |
|---|---|---|
| `templates/research-template.md` | RL 노트 양식 | 노트 생성 시 |
| `references/slot-writing-guide.md` | 슬롯 작성 패턴과 예시 | 슬롯 채우기 |
| `references/flow-sequence-guide.md` | 슬롯 12(꼭지 내부 흐름) 작성 가이드 | 슬롯 12 작성 |
| `references/visual-source-guide.md` | 슬롯 10(시각 소재) 수집 가이드 | 슬롯 10 작성 |
| `references/meta-fields-guide.md` | visualizable_as·expires_at 메타 필드 | 자료 메타 기록 |

## 파이프라인 위치

```
lecture-plan [관문 1] → lecture-research [관문 2] → lecture-blueprint [관문 BP] → lecture-slides [관문 3] → lecture-review
```

## 입력

### 필수
- **강의 기획안**: lecture-plan v2 산출물(LP_*.md) 또는 직접 작성
  - `gate_1_passed: true` 플래그 있으면 Phase 1.5 생략

### 선택
- 추가 키워드, 기존 RL_ 노트(보강), 리서치 깊이(기본 3~5 / 딥 5~10)
- 본인 사례 메모 (강의자가 직접 운영·관찰한 사례 노트)
- 기존 LI_*.md (강조 구간·반대 강의 정보 활용)

## 프로세스

### Phase 1. 기획안 확인

- 강의 제목·대상·시간·목차·학습 목표 추출
- **lecture-plan v2 YAML에서 gate_1_passed, target_profile 로드**
- **강의 의도 노트(LI_*.md)가 있으면 promise·peak_zones·anti_lecture·pattern 로드** (선택)
  - pattern (P-ACC/P-CYC/P-CON/P-DEM)은 슬롯 12 흐름 설계의 입력으로 사용
- gate_1_passed가 true면 Phase 1.5 건너뛰고 Phase 2로

### Phase 1.5. 타깃 프로파일 추출 (lecture-plan v2 미사용 시)

- 직무/업종, 사전지식, 관심 맥락, 이탈 요인, 반응 요인 5항목
- 확인 불가 시 "일반 직장인" 기본값 + 노트 명시

### Phase 2. 꼭지별 리서치 질문 생성

- 꼭지당 5~7개 (v3.0 대비 증가, 시각 소재 검색 추가), **타깃 프로파일 변수 강제 주입**
- 6종 카테고리: 개념 / 데이터 / 사례 / 비교 / 반박 / **시각 소재 (신규)**
- LI 있으면 anti_lecture 항목을 반박 질문으로 자동 변환

### Phase 3. 웹 리서치 실행

- 최근성(1년, AI는 6개월 가점), 원본 소스, 타깃 직무 일치, 숫자·결과 명시 우선
- 출처 등급 4단계: A1 (1차 공식) / A2 (1차 공공 데이터) / B (검증 2차 보도) / C (보조)
- **시각 소재 별도 검색**: 도구 스크린샷 공식 페이지, 결과물 이미지, 인포그래픽 참조

### Phase 4. 슬롯 채우기 (12슬롯)

꼭지별 템플릿:

#### 슬롯 1. 도입 훅
- 청중 환기용 한 줄 또는 짧은 사례
- 형식: 질문형 / 사례형 / 대비형 / 인용형 중 하나
- **핵심 개념 연결 메모 (신규)**: 이 훅에서 슬롯 2로 어떻게 넘어가는지 1줄
  - 예: "이 사례를 보면 자연스럽게 '도구 선택 기준'이 떠오른다"

#### 슬롯 2. 핵심 개념
- 1~2줄, 정의·기준·결과 중심
- 추상 명사 중심 금지, 행동·상태·결과로 작성

#### 슬롯 3. 데이터 포인트

수치·통계·시장 데이터 3~5개. 사례와 분리해서 별도 정리.

| 카테고리 | 슬롯 내용 |
|---|---|
| 시장 | 시장 규모, 성장률, 사용자 수, 점유율 |
| 사용 | 평균 사용 시간, 빈도, 채택률, 활용 패턴 |
| 비용 | 가격, 절감 효과, 투자 규모 |
| 시간 | 작업 시간 변화, 학습 시간, 도입 시간 |

각 데이터 포인트에 다음 메타 필수:
- 출처 (A1·A2·B 등급, C 등급은 데이터 포인트로 사용 금지)
- 시점 (YYYY-Q 또는 YYYY-MM)
- visualizable_as (V-CHART / V-TEXT 중)
- expires_at (3~6개월 권장)
- **강의 활용 (신규)**: 어느 메시지의 근거로 사용되는지 1줄

수집 기준:
- 꼭지당 3개 이상 (없으면 사유 명시)
- 4카테고리 중 2카테고리 이상 커버
- 같은 출처 데이터 2개 이상 금지 (출처 다양성)

#### 슬롯 4. 대표 사례 3개 (A/B/C 등급)

기존 v3.0과 동일.

**등급 정의**
- A: 타깃 직무 동일 + 최근 1년 + 결과 수치
- B: 유사 직무 + 최근 2년 + 과정 설명
- C: 개념 예시용 보조

각 사례에 메타:
- visualizable_as (V-IMAGE / V-TEXT 우선)
- expires_at (6개월 권장)
- 강의 활용 (어느 메시지의 근거인지)

#### 슬롯 5. 본인 사례·경험

기존 v3.0과 동일. 4유형(운영·실험·관찰·기록).

작성 양식:
- 맥락 (운영 규모·기간·역할)
- 관찰 (구체적 데이터·패턴·반응)
- 강의 활용 (어느 메시지의 근거인지)
- visualizable_as
- expires_at (장기 유효, 12~24개월)

#### 슬롯 6. 비교 매트릭스 (해당 시)

기존 v3.0과 동일.

#### 슬롯 7. 주요 반박과 응답

기존 v3.0과 동일.

#### 슬롯 8. 실습 소재
- 실습명·소요·난이도·준비물·진행 방식
- **검증 메시지 (신규)**: 이 실습이 어느 메시지·슬롯의 검증인지 명시
  - 예: "Ch2의 핵심 개념(슬롯 2)을 직접 재현"

#### 슬롯 9. 수준별 설명 (초/중/고)
- 기존 v3.0과 동일

#### 슬롯 10. 슬라이드 시각 소재 ★ (강화)

기존 "이미지 키워드" 슬롯을 **실제 사용 가능한 시각 소재**로 강화.

3가지 소재 유형으로 분리 수집:

##### 10-1. 이미지 소재 (V-IMAGE 후보)
- 도구 스크린샷 (공식 페이지 URL 또는 직접 캡처)
- 결과물 사례 (Before/After, 시리즈, 단계별)
- 시연 화면 (라이브 데모용)

각 항목에 명시:
- 소스 (URL 또는 직접 제작)
- 사용 슬라이드 번호 추정
- 라이선스 점검 (공식·CC·직접 제작 중)

##### 10-2. 도식 소재 (V-DIAGRAM 후보)
- 다이어그램 구조 (수평 플로우 / 2분할 비교 / 중앙 방사형 / 매트릭스 / 타임라인 / 계층 트리 중)
- 노드 구성 (3~8개 노드와 각 노드 라벨)
- 관계선 (노드 간 연결과 방향)

각 항목에 명시:
- 시각화 형태 (다이어그램 6레이아웃 중)
- 노드 목록 (텍스트로 미리 작성)
- 사용 슬라이드 번호 추정

##### 10-3. 차트 소재 (V-CHART 후보)
- 슬롯 3 데이터 포인트 중 V-CHART 가능 자료 매핑
- 차트 형태 (막대·선·도넛·영역 중)
- X축·Y축 데이터 명시

수집 기준:
- 꼭지당 이미지 1개 이상 + 도식 1개 이상 (또는 차트 1개 이상)
- V-TEXT만 가능한 꼭지 ≤ 30%
- 라이선스 표시 명시 (공식·CC·직접 제작)
- 검증 가능한 URL 또는 직접 제작 메모

#### 슬롯 11. 구술 멘트 ★ (분할)

기존 "구술용 메모(3~5분 분량)"를 **3종 분할**.

##### 11-1. 도입 멘트 (Hook line)
- 꼭지 시작 시 첫 문장
- 슬롯 1(도입 훅)을 말로 푼 형태
- 30~80자 권장
- 4가지 유형 중 하나 명시 (질문·사례·대비·인용)

예: "지난주 한 마케터가 같은 프롬프트를 5개 도구에 넣었습니다."

##### 11-2. 전환 멘트 (Bridge)
- 꼭지 내 슬라이드 사이 전환 멘트 2~4개
- 자료 → 자료, 사례 → 원칙, 원칙 → 적용 단계 사이 연결
- 50자 이내, 접속어 활용

예: "그래서 도구 선택이 중요해집니다."
예: "이 데이터를 직접 검증해본 사례가 있어요."

##### 11-3. 마무리 멘트 (Close)
- 꼭지 마지막 정리 한 줄
- 핵심 메시지 재확인 + 다음 꼭지 예고
- 50~100자 권장

예: "여기서 본 건 도구 비교가 아니라 선택 기준이었습니다. 다음에서는 그 기준을 본인 업무에 적용해봅니다."

#### 슬롯 12. 꼭지 내부 흐름 ★ (신규)

**v3.0의 가장 큰 약점**(슬라이드 흐름이 빈약)을 정면 보완.

11개 슬롯의 자료들을 **어떤 순서·강도로 풀어낼 것인지** 4~5단계로 시퀀스화.

##### 표준 4단계 시퀀스

| 단계 | 역할 | 사용 슬롯 |
|---|---|---|
| ① 도입 (Open) | 청중 환기 + 핵심 개념 예고 | 슬롯 1 (도입 훅) + 슬롯 11-1 (도입 멘트) |
| ② 전개 (Develop) | 개념·데이터로 메시지 설명 | 슬롯 2 (핵심 개념) + 슬롯 3 (데이터 포인트) + 슬롯 11-2 (전환 멘트) |
| ③ 절정 (Climax) | 사례·비교·실습으로 메시지 증명 | 슬롯 4·5·6 (사례·본인 사례·비교) + 슬롯 8 (실습) |
| ④ 정리 (Close) | 메시지 재확인 + 반박 사전 차단 + 다음 예고 | 슬롯 7 (반박과 응답) + 슬롯 11-3 (마무리 멘트) |

##### LI pattern별 변형

LI의 진행 패턴(슬롯 3)에 따라 4단계 비중을 조정한다.

| pattern | ① 도입 | ② 전개 | ③ 절정 | ④ 정리 |
|---|---|---|---|---|
| P-ACC (점진적 누적형) | 10% | 50% | 30% | 10% |
| P-CYC (사례 중심 순환형) | 15% | 25% | 50% | 10% |
| P-CON (문제-해결 대비형) | 20% | 30% | 35% | 15% |
| P-DEM (시연 시연 시연형) | 5% | 15% | 70% | 10% |

##### 작성 양식

```markdown
**꼭지 내부 흐름 (꼭지 시간: N분, pattern: P-XXX)**

① 도입 ({N}분)
- 사용 슬롯: 1, 11-1
- 핵심: {청중 환기 방식}

② 전개 ({N}분)
- 사용 슬롯: 2, 3, 11-2
- 핵심: {개념·데이터로 메시지 설명}

③ 절정 ({N}분)
- 사용 슬롯: 4 사례 A, 5 본인 사례, 6 비교, 8 실습
- 핵심: {메시지 증명 방식}

④ 정리 ({N}분)
- 사용 슬롯: 7 반박 1·2, 11-3
- 핵심: {메시지 재확인 + 다음 꼭지 예고}
```

##### 수집 기준

- 모든 꼭지에 4단계 시퀀스 명시
- 각 단계에 사용 슬롯 매핑 1개 이상
- 단계별 시간 합 = 꼭지 총 시간
- pattern별 비중 가이드 ±10% 허용

##### 흐름 점검 신호

| 신호 | 진단 | 조치 |
|---|---|---|
| ② 전개가 60% 초과 | 정보 나열 강의 | 절정으로 자료 일부 이동 |
| ③ 절정이 30% 미만 | 메시지 증명 부족 | 사례·실습 추가 |
| ④ 정리 5% 미만 | 마무리 빈약 | 반박·재확인 보완 |
| 같은 슬롯이 2단계 이상에 중복 | 슬롯 활용 비효율 | 단계별 슬롯 분리 |

### Phase 4.5. 리서치 실패 경로

- A·B 사례 2개 미만 꼭지: 검색어 재구성 → 인접 확장 → 대체 설계(수강생 사례 수집 세션)
- 데이터 포인트 3개 미만 꼭지: 보고서·통계 사이트 우선 재검색
- 본인 사례 0개 + 외부 사례도 부족: 사용자에게 직접 사례 메모 요청
- 비교 매트릭스 작성 불가: 메시지를 비교형이 아닌 정의형·기준형으로 재설계 권고
- **시각 소재 0개 (신규)**: 도구 스크린샷·결과물·인포그래픽 추가 검색 → 그래도 부족하면 직접 제작 권고
- **꼭지 내부 흐름 비중 어긋남 (신규)**: pattern 재확인 또는 슬롯 재분배

## 연계 스킬

## Harness 블록

| 항목 | 값 |
|---|---|
| 원문 보존 레벨 | L2 균형형 |
| 생성-평가 분리 | 슬롯 채움 → Phase A → 관문 2 (14개) → 재생성 |
| 분량 가드레일 | 꼭지당 1,200~1,800자 / 전체 9,000~18,000자 |
| 재생성 트리거 | A·B 2개 미만 / 데이터 포인트 3개 미만 / 시각 소재 0건 / 흐름 시퀀스 어긋남 / Phase A 12/14 미만 / 관문 2 14/14 미만 |

### 원문 보존 원칙

- 직접 인용 금지 기본. 강의 전달용 재구성
- 예외: 숫자·고유명사·공식 발표 문구는 원문 + 출처
- 구술 멘트는 말로 전달할 형태 (글말 금지)
- 데이터 포인트·비교 매트릭스의 수치는 정확도 우선 (반올림·생략 금지, 단위 명시)

## 사용자 선호 반영

- 응답은 핵심부터, 단독 추임새 금지, 결정형 어조
- AI 흔적 표현 제거: 과장형 형용사·모호한 부사·추측 표현
- 정의·기준·결과 중심 문장
- 한국어 산출물은 한국어로 작성

## 실행 원칙

- lecture-plan v2 입력 시 gate_1_passed 확인 후 진행
- 기획안 없이 실행 시 lecture-plan 먼저 안내
- LI 있으면 pattern을 슬롯 12 흐름 설계 입력으로 사용
- 슬롯은 강의 바로 쓸 수 있는 형태로 (원문 요약 금지)
- 사례는 A·B 2개 이상 / 데이터는 3개 이상 / 시각 소재는 1개 이상 / 흐름 시퀀스 4단계 정합이 통과 기준
- 본인 사례 0개인 꼭지는 사유 명시 필수
- 모든 자료에 visualizable_as·expires_at 부착 필수
- **관문 2 통과 전 lecture-blueprint 진입 금지**
- 금지어 규칙 적용
