# 꼭지 내부 흐름 설계 가이드 (슬롯 12)

lecture-research v3.1에서 신규 추가된 슬롯 12(꼭지 내부 흐름)의 작성 패턴 가이드. v3.0의 가장 큰 약점이었던 "정보는 있는데 강의가 단조롭다" 문제를 정면 보완한다.

---

## 왜 슬롯 12가 필요한가

기존 v3.0의 슬롯 1~11은 모두 **재료 단위**다. 데이터·사례·비교·반박이 다 있지만, 이것들을 **어떤 순서로 어떤 강도로 풀어낼 것인가**는 슬라이드 단계에서 즉흥 결정된다. 그 결과 "정보 나열 강의"가 만들어진다.

슬롯 12는 11개 슬롯의 자료들을 **시퀀스화**해서, lecture-blueprint가 매핑표를 만들 때 임의 해석할 여지를 사전 차단한다.

---

## 표준 4단계 시퀀스

모든 꼭지는 4단계로 분해된다. 각 단계의 역할과 사용 슬롯이 고정되어 있다.

### ① 도입 (Open)

**역할**: 청중을 끌어당기고, 이 꼭지에서 다룰 메시지를 예고한다.

**핵심 행위**
- 슬롯 1(도입 훅)을 슬라이드에 띄움
- 슬롯 11-1(도입 멘트)을 강사가 말함
- 청중 환기 (질문·사례·대비·인용 중 하나)

**기본 사용 슬롯**: 1, 11-1
**보조 사용 가능**: 슬롯 5(본인 사례)에서 짧은 도입 사례 1개

**시간**: 꼭지 시간의 5~20% (pattern에 따라 변동)

### ② 전개 (Develop)

**역할**: 핵심 메시지를 개념·데이터로 설명한다.

**핵심 행위**
- 슬롯 2(핵심 개념)를 정의·기준·결과형으로 제시
- 슬롯 3(데이터 포인트)으로 메시지를 뒷받침
- 슬롯 11-2(전환 멘트)로 슬라이드 사이 연결

**기본 사용 슬롯**: 2, 3, 11-2
**보조 사용 가능**: 슬롯 9(수준별 설명)의 초·중급 부분

**시간**: 꼭지 시간의 15~50% (pattern에 따라 변동)

### ③ 절정 (Climax)

**역할**: 메시지를 사례·비교·실습으로 증명한다. 강의의 가장 강한 지점.

**핵심 행위**
- 슬롯 4(대표 사례 A)를 본문에 인용
- 슬롯 5(본인 사례)로 강의자 직접 검증
- 슬롯 6(비교 매트릭스)로 비교형 메시지 증명
- 슬롯 8(실습)으로 청중 직접 검증

**기본 사용 슬롯**: 4(사례 A), 5, 6(해당 시), 8(해당 시)
**보조 사용 가능**: 슬롯 9(수준별 설명)의 고급 부분, 슬롯 4(사례 B·C)

**시간**: 꼭지 시간의 30~70% (pattern에 따라 변동)

### ④ 정리 (Close)

**역할**: 메시지를 재확인하고, 청중 의문을 사전 차단하고, 다음 꼭지를 예고한다.

**핵심 행위**
- 슬롯 7(반박과 응답)으로 청중 의문 차단
- 슬롯 11-3(마무리 멘트)으로 정리
- 다음 꼭지 예고

**기본 사용 슬롯**: 7, 11-3
**보조 사용 가능**: 슬롯 2(핵심 개념) 재인용

**시간**: 꼭지 시간의 5~15%

## LI pattern별 비중 가이드

강의 의도 노트(LI)의 진행 패턴(슬롯 3)에 따라 4단계 비중을 조정한다.

### P-ACC (점진적 누적형)

```
①도입 10% | ②전개 50% | ③절정 30% | ④정리 10%
```

**특징**
- 전개 단계가 가장 길다 — 개념을 차근차근 쌓아 올림
- 절정은 통합 적용 지점
- 정리는 다음 꼭지의 전제로 연결

**적합 상황**: 초급 청중, 신규 개념 도입 강의

### P-CYC (사례 중심 순환형)

```
①도입 15% | ②전개 25% | ③절정 50% | ④정리 10%
```

**특징**
- 절정 단계가 가장 길다 — 사례 → 원칙 → 사례 반복
- 전개는 짧게, 사례에서 원칙 도출
- 정리는 누적 사례에서 일반화

**적합 상황**: 중급 이상 청중, 적용 동기 강한 강의

### P-CON (문제-해결 대비형)

```
①도입 20% | ②전개 30% | ③절정 35% | ④정리 15%
```

**특징**
- 도입이 비교적 길다 — 문제 인식이 중요
- 전개·절정은 균형 (문제 → 해결)
- 정리에서 적용 행동 명시

**적합 상황**: 기존 방식에 갇힌 청중, 패러다임 전환 강의

### P-DEM (시연 시연 시연형)

```
①도입 5% | ②전개 15% | ③절정 70% | ④정리 10%
```

**특징**
- 절정이 압도적으로 길다 — 시연·실습 중심
- 도입·전개는 최소화
- 정리는 참가자 자기 작업 검토

**적합 상황**: 시연·실습 중심 워크숍

## 작성 양식 (예시)

### 예시 1. P-ACC 패턴 (60분 꼭지)

```markdown
**꼭지 내부 흐름 (꼭지 시간: 60분, pattern: P-ACC)**

① 도입 (6분)
- 사용 슬롯: 1, 11-1
- 핵심: 마케터 사례 1개로 "도구 선택 기준이 모호하다"는 문제 환기

② 전개 (30분)
- 사용 슬롯: 2, 3, 11-2
- 핵심: 도구 선택의 3축(입력·출력·맥락)을 데이터로 설명. D1·D2·D3 차트 활용

③ 절정 (18분)
- 사용 슬롯: 4 사례 A, 5 본인 사례 1, 8 실습
- 핵심: 마케팅 카피 작성 사례 시연 + 청중 본인 작업 적용 실습

④ 정리 (6분)
- 사용 슬롯: 7 반박 1·2, 11-3
- 핵심: "도구는 다 비슷하다" 반박 차단 + 다음 꼭지(실전 적용) 예고
```

### 예시 2. P-CYC 패턴 (45분 꼭지)

```markdown
**꼭지 내부 흐름 (꼭지 시간: 45분, pattern: P-CYC)**

① 도입 (7분)
- 사용 슬롯: 1, 11-1, 5 본인 사례 1
- 핵심: 카카오 커뮤니티 1,500명 운영 사례로 "도구가 아니라 흐름" 환기

② 전개 (11분)
- 사용 슬롯: 2, 3
- 핵심: 흐름 설계의 4가지 원리 짧게 제시 (개념은 최소화)

③ 절정 (23분)
- 사용 슬롯: 4 사례 A·B, 5 본인 사례 2, 6 비교 매트릭스
- 핵심: 3개 사례 순환으로 같은 원리 반복 확인

④ 정리 (4분)
- 사용 슬롯: 7 반박 1, 11-3
- 핵심: 흐름 설계의 핵심 원리 1줄 정리 + 다음 꼭지 예고
```

## 흐름 점검 신호

작성한 흐름 시퀀스를 다음 신호로 점검한다.

| 신호 | 진단 | 조치 |
|---|---|---|
| ② 전개가 60% 초과 | 정보 나열 강의 위험 | 절정으로 자료 일부 이동 |
| ③ 절정이 30% 미만 | 메시지 증명 부족 | 사례·실습 추가 |
| ④ 정리 5% 미만 | 마무리 빈약 | 반박·재확인 보완 |
| ① 도입 25% 초과 | 도입 길어 본문 압축 | 도입 핵심만 남기고 단축 |
| 같은 슬롯이 2단계 이상에 중복 | 슬롯 활용 비효율 | 단계별 슬롯 분리 |
| 시간 합 ≠ 꼭지 시간 | 정합 어긋남 | 단계별 시간 재분배 |

## 흐름 설계가 어려울 때

### 케이스 1. 사례·데이터가 부족해 절정이 빈약하다

→ 슬롯 4(외부 사례) Phase 4.5(인접 확장) 재실행
→ 슬롯 5(본인 사례) 직접 메모 추가
→ 슬롯 6(비교 매트릭스) 보강

### 케이스 2. 반박이 떠오르지 않아 정리가 빈약하다

→ 슬롯 7 4유형(회의·비용·위협·대체) 중 빠진 유형 보강
→ LI의 anti_lecture가 있으면 그 항목을 반박 1로 활용

### 케이스 3. pattern을 모르겠다

→ 강의 의도 노트(LI)를 먼저 작성해서 pattern 결정
→ LI 없으면 pattern 가이드(`pattern-decision-guide.md`) 참조하여 직접 결정

### 케이스 4. 4단계 비중이 pattern과 맞지 않는다

→ 자료 분포에 따라 pattern 자체를 재선택
→ 예: 자료가 사례 위주이면 P-ACC가 아닌 P-CYC가 적합

## lecture-blueprint와의 연계

슬롯 12의 4단계 시퀀스는 lecture-blueprint 매핑표 작성 시 직접 입력으로 사용된다.

- ① 도입의 사용 슬롯 → bridge 매핑표의 첫 1~2행
- ② 전개의 사용 슬롯 → bridge 매핑표의 중간 30~50% 행
- ③ 절정의 사용 슬롯 → bridge 매핑표의 강도 W "상" 행
- ④ 정리의 사용 슬롯 → bridge 매핑표의 마지막 1~2행

이렇게 RL 단계에서 흐름이 고정되어 있으면 bridge·blueprint·slides 단계의 임의 해석이 사라지고, 슬라이드는 처음 의도한 흐름 그대로 만들어진다.

## 사용자 선호 반영

작성자 선호와 정합:

- 결정 기준 제시형 (각 단계의 역할·시간·슬롯이 명확)
- 추측 금지 (4단계 비중은 pattern으로 결정, 임의 변경 금지)
- 권유·감탄형 표현 없음
- 한국어 작성, 코드(P-ACC 등)는 영문 표준
