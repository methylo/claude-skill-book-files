# 구도 설계 가이드 (Composition Guide)

SKILL.md의 Step 2(유형 판단)와 Step 3(구도 설계)에서 참조한다.

---

## 라인 드로잉 구도 3가지

| 구도 | 설명 | 적합한 챕터 |
|------|------|---------|
| **좌우 대칭** | 좌=Before, 우=After, 중앙=전환 장치 | 상태 전환, 환경 대비, 인식 변화 |
| **중앙 집중** | 인물 1명 중앙, 주변에 상황 요소 방사형 | 핵심이 "한 사람의 판단" |
| **시간 흐름** | 좌→중앙→우 3장면 연속 | 과정·변화가 단방향 |

### 구도 선택 기준 (라인 드로잉)

1. 챕터 핵심이 "A에서 B로 바뀌었다" → **좌우 대칭**
2. 챕터 핵심이 "이 사람이 판단/선택한다" → **중앙 집중**
3. 챕터 핵심이 "이런 과정을 거쳤다" (3단계 이상) → **시간 흐름**
4. 확실하지 않으면 → **좌우 대칭** (가장 범용적)

## 인포그래픽 세부 유형 6가지

인포그래픽은 세부 유형이 곧 구도다.

### 세부 유형 선택 결정 트리

아래 순서대로 질문하여 첫 번째로 "예"에 해당하는 유형을 선택한다.

```
Q1. 챕터에 Before/After 또는 A vs B 대비 구조가 있는가?
    → 예: 비교형
    → 아니오: Q2로

Q2. 챕터에 순차적 단계(입력→처리→출력, 체크리스트, 필터링)가 있는가?
    → 예: 프로세스형
    → 아니오: Q3으로

Q3. 챕터에 반복·순환·지속 개선 구조가 있는가? (끝이 다시 시작으로 돌아오는가?)
    → 예: 순환형
    → 아니오: Q4로

Q4. 챕터에 상위/하위, 기반/표면, 보이는 것/보이지 않는 것의 층위 구분이 있는가?
    → 예: 계층형
    → 아니오: Q5로

Q5. 챕터에 시간축을 따른 변화(과거→현재, 시기 구분)가 있는가?
    → 예: 타임라인형
    → 아니오: Q6으로

Q6. 챕터에 하나의 입력이 여러 갈래로 분류되거나, 유형화 구조가 있는가?
    → 예: 구조형
    → 아니오: 비교형 (가장 범용적, 기본값)
```

**Q2(프로세스형) vs Q5(타임라인형) 구분 기준**:
- 프로세스형: 단계마다 **행위**(점검·변환·필터링)가 있음. "무엇을 하는가"가 중심.
- 타임라인형: 단계마다 **시점**(과거·전환기·현재)이 있음. "언제 바뀌었는가"가 중심.

### 좌·중앙·우 3분할 구도 (4가지)

| 세부 유형 | 적합한 원고 특성 | 좌측 | 중앙 | 우측 |
|---------|--------------|------|------|------|
| **비교형** | Before/After, 이전/이후, 단일/복수 | 이전(회색) | 전환 화살표 | 이후(보조색) |
| **프로세스형** | 순차 점검, 단계별 흐름, 필터링 | 입력 | 단계(필터/게이트) | 출력 |
| **타임라인형** | 시간에 따른 변화, 시기 구분 | 과거 | 전환점 | 현재 |
| **구조형** | 분류, 유형화, 1→N 관계 | 통합(1개) | 분기 화살표 | 분류(N개) |

### 전용 구조 구도 (2가지)

좌·중앙·우 3분할에 맞지 않으므로 전용 구조를 사용한다.

| 세부 유형 | 적합한 원고 특성 | 구조 | 배치 원칙 |
|---------|--------------|------|---------|
| **계층형** | 층위 구조, 기반/표면 구분 | **상하 구조** | 하단=기반/토대, 상단=표면/결과, 수직 화살표로 연결 |
| **순환형** | 반복, 지속적 개선, 끝없는 루프 | **4분면 대칭** | 좌상→우상→우하→좌하 시계방향 순환, 중앙에 핵심 아이콘 |

## 좌우 대칭 상세 규칙 (라인 드로잉·인포그래픽 공통)

```
좌우 화면 비율: 각 40%, 중앙 전환 장치 20%
좌측: Before / 문제 / 이전 / 입력
중앙: 전환 장치 (점선, 화살표, 시계, 격자 등)
우측: After / 해결 / 이후 / 출력
좌우 인물(라인 드로잉의 경우)은 동일인 — 자세·표정·주변 사물만 변화
```

## 중앙 전환 장치 옵션

좌우 대칭 구도에서 중앙에 배치할 장치를 선택한다.

| 장치 | 의미 | 적합한 전환 |
|------|------|---------|
| 세로 점선 | 시간 경과 | 상태 전환, 깨달음 |
| 세로 실선 | 선명한 구분 | 환경 전환, 조건 변경 |
| 큰 화살표(→) | 방향 전환 | Before/After, 개선 |
| 시계 아이콘 | 짧은 시간 경과 | 순간적 전환, 결정의 순간 |
| 격자 패턴 | 규칙·프레임 | 규칙 도입, 구조 변화 |
| 거울 프레임 | 자기 인식 | 반영, 자기 발견 |
