# 색상 체계 (Color System)

SKILL.md의 Step 5(일관성 점검·배치 계획)에서 참조한다.

---

## 파트별 보조색 체계

책이 파트(Part) 구조를 갖는 경우, 인포그래픽의 보조색을 파트별로 지정한다.

| 설계 기준 | 방법 |
|---------|------|
| 파트 수 | 2~5개 파트에 각각 고유 보조색 지정 |
| 색상 선택 | 책의 톤·장르에서 도출. 파트의 성격과 색상 의미 연결 |
| 주조색 | 전체 공통 1색 |
| 배경 | 흰색(#FFFFFF) 고정 |

---

## 장르별 기본 색상 세트 (참고용)

사용자가 색상을 지정하지 않은 경우 아래를 기본값으로 제안한다.

| 장르 | 주조색 | 보조색 예시 (파트별) | 톤 |
|------|--------|-------------------|-----|
| 실용서·비즈니스 | 네이비(#1B2A4A) | 청록(#2EC4B6), 앰버(#E8A838), 슬레이트(#6B7B8D) | 신뢰·전문 |
| 에세이·산문 | 웜그레이(#5C5C5C) | 코랄(#E8735A), 세이지(#8FAE7E), 머스타드(#D4A843) | 따뜻·내밀 |
| 자기계발·성장 | 딥그린(#1A5632) | 골드(#C9A84C), 테라코타(#C4704B), 스카이(#5BA4CF) | 성장·활력 |
| 기술·IT | 차콜(#2D2D2D) | 일렉트릭블루(#3B82F6), 민트(#34D399), 퍼플(#8B5CF6) | 현대·혁신 |
| 인문·교양 | 버건디(#6B2737) | 올드골드(#B8963E), 포레스트(#3D6B4F), 인디고(#4338CA) | 깊이·품격 |

## 색상 적용 원칙

| 항목 | 규칙 |
|------|------|
| 라인 드로잉 | 흑백 통일. 파트별 보조색 적용하지 않음 |
| 인포그래픽 — Before 영역 | 회색(#B0B8C4) 또는 연한 톤 |
| 인포그래픽 — After 영역 | 해당 파트의 보조색 적용 |
| 인포그래픽 — 주조색 | 제목, 구분선, 프레임에 사용. 전체 통일 |
| 배경 | 모든 삽화 흰색(#FFFFFF) 고정 |
| 색상 수 제한 | 삽화 1장당 최대 3색 (주조색 + 보조색 + 배경) |
