# 인포그래픽 마스터 프롬프트 + 스타일 규칙

SKILL.md의 Step 4(프롬프트 구조화)에서 인포그래픽 유형일 때 참조한다.

---

## 마스터 프롬프트 — 기본 (비교/프로세스/타임라인/구조형)

좌·중앙·우 3분할 구도에 해당하는 4가지 세부 유형에 공통 사용한다.

```
깔끔한 인포그래픽 삽화를 만들어줘.

[기본]
{등장 요소 나열 — 아이콘, 도형, 화살표 등}.
미니멀 플랫 디자인.

[유형] {비교형 / 프로세스형 / 타임라인형 / 구조형}

[좌측 — {라벨}]
{구체적 구성 묘사 3~5줄}

[중앙]
{전환 장치 1~2줄}

[우측 — {라벨}]
{구체적 구성 묘사 3~5줄}

[기타]
주조색 {색상명(HEX)}, 보조색 {색상명(HEX)}.
흰색(#FFFFFF) 배경. 가로형(16:9).
{추가 조건}.
```

## 마스터 프롬프트 — 순환형

좌·중앙·우 3분할이 아닌 4분면 배치 구조를 사용한다.

```
깔끔한 인포그래픽 삽화를 만들어줘.

[기본]
{등장 요소 나열 — 아이콘, 도형, 화살표 등}.
미니멀 플랫 디자인.

[유형] 순환형 — 4분면 시계방향 배치

[좌상 — {1단계 라벨}]
{아이콘·도형 구성 1~2줄}

[우상 — {2단계 라벨}]
{아이콘·도형 구성 1~2줄}

[우하 — {3단계 라벨}]
{아이콘·도형 구성 1~2줄}

[좌하 — {4단계 라벨}]
{아이콘·도형 구성 1~2줄}

[연결]
4분면을 잇는 곡선 화살표 — 시계방향 순환.
중앙에 순환 핵심 키워드 아이콘 배치.

[기타]
주조색 {색상명(HEX)}, 보조색 {색상명(HEX)}.
흰색(#FFFFFF) 배경. 가로형(16:9).
{추가 조건}.
```

## 마스터 프롬프트 — 계층형

좌·우가 아닌 상·하 구조를 사용한다.

```
깔끔한 인포그래픽 삽화를 만들어줘.

[기본]
{등장 요소 나열 — 아이콘, 도형, 구분선 등}.
미니멀 플랫 디자인.

[유형] 계층형 — 상하 구조

[하단 — {기반/토대 라벨}]
{기반 요소의 아이콘·도형 구성 2~3줄}

[구분]
{가로 구분선 / 점선 / 그라데이션 경계}

[상단 — {표면/결과 라벨}]
{표면 요소의 아이콘·도형 구성 2~3줄}

[연결]
하단에서 상단으로 향하는 수직 화살표 {N}개.

[기타]
주조색 {색상명(HEX)}, 보조색 {색상명(HEX)}.
흰색(#FFFFFF) 배경. 가로형(16:9).
{추가 조건}.
```

## 스타일 규칙

### 공통 규칙 (모든 인포그래픽)

| 항목 | 규칙 |
|------|------|
| 디자인 | 미니멀 플랫 디자인 |
| 도형 | 둥근 모서리 사각형, 원형 아이콘 |
| 선 | 얇은 실선, 화살표는 단방향 삼각형 끝 |
| 아이콘 | 단순 실루엣, 내부 디테일 최소 |
| 색상 수 | 주조색 + 보조색 + 배경 = 최대 3색 |
| 도형 개수 | 전체 6~10개 이내 |
| 텍스트 | 핵심 키워드만 최소한 포함 가능 (한국어+영문 병기) |
| 정보 계층 | 크기·색상·위치로 1순위/2순위 구분 |

### 구도별 색상 적용 규칙

| 구도 | 색상 적용 |
|------|---------|
| 비교형·타임라인형 | 좌측(Before/과거)=회색(#B0B8C4), 우측(After/현재)=보조색 |
| 프로세스형·구조형 | 입력=회색, 출력/분류 결과=보조색 |
| 계층형 | 하단(기반)=회색, 상단(표면)=보조색 |
| 순환형 | 4분면 모두 보조색 동일. 현재 활성 단계만 보조색 진하게, 나머지는 연하게 |

### 기본 아이콘 세트 (참고용)

첫 삽화에서 아이콘 스타일을 확정하고, 전체 챕터에 동일 세트를 반복 사용한다.

| 개념 | 아이콘 형태 |
|------|----------|
| 사람/사용자 | 원형 머리 + 반원 상체 (실루엣) |
| AI/자동화 | 칩 아이콘 (사각형 + 양옆 핀) 또는 번개 |
| 문서/콘텐츠 | 종이 아이콘 (사각형 + 상단 접힘) |
| 체크/완료 | 원 안의 체크 마크 |
| 시간/일정 | 원형 시계 |
| 소통/공유 | 말풍선 |
| 성장/상승 | 우상향 화살표 또는 계단 |
| 도구/시스템 | 톱니바퀴 |

## 완성 프롬프트 예시

### 예시 1: 순환형 — "AI 글쓰기 워크플로우 사이클"

**① 기본 설명**
이 챕터는 AI 글쓰기 워크플로우가 "주제 탐색 → 구조 설계 → 초안 생성 → 리라이팅" 4단계를 반복 순환하는 구조임을 설명한다. 한 번 돌고 끝나는 것이 아니라 리라이팅 결과가 다시 주제 탐색을 촉발하는 지속적 개선 루프다.

**② 구도 상세 (4분면)**
- 좌상(1단계): 돋보기 아이콘 + "탐색" 키워드. 흩어진 점 3개가 돋보기로 모여드는 형태.
- 우상(2단계): 블록 3개가 위에서 아래로 정렬된 형태 + "설계" 키워드.
- 우하(3단계): 종이 아이콘에서 텍스트 줄이 나오는 형태 + "초안" 키워드.
- 좌하(4단계): 연필 아이콘이 종이 위를 다듬는 형태 + "리라이팅" 키워드.
- 중앙: 순환 화살표 아이콘(원형).

**③ 기타**
4분면 간 곡선 화살표가 시계방향으로 연결. 좌하(리라이팅)에서 좌상(탐색)으로 돌아오는 화살표를 약간 굵게 하여 "반복" 강조. 현재 활성 단계 없이 4분면 동일 톤.

```
깔끔한 인포그래픽 삽화를 만들어줘.

[기본]
돋보기, 블록 3개, 종이, 연필, 순환 화살표.
미니멀 플랫 디자인.

[유형] 순환형 — 4분면 시계방향 배치

[좌상 — 탐색(Explore)]
돋보기 아이콘. 흩어진 점 3개가 돋보기 쪽으로 모여드는 형태.

[우상 — 설계(Structure)]
둥근 모서리 블록 3개가 위에서 아래로 정렬. 블록 사이에 얇은 연결선.

[우하 — 초안(Draft)]
종이 아이콘에서 텍스트 줄 3개가 나오는 형태. 줄은 점선으로 '생성 중' 표현.

[좌하 — 리라이팅(Rewrite)]
연필 아이콘이 종이 위를 다듬는 형태. 종이 줄이 실선으로 변환.

[연결]
4분면을 잇는 곡선 화살표 — 시계방향 순환.
좌하→좌상 화살표는 약간 굵게 하여 반복 강조.
중앙에 원형 순환 화살표 아이콘 배치.

[기타]
주조색 네이비(#1B2A4A), 보조색 청록(#2EC4B6).
흰색(#FFFFFF) 배경. 가로형(16:9).
텍스트는 각 분면에 한국어+영문 키워드만 최소한 포함.
```

### 예시 2: 비교형 — "수동 작업 vs AI 워크플로우"

```
깔끔한 인포그래픽 삽화를 만들어줘.

[기본]
사람 실루엣, 문서 아이콘, 시계, 체크마크, 칩 아이콘, 화살표.
미니멀 플랫 디자인.

[유형] 비교형

[좌측 — 수동(Manual)]
사람 실루엣이 문서 아이콘 5개를 하나씩 처리하는 형태.
문서 사이에 긴 화살표(시간 소요 표현).
상단에 시계 아이콘 — 시침이 많이 돌아간 상태.
회색(#B0B8C4) 톤.

[중앙]
큰 화살표(→) 전환.

[우측 — AI 워크플로우(AI Workflow)]
사람 실루엣 옆에 칩 아이콘.
문서 5개가 동시에 처리되는 형태(병렬 배치).
상단에 시계 아이콘 — 시침이 조금만 돌아간 상태.
각 문서에 체크마크. 청록(#2EC4B6) 톤.

[기타]
주조색 네이비(#1B2A4A), 보조색 청록(#2EC4B6).
흰색(#FFFFFF) 배경. 가로형(16:9).
좌우 차이 핵심: 문서의 '순차 배치 vs 병렬 배치'와 시계 시침 차이.
```
