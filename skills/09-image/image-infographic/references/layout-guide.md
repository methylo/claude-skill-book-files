# 레이아웃·컬러 가이드

레이아웃 선택, 컬러 키, 시각 장치, 밀도 보강 기준이다.

## 업체별 컬러 키

매번 다른 업체 강의에 대응하기 위해 **업체 성격별 포인트 컬러 키**를 지정한다. 배경(#FFFFFF)과 폰트(Noto Sans KR)는 고정, 스틱맨 선·아이콘·강조 텍스트·구분선·배지에만 포인트 컬러를 적용한다.

### 컬러 키 지정 방식

**자동 추천**: 사용자가 업체명 또는 업체 성격을 입력하면 매칭되는 컬러 키를 자동 추천한다.
- 예: "서울경제진흥원" → 공공기관 → 딥그린+라이트그린 자동 적용

**수동 지정**: 사용자가 직접 헥스코드 또는 프리셋 이름을 지정한다.
- 예: "이번 강의는 퍼플+핑크로 가자" → 스타트업 프리셋 적용
- 예: "메인 #E63946, 보조 #457B9D로" → 커스텀 컬러 적용

**확인 절차**: 자동 추천 후 사용자에게 **"이 컬러로 진행할까요?"**를 1회 확인한 뒤 배치 생성에 들어간다. 단일 슬라이드 생성 시에는 확인 없이 바로 진행한다.

### 컬러 키 적용 범위

|------|----------|
| 스틱맨 선·윤곽 | 메인 컬러 |
| 타이틀 배지·강조 텍스트 | 메인 컬러 배경 + 흰색 텍스트, 또는 메인 컬러 텍스트 |
| 구분선·연결선·화살표 | 메인 컬러 |
| 보조 아이콘·서브 배지 | 보조 컬러 |
| 본문 텍스트 | 기본 검정 #1F2937 (가독성 우선) |
| 배경 | 흰색 #FFFFFF 고정 |

## 시각 장치 3종

레이아웃과 독립적으로 얹어 사용하는 시각 장치다. 원고 내용에 따라 0~2개를 조합한다.

| 장치 | 용도 | 적용 예시 |
|------|------|----------|
| **강조 배지** | 핵심 키워드·숫자 부각 | 원형·사각형 배지 (메인 컬러), 숫자 "6개월", "3가지" |
| **연결선·화살표** | 스틱맨·요소 간 관계 표현 | 직선·곡선·점선, 단방향·양방향 |
| **데이터 표시** | 숫자·퍼센트 전면 배치 | 큰 폰트 수치, 퍼센트 원형 그래프 |

**데이터 표시**는 기존 "데이터형 스타일"을 대체한다. 레이아웃(L1~L5) 어디에든 숫자가 있으면 이 장치를 얹는다.

## 레이아웃 자동 추천 로직

원고를 분석한 뒤 **3개 추천**(강조 패널 변형 우선)을 출력하고, 각 추천에 해당하는 완성 프롬프트를 함께 제공한다.

### 추천 우선순위 원칙 (2026-04-20 개정)

표준 L1~L5 단독 레이아웃은 시각적 차별성이 낮아 시리즈로 반복하면 단조롭다. 따라서 **강조 패널 변형(EP, Emphasis Panel)을 ①·② 자리에 우선 배치**하고, 표준 단독 레이아웃은 ③ 자리(시리즈 일관성·빠른 일괄 생성용)로 후순위 처리한다.

- ① **EP-A 컴팩트 + 하단 강조 패널**: 본문 상단 60~65% + 하단 강조 패널 35~40%
- ② **EP-B 좌측 본문 + 우측 사이드 강조**: 좌측 본문 65~70% + 우측 세로 강조 패널 30~35%
- ③ **표준 L?형 단독**: 강조 패널 없는 순수 L1~L5 형태

EP-A·EP-B의 본문 영역에는 아래 "원고 신호 → 베이스 레이아웃" 표를 그대로 적용한다.

### 베이스 레이아웃 매칭 (EP-A·EP-B 본문 영역에 적용)

| 원고에서 감지되는 신호 | 베이스 레이아웃 |
|---------------------|---------------------|
| 핵심 개념 1개 정의·강조 | L1 중앙 집중형 / L5 방사형 |
| 장단점·변화 전후·A vs B | L2 좌우 2분할 / L3 카드 그리드 |
| 특징 3~4개 나열·사례 4개 병렬 | L3 카드 그리드 / L5 방사형 |
| 시간 순서·발전 과정·로드맵·단계 | L4 가로 타임라인 / L3 카드 그리드 |
| 중심 개념에서 여러 요소 파생 | L5 방사형 / L3 카드 그리드 |
| 단계별 프로세스 (4단계 이하) | L4 가로 타임라인 / L3 카드 그리드 |
| 단계별 프로세스 (5단계 이상) | L4 가로 타임라인 (단독) |
| 구조·분류·기술 설명 | L5 방사형 / L3 카드 그리드 |
| 문제 상황·사례 1개 | L1 중앙 집중형 / L2 좌우 2분할 |
| 비포/애프터 + 숫자 | L2 좌우 2분할 (+데이터 표시 장치) |

### 강조 패널 변형 2종 — 상세 사양

#### EP-A: 컴팩트 + 하단 강조 패널

- **상단 본문 영역(약 60~65%)**: 베이스 레이아웃(L1~L5) 적용. 카드·노드·타임라인 셀이 압축된 형태로 들어감
- **하단 강조 패널(약 35~40%)**: 가로로 가득 찬 어두운 띠(메인 컬러 진한 톤). 패널 안에는 핵심 메시지 한 줄(15~22자) + 부가 라벨 1~2개(키워드 또는 숫자)
- **타이틀**: T1 상단 중앙 고정 (기본 모드 권장)
- **시각 효과**: 본문↔패널 색 대비로 시선 자연 유도, 결론·다음 액션을 시각적으로 못 박음
- **적용 권장**: 메시지가 명확한 모든 슬라이드 (특히 결론·핵심 한 줄이 있는 경우)

#### EP-B: 좌측 본문 + 우측 사이드 강조

- **좌측 본문 영역(약 65~70%)**: 베이스 레이아웃(L1~L5) 적용. 세로로 압축된 형태로 들어감
- **우측 사이드 패널(약 30~35%)**: 세로 띠(메인 컬러 진한 톤 또는 흰 배경 + 굵은 좌측 컬러 바). 패널 안에는 핵심 숫자 1개(큰 폰트) 또는 핵심 키워드 1~2개 + 짧은 결론(10~15자)
- **타이틀**: T2 좌측 분할(프리미엄) 또는 T1 상단 중앙 고정
- **시각 효과**: 매거진 사이드바 느낌, 숫자 데이터·핵심 키워드 강조에 적합
- **적용 권장**: 숫자·통계가 핵심인 슬라이드, 키 메시지를 사이드 캡슐로 분리하고 싶은 경우

### 추천 조합 자동 선택 규칙

| 원고 성격 | ① 추천 | ② 추천 | ③ 추천 |
|---------|--------|--------|--------|
| 결론·핵심 한 줄이 명확 (기본값) | EP-A | EP-B | 표준 베이스 단독 |
| 숫자·통계가 중심 | EP-B | EP-A | 표준 베이스 단독 |
| 단순 나열·구조 (결론 모호) | EP-A | 표준 베이스 단독 | EP-B |
| 시리즈 일관성·반복 회피 우선 | 표준 베이스 단독 | EP-A | EP-B |

**기본값**: 사용자가 모드를 명시하지 않으면 첫 번째 행(결론 명확형)을 적용한다.

### 레이아웃 충돌 시 판단 기준

하나의 원고에 여러 성격이 섞여 있을 때, 아래 우선순위로 판단한다.

| 상황 | 판단 기준 |
|------|----------|
| 비교 + 시간 순서 | 시간축이 명확 → L4 타임라인. 비교가 주 → L2 좌우 2분할 |
| 나열 + 순서 | 순서 필수 → L4 타임라인. 순서 없이 병렬 → L3 카드 그리드 |
| 구조 설명 + 숫자 데이터 | 숫자가 핵심 → L1 중앙 집중형 + 데이터 표시 장치. 구조가 핵심 → L5 방사형 |
| 사례 4개 이상 | → L3 카드 그리드. 카드 그리드는 최대 4개, 초과 시 핵심 4개만 선별 |
| 단일 핵심 메시지 | → L1 중앙 집중형 (다른 레이아웃보다 항상 우선) |

**원칙**: 원고의 **핵심 메시지가 무엇을 전달하려는지**를 기준으로 판단한다. "이 슬라이드를 본 사람이 무엇을 가져가야 하는가?"에 대한 답이 레이아웃을 결정한다.

### 배치 생성 시 레이아웃 다양성 규칙

lecture-slides의 04-image-list.md를 입력받아 여러 슬라이드를 배치 생성할 때, **레이아웃이 연속 3회 반복되지 않도록** 분산한다.

- 같은 레이아웃이 3회 연속 나오면 2번째·3번째 중 하나는 대체 레이아웃(추천 우선순위 2순위)으로 교체
- 단, 원고 성격이 명확히 같은 레이아웃을 요구하면 예외 허용
- 업체 컬러 키는 전체 슬라이드에 **동일하게 통일 적용**한다 (다양성 대상 아님)

## 시각 밀도 보강 규칙

16:9 가로 비율에서 슬라이드로 바로 쓸 수 있는 밀도를 확보하려면, 프롬프트 작성 시 다음 3가지 보강 장치를 반드시 적용한다.

### 보강 1: 하위 정보 레이어 추가

각 포인트에 **하위 태그·부가 설명·세부 항목**을 1~3개씩 붙여 정보량을 늘린다.

| 보강 전 | 보강 후 |
|--------|--------|
| "SKILL.md" — 문서 아이콘 | "SKILL.md" — 문서 아이콘, 설명: "트리거·절차·출력 규칙", 하위 태그: "워크플로우", "조건 분기", "출력 형식" |
| "초안 작성" — 연필 아이콘 | "초안 작성" — 연필 아이콘, 설명: "AI로 재료 확보", 하위 태그: "빠른 생성", "완벽보다 속도" |

### 보강 2: 배경·구역 분리

화면을 **2~3개 구역**으로 나눠 시각적 밀도를 높인다.

- **제목 영역**: 진한 색상 배경 띠 위에 흰색 제목 텍스트
- **콘텐츠 영역**: 연한 회색 또는 연한 색상 배경 블록 안에 주요 요소 배치
- **하단 영역**: 흰색 여백에 요약 문구 또는 부가 정보

### 보강 3: 시각 장치 추가

- **번호 뱃지**: 각 카드/단계 좌상단에 원형 번호 배치
- **카드 색상 분리**: 각 카드마다 다른 연한 색상 배경
- **연결 장치**: 굵은 연결선, 화살표, 점선 구분선 등
- **크기 지시**: "카드 크기를 크게", "요소가 화면을 충분히 채우도록" 등 명시
- **한 줄 설명**: 각 항목 아래 짧은 부가 설명 추가

### 밀도 보강 체크리스트

프롬프트 작성 완료 후 아래를 점검한다. **3개 이상 충족해야 출력**한다.

- [ ] 각 핵심 포인트에 하위 태그 또는 부가 설명이 있는가
- [ ] 화면이 2개 이상 구역(제목 띠 + 콘텐츠 블록)으로 나뉘어 있는가
- [ ] 각 카드/요소에 서로 다른 색상이 적용되어 있는가
- [ ] 번호 뱃지 또는 아이콘이 모든 항목에 포함되어 있는가
- [ ] "화면을 충분히 채우도록" 또는 "카드 크기를 크게" 같은 크기 지시가 있는가
