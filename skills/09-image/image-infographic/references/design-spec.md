# 디자인 사양

프롬프트를 조립할 때 읽는 텍스트 렌더링·타이틀·폰트·사양 규칙이다.

## 텍스트 렌더링 핵심 원칙 (매우 중요)

나노바나나 프로는 프롬프트 내 **모든 텍스트를 이미지에 그릴 가능성**이 있다. 사양 표기·영문 라벨·픽셀 크기 표기가 이미지에 잘못 들어가는 사고를 막기 위해 다음 원칙을 반드시 따른다.

### 이미지에 절대 들어가면 안 되는 것

1. **매거진 헤더** ("ISSUE 01 · OOO" 형식) — 전면 금지
2. **영문 부제** (메인 타이틀 아래) — 전면 금지
3. **카드 내 영문 서브타이틀** ("Plan", "Research" 등) — 전면 금지
4. **사양 표기 텍스트**:
   - 픽셀 크기 (60px, 3px, 40px, 100px 등)
   - 폰트 사양 (Bold, Light, SemiBold, 14pt, 18pt, 52pt 등)
   - 헥스코드 (#065F46, #6B7280 등)
   - 폰트 이름 (Noto Sans KR, Google Fonts 등)
5. **레이아웃 설명 텍스트** ("좌측 정렬", "중앙 배치" 등)

### 이미지에 들어가도 되는 것 (한글 콘텐츠만)

1. 메인 타이틀 (한글)
2. 카드 인덱스 번호 ("01", "02", "03", "04" — 숫자만)
3. 카드 한글 타이틀
4. 카드 한글 캡션
5. 데이터 표시 시각 장치의 숫자·퍼센트
6. 시각 장치의 짧은 한글 라벨

### 프롬프트 작성 방식

이미지에 들어갈 텍스트와 디자인 사양을 **반드시 별도 섹션으로 분리**한다.

**❌ 잘못된 방식 (사양과 콘텐츠 혼재)**
```
- 한글 타이틀: "맞춤 큐레이션" (SemiBold 24pt, 딥그린 #065F46)
```

**✅ 올바른 방식 (분리)**
```
[카드 1 — 이미지에 표시할 한글 텍스트]
- 인덱스 숫자: 01
- 한글 타이틀: 맞춤 큐레이션
- 한글 캡션: 이용자별 독서 취향 분석

[카드 1 — 디자인 사양 (이미지에 표시 금지)]
- 타이틀 폰트 굵기: SemiBold
- 타이틀 색상: 딥그린
- 본문 폰트 굵기: Regular
- 캡션 색상: 그레이
```

콘텐츠 섹션에는 **순수 한글 텍스트만**, 사양 섹션에는 **디자인 지시만** 둔다.

### 영문 강제 규칙 (모든 프롬프트 끝에 필수 포함)

```
CRITICAL RENDERING RULES — DO NOT VIOLATE:
- Do NOT render any pixel size notations (60px, 3px, 40px, 100px, etc.) as visible text.
- Do NOT render any font specifications (Bold, Light, SemiBold, Regular, 14pt, 18pt, 52pt, etc.) as visible text.
- Do NOT render any hex color codes (#065F46, #6B7280, #E5E7EB, etc.) as visible text.
- Do NOT render any font names (Noto Sans KR, Google Fonts, etc.) as visible text.
- Do NOT render English magazine headers like "ISSUE 01 · OOO".
- Do NOT render English subtitles below the main title.
- Do NOT render English card subtitles (Plan, Research, etc.).
- Do NOT render layout descriptions or measurement guides.
- Only render Korean text that is explicitly listed under "이미지에 표시할 한글 텍스트" sections.
- Numbers like "01", "02" are allowed only for card indexes.
```

이 규칙은 모든 프롬프트의 **마지막 섹션**에 반드시 포함한다.

## 디자인 스펙 누출 방지 강화 (2026-04-20 개정)

기존 CRITICAL RENDERING RULES만으로는 픽셀 수치·폰트명·컬러코드가 이미지에 렌더되는 사고를 막지 못한 사례가 있어, 아래 3단 강화 규칙을 모든 프롬프트에 추가 적용한다.

### 강화 1: ABSOLUTE TEXT RULE 선언문 (프롬프트 최상단 필수)

프롬프트 첫 문장 바로 다음에 아래 블록을 항상 포함한다.

```
ABSOLUTE TEXT RULE
- KOREAN TEXT TO RENDER의 한국어 문자열만 화면에 렌더한다.
- 그 외 모든 숫자·측정값·좌표·컬러코드·폰트명·영문 라벨은 내부 레이아웃 지침이며 화면에 텍스트로 표시하지 않는다.
```

### 강화 2: 디자인 스펙을 서술형 상대 표현으로 변환

수치·코드는 다음과 같이 서술형으로 바꿔 작성한다.

| 금지 (수치형) | 허용 (서술형) |
|------------|------------|
| Bold 60pt | large bold |
| 720×340px, gap 40px | evenly spaced with moderate gap |
| y=300 | middle area |
| #1E3A8A | navy blue fill |
| 2px #60A5FA border | thin sky blue outline |

### 강화 3: CRITICAL RENDERING RULES 확장 금지 목록

기존 영문 규칙에 다음 명시 금지 항목을 추가한다.

- Pixel dimensions (px, 60×32px)
- Coordinate values (x=, y=)
- Font names and weights (Noto Sans KR, Bold, Regular, SemiBold, pt)
- Hex color codes (#1E3A8A)
- Measurement units (px, pt, %, deg)
- Specification labels (Title:, Card:, Body:, Footer:)
- English words from design spec

### 프롬프트 4섹션 고정 구조 (권장 템플릿)

```
[유형] 인포그래픽 이미지를 16:9 비율로 생성해줘.

ABSOLUTE TEXT RULE
- KOREAN TEXT TO RENDER의 한국어만 화면에 렌더한다.
- 그 외 숫자·측정값·좌표·컬러코드·폰트명·영문 라벨은 내부 지침이며 표시 금지.

KOREAN TEXT TO RENDER (정확히 이 한국어만 렌더)
- 제목: "..."
- 항목1 키워드: "..." / 항목1 부가: "..."
- 항목2 키워드: "..." / 항목2 부가: "..."
- 항목3 키워드: "..." / 항목3 부가: "..."
- 강조 패널 메시지: "..."

VISUAL STYLE (for layout only, not to be shown as text)
- 흰 배경, 매거진 에디토리얼 톤, 한글 산세리프 굵은 느낌
- 베이스 레이아웃: [서술형 — 예: 카드가 가로 3열로 균등 배치]
- 강조 패널: [EP-A/EP-B 서술형 — 예: 하단을 가로로 가득 채우는 진한 네이비 띠, 흰 글자 한 줄]
- 컬러 키: 메인 navy blue, 보조 sky blue, 본문 진한 회색
- 라인 아이콘, 스틱맨 1명, 강조 배지·연결선·데이터 표시 장치 포함
- 카드는 둥근 모서리, 얇은 외곽선, 적당한 여백, 균등 간격

CRITICAL RENDERING RULES (화면 표시 금지)
- 픽셀 수치 (px, 60×32px)
- 좌표 값 (x=, y=)
- 폰트 이름·굵기 (Noto Sans KR, Bold, Regular, pt)
- 헥스 컬러 코드 (#1E3A8A)
- 측정 단위 (px, pt, %, deg)
- 사양 라벨 (Title:, Card:, Body:, Footer:)
- 영문 디자인 사양 단어
- KOREAN TEXT TO RENDER에 없는 한국어·영문·숫자 표시 금지
- 한글 철자는 KOREAN TEXT TO RENDER와 정확히 일치
```

## 타이틀 배치 옵션 3종 (T1·T2·T3)

메인 타이틀 영역과 카드 그리드의 배치 관계를 결정한다. 같은 내용·같은 디자인 격이라도 배치가 달라지면 인상이 크게 달라진다.

### T1. 상단 중앙형 (Top Center)

화면 상단에 메인 타이틀 영역, 그 아래에 카드 그리드 배치.

```
┌─────────────────────────────────────┐
│         ISSUE 01 · LIBRARIAN        │
│      AI 시대 사서의 4가지 새 역할      │
│      ─                              │
│      Librarian Roles in the AI Era  │
│                                     │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌────┐ │
│  │  01  │ │  02  │ │  03  │ │ 04 │ │
│  └──────┘ └──────┘ └──────┘ └────┘ │
└─────────────────────────────────────┘
```

- **타이틀 위치**: 화면 상단 좌측 정렬, 폭 화면의 100% 사용 가능
- **카드 그리드**: 타이틀 아래 2×2 또는 1×4
- **적합 상황**: 본문 슬라이드, 다수 일괄 생성, 안정적 가독성 우선
- **장점**: 가장 안정적, 텍스트 정확도 가장 높음
- **단점**: 시각적 임팩트는 T2·T3보다 약함
- **기본 모드 고정값**

### T2. 좌측 분할형 (Left Split)

화면을 좌우로 분할. 좌측에 메인 타이틀 영역, 우측에 카드 그리드.

```
┌─────────────────────────────────────┐
│ ISSUE 01·LIBRARIAN  │ ┌────┐ ┌────┐ │
│                     │ │ 01 │ │ 02 │ │
│ AI 시대 사서의      │ └────┘ └────┘ │
│ 4가지 새 역할       │              │
│ ─                   │ ┌────┐ ┌────┐ │
│ Librarian Roles     │ │ 03 │ │ 04 │ │
│ in the AI Era       │ └────┘ └────┘ │
└─────────────────────────────────────┘
```

- **타이틀 위치**: 화면 좌측 절반(약 40%), 세로 중앙 정렬
- **카드 그리드**: 화면 우측 절반(약 60%), 2×2
- **적합 상황**: 챕터 구분 슬라이드, 표지, 매거진 인덱스 페이지 느낌
- **장점**: 매거진급 격조, 시각적 임팩트 강함
- **단점**: 카드가 약간 좁아짐, 일러스트 디테일 작아짐
- **프리미엄 모드 기본값**

### T3. 좌측 사이드바형 (Left Sidebar)

화면 좌측에 좁은 사이드바로 메인 타이틀, 우측 넓은 영역에 카드 그리드.

```
┌─────────────────────────────────────┐
│ ISSUE  │                            │
│  01    │ ┌──────┐ ┌──────┐         │
│        │ │  01  │ │  02  │         │
│ 사서의 │ └──────┘ └──────┘         │
│ 새 역할│                            │
│        │ ┌──────┐ ┌──────┐         │
│ ─      │ │  03  │ │  04  │         │
│        │ └──────┘ └──────┘         │
└─────────────────────────────────────┘
```

- **타이틀 위치**: 화면 좌측 사이드바(약 25%), 세로 정렬, 한글 타이틀이 세로 또는 좁은 폭으로 줄바꿈
- **카드 그리드**: 화면 우측(약 75%), 2×2
- **적합 상황**: 잡지 표지 느낌, 강의 시리즈 통합 표지
- **장점**: 가장 강한 매거진 표지 인상
- **단점**: 한글 타이틀이 좁아져서 줄바꿈 처리 필요, 텍스트 가독성 가장 낮음
- **프리미엄 모드 선택 옵션**

### 배치 자동 추천 로직

사용자가 배치를 지정하지 않은 경우 다음 기준으로 자동 추천한다.

| 슬라이드 종류 | 추천 배치 | 모드 |
|------------|----------|------|
| 본문 슬라이드 (다수) | T1 상단 중앙형 | 기본 모드 |
| 챕터 구분·섹션 표지 | T2 좌측 분할형 | 프리미엄 모드 |
| 강의 전체 표지·시리즈 표지 | T3 좌측 사이드바형 | 프리미엄 모드 |
| 마무리 정리 슬라이드 | T2 좌측 분할형 | 프리미엄 모드 |
| 미명시 + 기본 모드 | T1 고정 | 기본 모드 |
| 미명시 + 프리미엄 모드 | T2 기본값 | 프리미엄 모드 |

## 폰트 시스템 (Google Fonts Noto Sans KR)

이 스킬의 모든 한글 텍스트는 **Google Fonts의 Noto Sans KR**을 사용한다. 단, 폰트 이름·굵기·크기 표기를 **이미지 안에 텍스트로 노출하지 않는다.** 프롬프트의 디자인 사양 섹션에만 명시하고, 콘텐츠 섹션에는 절대 포함하지 않는다.

### 폰트 굵기 4단계 (타이포 위계 구현용)

영문 요소가 모두 제거되어 위계가 단순해졌다.

| 굵기 | 사용처 |
|------|--------|
| Light | 인덱스 숫자 (01·02·03·04) |
| Regular | 한글 캡션·본문 |
| SemiBold | 카드 한글 타이틀 |
| Bold | 메인 타이틀 |

### 폰트 사양 표기 원칙

프롬프트에서 폰트를 명시할 때:

- ✅ **디자인 사양 섹션에만** 명시 (이미지에 표시 안 됨)
- ❌ 콘텐츠 섹션에 절대 포함 금지
- ❌ "Noto Sans KR Bold 52pt" 같은 구체 사양을 콘텐츠 섹션에 적지 말 것
- ✅ 콘텐츠 섹션에는 **"한글 타이틀: 맞춤 큐레이션"**처럼 텍스트만 적는다

## 디자인 사양 통합 (양 모드 공통)

기본 모드와 프리미엄 모드에 공통으로 적용되는 디자인 사양이다. **이 사양들은 모두 디자인 지시이며, 이미지에 텍스트로 노출되지 않는다.** 프롬프트 작성 시 "큰", "작은", "얇은" 등 상대적 표현으로 전달한다.

### 메인 타이틀 영역

| 요소 | 설명 |
|------|------|
| 메인 타이틀 (한글) | 큰 크기, Bold 굵기, 검정 |
| 매거진 헤더 | **없음** (제거됨) |
| 영문 부제 | **없음** (제거됨) |
| 장식 라인 | **없음** (제거됨) |

### 카드 내부 6단 구조 (모든 카드 동일)

수직으로 정확히 정렬되는 6단 구조. 영문 서브타이틀이 제거되어 7단 → 6단으로 단순화됨.

1. **인덱스 숫자** — 작은 크기, 보조 컬러 (예: "01")
2. **한글 카드 타이틀** — 중간 크기, SemiBold 굵기, 메인 컬러
3. **구분선** — 짧은 가로 선, 메인 컬러
4. **일러스트 영역** — 옅은 원형 배경 + 스틱맨 1명(굵은 선) + 보조 요소 2~3개(얇은 선)
5. **한글 캡션** — 작은 크기, Regular 굵기, 그레이
6. **푸터 라인** — 카드 하단, 짧은 가로 선, 매우 얇은 그레이

### 카드 컨테이너 사양

| 항목 | 값 |
|------|-----|
| 모서리 | 부드러운 라운드 |
| 테두리 | 매우 얇은 헤어라인 그레이 |
| 그림자 | 매우 미세 (barely visible) |
| 내부 패딩 | 충분히 (breathing room) |
| 카드 간 간격 | 넓게 |
| 외곽 여백 | 넓게 (generous white space) |
| 배경 | 순백 |

### 일러스트 통일 원칙

모든 카드의 일러스트는 다음 규칙을 따른다.

- 메인 스틱맨: 1명, 굵은 선, 메인 컬러
- 보조 요소: 2~3개 (책·노트북·아이콘·작은 보조 스틱맨 등), 얇은 선
- 배경: 옅은 원형 (업체 컬러 키 매칭), barely visible
- 모든 카드 동일 시각 밀도

### 색상 시스템

업체 컬러 키 기반.

| 역할 | 색상 출처 | 사용처 |
|------|---------|--------|

### 필수 영문 스타일 키워드


## 텍스트 규칙 통합표

나노바나나 프로는 한글 렌더링이 가능하지만, 글자 수가 많으면 오탈자·깨짐이 발생할 수 있다. 아래 기준을 일관 적용한다.

| 요소 | 글자 수 기준 | 비고 |
|------|-------------|------|
| 슬라이드 제목 | 12자 이내 | 상단 제목 영역 |
| 항목 키워드 | 8자 이내 (최대 12자) | 카드·단계·가지의 메인 레이블 |
| 부가 설명 | 15자 이내 | 아이콘 옆 또는 카드 내 한 줄 설명 |
| 불릿 설명 (장면형) | 25자 이내 | 장면형 카드 하단 불릿 포인트 |
| 하위 태그 | 6자 이내 | 키워드 아래 보조 태그 |
| 전체 항목 수 | 6개 이내 | 카드·단계·가지 등 메인 요소 |

**추가 규칙**:
- 키워드 중심: 문장이 아닌 명사·동사 키워드로 압축
- 영문 병기 고려: 핵심 용어는 한글(영문) 병기하면 렌더링 안정성 향상
- 생성 후 한글 확인 필수
