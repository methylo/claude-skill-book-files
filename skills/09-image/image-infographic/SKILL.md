# 나노바나나 인포그래픽 프롬프트 생성 스킬

강의 원고·교안의 본문 텍스트를 나노바나나 프로(Gemini 3 Pro Image)용 **슬라이드 1장 인포그래픽** 이미지 프롬프트로 변환하는 스킬이다.

**핵심 흐름**: 원고 텍스트 입력 → 핵심 추출·압축 → 유형×스타일 판단 → 슬라이드 1장 프롬프트 출력

나노바나나 프로는 고급 추론 기능으로 사실 정보 기반 인포그래픽을 직접 생성하는 데 강점이 있다. 프롬프트에 "인포그래픽"을 반드시 포함하고, 구도·배치 방향 중심으로 지시하면 가장 좋은 결과를 얻을 수 있다.

**참조 파일 안내**:
- `style-templates.md` — 스타일 A~F별 상세 템플릿 (유형별 변형 포함)
- `examples.md` — 스타일별 실전 예시 (원고→추출→프롬프트 변환)

프롬프트를 작성하기 전에 반드시 해당 스타일의 템플릿과 예시를 참조한다.

## 시각 스타일 기본값 (모든 유형·스타일 공통)

모든 프롬프트에 아래 시각 규칙을 반드시 포함한다.

| 항목 | 기본값 |
|------|--------|
| 배경 | #FFFFFF (Solid pure white, flat color, no shadows) |
| 폰트 | Google Fonts Noto Sans KR (모든 한글·영문 텍스트 통일) |
| 캐릭터 | 스틱맨(stickman) — 필요할 때만 사용 |
| 화면 비율 | 16:9 가로형 |
| 스타일 | 매거진급 에디토리얼 디자인, 미니멀 럭셔리 |
| 색상 체계 | 업체 컬러 키 4단 명도 + 그레이 보조 + 헤어라인 |

> **사이즈 지정**: 나노바나나 프로는 픽셀이 아닌 **비율**로 지정한다. 프롬프트에 `가로세로 비율 16:9`로 명시. 필요시 `4:3`, `1:1`, `9:16(세로형)` 등으로 변경 가능.

## 출력 모드 2종

이 스킬은 두 가지 출력 모드를 지원한다. **두 모드 모두 매거진급 에디토리얼 디자인을 기본으로 한다.** 차이는 타이틀 배치 옵션의 자유도에만 있다.

### 모드 1. 기본 모드 (Standard Editorial)

매거진급 디자인 + **T1 상단 중앙 배치 고정**. 빠른 생성과 일관성이 우선되는 상황에 적합.

- 한글 메인 타이틀 (영문 부제·매거진 헤더·장식 라인 없음)
- 카드 내부 6단 구조 (인덱스·한글타이틀·구분선·일러스트·캡션·푸터)
- 카드 모서리 20px, 패딩 40px, 외곽 여백 100px
- 일러스트 뒤 옅은 원형 배경
- **타이틀 배치는 T1 상단 중앙 고정**

**활성화 조건**: 별도 지정 없을 때 기본값. 다수 슬라이드 일괄 생성·강의 슬라이드 본문·내부 자료에 적합.

### 모드 2. 프리미엄 에디토리얼 모드 (Premium Editorial)

기본 모드와 **동일한 디자인 격** + 타이틀 배치를 사용자가 선택 가능. 표지·챕터 구분·발표 자료처럼 시각적 임팩트가 필요한 슬라이드에 적합.

- 기본 모드의 모든 디자인 사양 그대로 유지
- **타이틀 배치 3종 중 선택**: T1 상단 중앙형 / T2 좌측 분할형 / T3 좌측 사이드바형
- 타이틀 미지정 시 기본값은 T2 좌측 분할형

**활성화 조건** (다음 중 하나라도 충족 시 자동 활성화):
- 사용자가 "프리미엄", "고급스럽게", "에디토리얼", "매거진", "고급 디자인", "발표용", "공식 자료" 등을 언급
- "표지", "챕터 구분", "섹션 표지", "타이틀 슬라이드" 등 고임팩트 슬라이드 명시
- 사용자가 T1·T2·T3 배치를 직접 지정

기본 모드와 프리미엄 모드는 **컬러 키·레이아웃·시각 장치·디자인 사양을 모두 공유**한다. 차이는 타이틀 배치 선택 자유도에만 있다.

## 인포그래픽 유형 3가지

### 1. 요약형 (Summary)

하나의 소주제를 핵심 포인트 3~5개로 압축해 한눈에 보여준다.

- 상단: 제목(소주제명)
- 중앙: 핵심 포인트를 아이콘+키워드로 배치
- 적합한 원고: 개념 설명, 원칙·팁 나열, 특징 정리

### 2. 구조형 (Structure)

요소 간 관계·위계·비교를 시각적 구조로 표현한다.

- 상단: 제목
- 중앙: 비교표·매트릭스·계층 다이어그램·관계도
- 적합한 원고: 개념 비교, 분류 체계, 프레임워크 설명, 장단점 대비

### 3. 프로세스형 (Process)

순서가 있는 단계·흐름을 시각적으로 표현한다.

- 상단: 제목
- 중앙: 좌→우 단계 흐름, 화살표 연결
- 적합한 원고: 절차 안내, 워크플로우, 단계별 가이드, 실습 순서

---

## 레이아웃 모듈 5종

유형(요약형·구조형·프로세스형)과 별개로, **레이아웃 모듈**을 선택한다. 같은 유형이라도 레이아웃에 따라 완전히 다른 인상의 인포그래픽이 나온다. 기존 "시각화 스타일 6가지"는 레이아웃 모듈 5종 안에 재분류되었다.

| 레이아웃 | 구도 설명 | 적합한 원고 | 흡수한 기존 스타일 |
|---------|----------|------------|-------------------|
| L1. 중앙 집중형 | 화면 중앙에 핵심 1개 + 주변 보조 요소 | 핵심 정의, 단일 메시지 강조 | 요약형 핵심 강조 |
| L2. 좌우 2분할 | 중앙 구분선, 좌우 대비 구조 | 장단점, Before/After, A vs B | 비교형 |
| L3. 카드 그리드 2×2 | 4개 동등 카드 병렬 | 특징 4개, 사례 4개, 장점 4개 | 다이어그램형 일부, 요약형 일부 |
| L4. 가로 타임라인 | 화면 가로축 위 단계·이벤트 배치 | 프로세스, 로드맵, 발전 과정 | 타임라인형, 프로세스 다이어그램 |
| L5. 방사형 (허브-스포크) | 중심 개념에서 방사형 확산 | 생태계, 관계도, 파생 요소 | 마인드맵형, 다이어그램형 일부 |

**데이터형**(숫자·통계 전면 배치)은 별도 레이아웃이 아닌 **시각 장치**로 재분류되었다. 5종 레이아웃 어디에든 "강조 숫자 배지"로 얹어 사용한다.

**장면형**(스틱맨 상황 연기)은 5종 모두의 **기본 표현 방식**으로 통합되었다. 모든 레이아웃에서 스틱맨이 상황을 연기하는 것을 기본으로 한다.

## 레이아웃 자동 추천 로직

상세 기준은 `references/layout-guide.md`의 같은 이름 절에 있다. 레이아웃과 컬러를 고를 때 읽는다.

## 프롬프트 생성 워크플로우

### 기본 동작 모드

**기본값은 "한 번에 출력"이다.** 추출 결과 + 레이아웃 추천 2~3개 + 각 프롬프트를 한 번의 응답에 모두 제공한다. 사용자가 "단계별로 확인하면서 진행해줘" 또는 "추출 결과 먼저 보여줘"라고 요청할 때만 단계를 분리한다.

### Step 1: 원고 텍스트 + 업체 정보 수신

사용자가 단락·소주제 단위(수백 자)의 강의 원고 또는 교안 텍스트를 입력한다.

확인할 사항:
- **원고 텍스트**: 시각화할 본문 (필수)
- **업체명 또는 업체 성격**: 업체 컬러 키 매칭용 (권장 — 미지정 시 기본값 네이비 적용)
- **출력 모드**: 기본 모드 / 프리미엄 에디토리얼 모드 (선택 — 미지정 시 기본 모드, 키워드 감지 시 자동 전환)
- **유형 지정**: 요약형·구조형·프로세스형 중 택1 (선택 — 미지정 시 자동 판단)
- **레이아웃 지정**: L1~L5 중 택1 (선택 — 미지정 시 자동 추천)
- **컬러 키 지정**: 프리셋 이름 또는 커스텀 헥스코드 (선택 — 미지정 시 업체 성격 자동 매칭)
- **추가 요청**: 캐릭터 수, 비율 변경, 강조 포인트 등 (선택)

**업체 정보가 이전 대화에 이미 언급되었다면 재질문하지 않고 그대로 사용한다.**

**프리미엄 모드 자동 활성화 키워드**: "프리미엄", "고급스럽게", "에디토리얼", "매거진", "고급 디자인", "발표용", "공식 자료", "퀄리티 올려줘", "디자인 개선", "다시 만들어줘 + 고급" 등이 입력에 포함되면 자동으로 프리미엄 모드 전환.

### Step 2: 핵심 추출·압축

원고에서 슬라이드 1장에 담을 핵심을 추출한다. 이 단계가 스킬의 핵심이다.

**추출 규칙**:
1. 원고의 **중심 주장·핵심 메시지**를 1문장으로 파악한다
2. 이를 뒷받침하는 **하위 포인트 3~5개**를 추출한다
3. 각 포인트를 **한글 8자 이내 키워드**로 압축한다
4. 슬라이드 제목을 **12자 이내**로 만든다

**압축 전략**:
- 원고에 나열된 항목이 있으면 → 그대로 키워드화
- 원고가 설명 중심이면 → 핵심 개념어 추출
- 원고에 순서·절차가 있으면 → 단계별로 분리
- 원고에 비교·대비가 있으면 → 비교 축 추출

### Step 3: 유형·레이아웃·컬러 키·시각 장치 판단

사용자가 지정하지 않은 항목은 추출된 내용의 성격으로 자동 판단한다.

**3-1. 유형 판단**

| 원고 내용의 성격 | 판단 유형 |
|-----------------|----------|
| 핵심 포인트·원칙·팁 나열 | 요약형 |
| 개념 비교, 분류, 관계 설명 | 구조형 |
| 절차, 단계, 흐름, 순서 | 프로세스형 |

**3-2. 레이아웃 판단**

위 "레이아웃 자동 추천 로직"에 따라 2~3개를 추천한다. 단일 핵심 메시지는 L1 중앙 집중형을 우선 추천한다.

**3-3. 컬러 키 판단**

업체명이 입력된 경우:
- "경희사이버대학교", "안산교육지원청", "ㅇㅇ대학교", "ㅇㅇ학교" → 교육기관 (네이비+스카이블루)
- "서울경제진흥원", "ㅇㅇ진흥원", "ㅇㅇ시청", "ㅇㅇ교육청" → 공공기관 (딥그린+라이트그린)
- "와치텍", "ㅇㅇ테크", "ㅇㅇ소프트", IT 관련 키워드 → IT·테크 (차콜+오렌지)
- "하일렌요양병원", "ㅇㅇ병원", "ㅇㅇ클리닉" → 의료 (틸+민트)
- "ㅇㅇ스튜디오", "ㅇㅇ크리에이티브", 디자인·광고 관련 → 스타트업·크리에이티브 (퍼플+핑크)
- "ㅇㅇ증권", "ㅇㅇ은행", "ㅇㅇ컨설팅" → 금융·컨설팅 (다크블루+골드)
- 매칭 불가 또는 미입력 → 기본값 (네이비+스카이블루)

**3-4. 시각 장치 판단**

| 원고 신호 | 추천 장치 |
|----------|----------|
| 숫자·퍼센트·수치 포함 | 데이터 표시 |
| 핵심 키워드 3개 이하 | 강조 배지 |
| 요소 간 관계·흐름 중요 | 연결선·화살표 |
| 위 신호 중복 | 장치 2개까지 조합 허용 |

### Step 4: 프롬프트 작성

한국어 프롬프트를 작성한다. **이미지에 표시할 한글 텍스트와 디자인 사양을 반드시 별도 섹션으로 분리**한다.

#### 4-A. 프롬프트 표준 구조

모든 프롬프트는 아래 4개 섹션으로 구성한다.

```
[섹션 1] 제목 한 줄 — 유형·레이아웃·디자인 톤
[섹션 2] 이미지에 표시할 한글 텍스트 (모든 카드별)
[섹션 3] 디자인 사양 (이미지에 표시 금지)
[섹션 4] CRITICAL RENDERING RULES (영문 강제 규칙)
```

#### 4-B. 공통 디자인 사양 (기본·프리미엄 공통)

섹션 3에 들어갈 디자인 사양 템플릿이다. **이 사양은 절대 이미지에 텍스트로 들어가서는 안 된다.**

```
[섹션 3 — 디자인 사양 (이미지에 표시 금지)]

전체 레이아웃:
- 외곽 여백 generous, 카드 간 간격 넓게, 카드 내부 패딩 충분히
- 카드 모서리 부드럽게 라운드
- 카드 테두리 매우 얇은 헤어라인 그레이
- 카드 그림자 매우 미세하게 (barely visible)
- 카드 배경 순백
- 모든 카드 동일한 크기·동일한 시각 밀도

메인 타이틀 영역:
- 화면 상단 좌측 정렬 (T1) 또는 좌측 영역 (T2·T3)
- 큰 한글 타이틀 (Bold 굵기, 검정)
- 매거진 헤더·영문 부제·장식 라인 없음

카드 내부 6단 구조 (모든 카드 동일):
1. 좌측 상단 인덱스 숫자 (작은 크기, 보조 컬러)
2. 한글 카드 타이틀 (중간 크기, SemiBold, 메인 컬러)
3. 짧은 가로 구분선 (메인 컬러)
4. 일러스트 (옅은 원형 배경 위에 스틱맨 1명 + 보조 요소 2~3개)
5. 한글 캡션 (작은 크기, 그레이)
6. 카드 하단 짧은 푸터 라인 (얇은 그레이)

색상:
- 메인 컬러: [업체 컬러 키 메인 색상] — 메인 타이틀·스틱맨·구분선·카드 타이틀에 적용
- 보조 컬러: [업체 컬러 키 보조 색상] — 인덱스 숫자에 적용
- 일러스트 배경: [매칭 옅은 톤] — 스틱맨 뒤 원형 배경
- 그레이: 캡션·헤어라인 테두리·푸터 라인
- 본문: 검정
- 배경: 순백

폰트:
- 모든 한글 텍스트는 Google Fonts Noto Sans KR
- 굵기 위계: 메인 타이틀 Bold, 카드 타이틀 SemiBold, 캡션 Regular, 인덱스 Light

일러스트 통일 원칙:
- 모든 카드에 스틱맨 1명 (굵은 선) + 보조 요소 2~3개 (얇은 선)
- 일러스트 뒤에 옅은 원형 배경
- 모든 카드 동일한 시각 밀도

스타일 키워드:
premium editorial design, minimal luxury, swiss design influence,
magazine layout, perfect grid alignment, generous white space,
refined typography hierarchy, hairline borders, subtle depth,
sophisticated minimalism, breathing room, restraint,
museum quality, elegant restraint

가로세로 비율: 16:9
```

**핵심**: 픽셀 수치(60px, 100px 등)나 폰트 사양(52pt, Light 등)을 프롬프트에 적지 않는다. "큰", "작은", "얇은", "굵은", "충분한", "미세한" 같은 **상대적 표현**으로 대체한다.

#### 4-C. 모드별 타이틀 배치 분기

**기본 모드 (T1 상단 중앙형 고정)**

섹션 3에 다음을 추가한다.

```
타이틀 배치 — T1 상단 중앙형:
- 메인 타이틀을 화면 상단 좌측 정렬
- 카드 그리드는 타이틀 아래 배치
- 타이틀과 카드 사이 간격 충분히
```

**프리미엄 모드 (T1·T2·T3 선택)**

T2 좌측 분할형:
```
타이틀 배치 — T2 좌측 분할형:
- 화면을 좌우로 분할
- 좌측 영역(약 40%): 메인 타이틀 영역, 세로 중앙 정렬
- 우측 영역(약 60%): 카드 그리드
```

T3 좌측 사이드바형:
```
타이틀 배치 — T3 좌측 사이드바형:
- 좌측 사이드바(약 25%): 한글 메인 타이틀 (좁은 폭 줄바꿈 허용)
- 우측 영역(약 75%): 카드 그리드
- 좌우 사이에 얇은 세로 구분선
```

#### 4-D. 프롬프트 작성 예시 (참고용)

```
요약형 카드 그리드 2×2 인포그래픽 이미지를 생성해줘.
프리미엄 에디토리얼 디자인, 미니멀 럭셔리, 스위스 디자인.

[섹션 2 — 이미지에 표시할 한글 텍스트]

메인 타이틀: AI 시대 사서의 4가지 새 역할

카드 1 (좌상단):
- 인덱스 숫자: 01
- 한글 타이틀: 맞춤 큐레이션
- 한글 캡션: 이용자별 독서 취향 분석

카드 2 (우상단):
- 인덱스 숫자: 02
- 한글 타이틀: 정보 리터러시
- 한글 캡션: AI 시대 정보 판별 교육

카드 3 (좌하단):
- 인덱스 숫자: 03
- 한글 타이틀: 디지털 큐레이팅
- 한글 캡션: 전자자료 선별과 관리

카드 4 (우하단):
- 인덱스 숫자: 04
- 한글 타이틀: AI 협력
- 한글 캡션: AI를 도구로 활용

[섹션 3 — 디자인 사양 (이미지에 표시 금지)]

(위 4-B의 공통 디자인 사양 블록 + 4-C의 타이틀 배치 블록 그대로 삽입)

색상 적용:
- 메인 컬러: 딥그린 (공공기관 컬러 키)
- 보조 컬러: 라이트그린
- 일러스트 배경: 매우 옅은 그린

카드별 일러스트:
- 카드 1: 스틱맨이 작은 책을 다른 작은 스틱맨에게 건네는 모습 + 위에 작은 하트 아이콘
- 카드 2: 스틱맨이 작은 칠판 앞에 서 있고, 앞에 작은 청중 스틱맨 2명
- 카드 3: 스틱맨이 노트북을 보고 있고, 위에 작은 클라우드 + 옆에 작은 책 아이콘
- 카드 4: 스틱맨이 작은 AI 로봇과 손을 맞잡은 모습 + 위에 작은 톱니바퀴 아이콘

[섹션 4 — CRITICAL RENDERING RULES — DO NOT VIOLATE]

- Do NOT render any pixel size notations (60px, 3px, 40px, 100px, etc.) as visible text.
- Do NOT render any font specifications (Bold, Light, SemiBold, Regular, 14pt, 18pt, 52pt, etc.) as visible text.
- Do NOT render any hex color codes (#065F46, #6B7280, #E5E7EB, etc.) as visible text.
- Do NOT render any font names (Noto Sans KR, Google Fonts, etc.) as visible text.
- Do NOT render English magazine headers like "ISSUE 01 · OOO".
- Do NOT render English subtitles below the main title.
- Do NOT render English card subtitles (Plan, Research, etc.).
- Do NOT render layout descriptions or measurement guides.
- Only render Korean text that is explicitly listed under "이미지에 표시할 한글 텍스트" sections.
- Numbers like "01", "02" are allowed only for card indexes.
```

#### 4-E. 모드별 사용 지침

| 항목 | 기본 모드 (T1 고정) | 프리미엄 모드 (T1·T2·T3 선택) |
|------|-------------------|---------------------------|
| **언제** | 본문 슬라이드 다수, 빠른 일괄 생성 | 표지·챕터 구분·발표용 |
| **타이틀 배치** | T1 상단 중앙 고정 | T1·T2·T3 선택 (기본 T2) |
| **디자인 격** | 매거진급 에디토리얼 | 매거진급 에디토리얼 (동일) |
| **결과 안정성** | 높음 | 중간 |
| **재생성 권장 횟수** | 1~2회 | 2~3회 |

**원칙**: 사용자가 모드를 명시하지 않으면 **기본 모드(T1)로 시작**한다.

### Step 5: 출력

**레이아웃 미지정 시** (기본 동작): 추출 결과 + 3개 추천(강조 패널 변형 우선) + 각 프롬프트를 한 번에 출력한다.

```
[추출 결과]
- 제목: OOO
- 유형: OO형
- 핵심 포인트: ...
- 업체 컬러 키: OO (메인 #XXXXXX + 보조 #XXXXXX)
- 시각 장치: OO
- 핵심 메시지 한 줄: OOOOOOOOOOOOOO (15~22자)

[레이아웃 추천 — 3개 프롬프트 동시 제공]

추천1: EP-A 컴팩트 + 하단 강조 패널 (베이스: L? OO형) — 이유 설명
(프롬프트 코드블록)

추천2: EP-B 좌측 본문 + 우측 사이드 강조 (베이스: L? OO형) — 이유 설명
(프롬프트 코드블록)

추천3: 표준 L? OO형 단독 — 이유 설명 (시리즈 일관성용)
(프롬프트 코드블록)
```

**레이아웃 지정 시**: 해당 레이아웃 프롬프트 1개만 출력한다.

**배치 생성 시** (lecture-slides 04-image-list.md 입력): 슬라이드 번호 순서대로 각 슬라이드의 레이아웃·프롬프트를 테이블 형식으로 출력한다. 업체 컬러 키는 전체에 통일 적용, 레이아웃은 연속 3회 반복 방지 규칙 적용.

프롬프트 출력 후 반드시 안내:
- "생성된 이미지에서 한글 텍스트가 정확한지 확인하세요. 오류 시 해당 텍스트만 수정 요청하거나 새로 생성하는 것이 낫습니다."
- 수정 가능 항목: 색상, 항목 추가/삭제, 스타일 전환, 비율 변경 등
