# 나노바나나 프로 생성 가이드 (tool-guide.md)

Step 4(프롬프트 구조화)에서 참조한다. 나노바나나 프로(Gemini) 기준 프롬프트 입력 방법과 생성 워크플로우를 포함한다.

---

## 나노바나나 프로 프롬프트 입력 규칙

- 6블록 전체를 **한글 자연어 대화체**로 입력한다
- 역할 지정(블록 1) 유효 — "당신은 출판 전문 북커버 디자이너입니다"로 시작
- 제목·부제·저자명을 프롬프트에 포함하여 이미지에 함께 생성한다
- HEX 코드를 색감 블록에 명시하면 색상 정확도가 높아진다

---

## 텍스트 적용 가이드

나노바나나 프로는 한글 텍스트를 이미지에 직접 생성할 수 있다. 다음 규칙을 따른다:

| 항목 | 규칙 | 예시 |
|------|------|------|
| 제목 | 정확한 한글로 명시 + 폰트 스타일 지시 | "제목 'AI와 함께 일하는 법'을 상단에 굵은 고딕체로 배치" |
| 부제 | 제목보다 작은 크기로 지시 | "부제 '20년차 전문가의 현장 기록'을 제목 아래에 작은 크기로" |
| 저자명 | 하단 배치 지시 | "저자명 '홍길동'을 하단에 배치" |
| 폰트 스타일 | 구체적으로 지시 | "세리프체" / "굵은 고딕체" / "손글씨 느낌" |
| 색상 | 배경과 대비되는 색 지시 | "제목은 흰색으로, 저자명은 골드로" |

**텍스트 보정 필요 시:**
- 생성 결과에서 한글이 깨지거나 부정확하면 편집 도구(캔바, 미리캔버스 등)에서 보정한다
- 이미지 전체 분위기가 맞으면 텍스트만 교체하는 방식이 효율적이다

---

## 생성 워크플로우

```
1. 간편 테스트 프롬프트로 방향 확인 (3~5장)
2. 방향이 맞으면 6블록 풀 프롬프트로 정밀 생성 (10~15장)
3. 3~5장 선별 → Step 5로 이동
4. 필요시 블록 단위로 프롬프트 수정 후 재생성
5. 3회 재생성 후에도 안 맞으면 → 콘셉트 변경 (Step 3으로 복귀)
```

### 생성 팁

| 항목 | 가이드 |
|------|-------|
| 권장 생성 수량 | 간편 테스트 3~5장 → 풀 버전 10~15장 |
| 반복 생성 | "다시 생성" 버튼으로 동일 프롬프트 반복 |
| 변형 생성 | 색감 또는 구도 1가지만 변경하여 비교 |
| 텍스트 확인 | 생성 직후 제목·저자명 한글 정확도 확인 |
| 스타일 고정 | 마음에 드는 결과가 나오면 해당 프롬프트를 기준으로 미세 조정 |

### 프롬프트 수정 원칙
- 전체 재작성이 아니라 **블록 단위**로 수정한다
- 한 번에 1~2개 블록만 변경하여 변화를 추적한다
- 색감 변경 시 HEX 코드를 함께 수정한다
- 구도 변경 시 키 비주얼 체크리스트 7항목을 다시 점검한다
