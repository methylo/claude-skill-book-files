# 프롬프트 템플릿 (prompt-templates.md)

Step 4(프롬프트 구조화)에서 참조한다. 나노바나나 프로(Gemini) 기준 6블록 프레임워크의 블록별 작성 규칙, 장르별 템플릿을 포함한다.

---

## 6블록 프레임워크 — 블록별 작성 규칙

나노바나나 프로(Gemini)용 한글 자연어 대화체 형식이다.

### [블록 1] 역할 지정 + 책 정보

```
당신은 출판 전문 북커버 디자이너입니다.
아래 조건에 맞는 {전자책/종이책} 표지 이미지를 만들어주세요.

[책 정보]
 - 제목: {제목}
 - 부제: {부제}
 - 저자: {저자명}
 - 출판사: {출판사명}
 - 장르: {장르} — {1줄 설명}
```

### [블록 2] 분위기 — 필수
- Step 1의 톤에서 추출한 형용사 2~3개
- 서로 모순되지 않는 조합
- "~이 아닌" 부정형 표현도 유효 (예: "기술 서적의 차가움이 아니라")
- 장르별 형용사 조합은 `genre-patterns.md` 참조

### [블록 3] 색감 — 필수
- 주조색(Primary) 1개 + 보조색(Secondary) 1개 + 배경색, 총 3색을 HEX 코드로 명시
- `genre-patterns.md`의 3색 조합 세트에서 선택하거나 변형

### [블록 4] 구도 — 필수
- 키 비주얼의 위치, 크기, 구성 요소를 구체적으로 지시
- **SKILL.md의 키 비주얼 묘사 체크리스트 7항목**(오브젝트, 개수·관계, 크기·비율, 위치, 시선 방향, 디테일 수준, 질감)을 반드시 반영
- 텍스트(제목·부제·저자명) 배치 위치를 명시 ("상단 1/3에 제목", "하단에 저자명" 등)
- 구도 유형은 `genre-patterns.md` 참조

### [블록 5] 스타일
- 미니멀 라인 드로잉 / 플랫 디자인 / 수채화 / 사실적 사진 / 벡터 / 추상 등
- 원고 톤과 일치하는 스타일 선택
- "아날로그 + 디지털" 같은 혼합 스타일도 가능

### [블록 6] 출력 조건 + 텍스트 적용

필수 사항:

| 항목 | 이유 | 프롬프트 문구 |
|------|------|----------|
| 텍스트 포함 | 표지에 제목·부제·저자명 직접 생성 | "제목 '{제목}'을 상단에, 부제 '{부제}'를 제목 아래에, 저자명 '{저자명}'을 하단에 배치할 것" |
| 비율 지정 | 표지 규격 | `font-typography-guide.md` 비율 테이블 참조 |
| 배경 단순화 | 제목 가독성 | "배경은 단색 또는 그라데이션" |
| 해상도 | 인쇄 품질 | "고해상도로 생성" |
| 금지 요소 | 의도 이탈 방지 | "로봇/회로판/네온 사용하지 말 것" (필요시) |

**텍스트 적용 시 주의사항:**
- 제목·부제·저자명을 정확한 한글로 프롬프트에 명시한다
- 폰트 스타일 지시를 함께 넣는다 (예: "굵은 고딕체로", "세리프체로")
- 생성 결과에서 한글이 부정확하면 편집 도구(캔바, 미리캔버스 등)에서 보정한다

비율을 지정하지 않으면 종이책 기준 2:3으로 작성한다.

## 장르별 프롬프트 템플릿

### 템플릿 A: 실용서/비즈니스

```
당신은 출판 전문 북커버 디자이너입니다.
아래 조건에 맞는 전자책 표지 이미지를 만들어주세요.

[책 정보]
 - 제목: {제목}
 - 부제: {부제}
 - 저자: {저자명}
 - 출판사: {출판사명}

[장르] 실용서 / {분야}
[분위기] 전문적이면서 친근한, 깔끔하고 현대적인
[색감] 파란색(#3366CC)과 {보조색} 대비, 흰색(#FFFFFF) 기반
[구도] 중앙 집중형. {키 비주얼 설명 — 오브젝트, 크기 비율, 위치, 디테일 수준 명시}.
       상단 1/3에 제목 "{제목}" 배치 (굵은 고딕체), 하단에 저자명 "{저자명}" 배치.
[스타일] 미니멀 플랫 디자인, 벡터 일러스트 느낌
[조건]
 - 제목, 부제, 저자명을 표지 이미지에 포함할 것
 - 세로형 비율 (2:3)
 - 배경은 단색
 - 고해상도로 생성
```

### 템플릿 B: 경험서/에세이

```
당신은 출판 전문 북커버 디자이너입니다.
아래 조건에 맞는 책 표지 이미지를 만들어주세요.

[책 정보]
 - 제목: {제목}
 - 부제: {부제}
 - 저자: {저자명}
 - 출판사: {출판사명}
 - 장르: {경험서/에세이} — {1줄 설명}

[분위기] 담담하고 진솔한, {추가 형용사}
[색감] {주조색}과 {보조색}, {배경색} 기반
[구도] 미니멀형. 넓은 여백.
       {키 비주얼 설명 — 오브젝트, 크기 비율, 위치, 디테일 수준, 질감 명시}.
       상단 1/3에 제목 "{제목}" 배치 (세리프체), 하단에 저자명 "{저자명}" 배치.
[스타일] 미니멀 라인 드로잉 / {추가 스타일}
[조건]
 - 제목, 부제, 저자명을 표지 이미지에 포함할 것
 - 세로형 비율 (2:3)
 - 고해상도로 생성
 - {금지 요소}
```

### 템플릿 C: IT/테크 + 에세이 교차 (디지털 감성 혼합)

```
당신은 출판 전문 북커버 디자이너입니다.
아래 조건에 맞는 책 표지 이미지를 만들어주세요.

[책 정보]
 - 제목: {제목}
 - 부제: {부제}
 - 저자: {저자명}
 - 출판사: {출판사명}
 - 장르: {경험서} — {1줄 설명}

[분위기] 담담하면서도 현대적인. 아날로그 감성과 디지털 감각이 공존하는.
[색감] 배경: {따뜻한 색} / 아날로그 요소: {네이비 등} / 디지털 요소: {블루 계열}
       접점: {앰버 등 포인트색}
[구도] {구도 유형}.
       아날로그 요소(사람/도구)와 디지털 요소(노드/빛/데이터)가
       한 화면에 공존하는 구성.
       {키 비주얼 세부 — 오브젝트별 위치·크기·관계·디테일 수준 명시}
       상단 1/3에 제목 "{제목}" 배치 (굵은 산세리프체), 하단에 저자명 "{저자명}" 배치.
[스타일] 미니멀 라인 드로잉(아날로그) + 디지털 요소 오버레이
[조건]
 - 제목, 부제, 저자명을 표지 이미지에 포함할 것
 - 세로형 비율 (2:3)
 - 고해상도로 생성
 - 로봇, 복잡한 회로판, 네온 사용하지 말 것
```

## 프롬프트 6블록 빈 템플릿

사용자가 직접 채울 수 있는 범용 템플릿:

```
당신은 출판 전문 북커버 디자이너입니다.
아래 조건에 맞는 {전자책/종이책} 표지 이미지를 만들어주세요.

[책 정보]
 - 제목: {제목}
 - 부제: {부제}
 - 저자: {저자명}
 - 출판사: {출판사명}
 - 장르: {장르} — {1줄 설명}

[분위기] {형용사 2~3개}
[색감] {주조색(HEX)}과 {보조색(HEX)} 대비, {배경색(HEX)} 기반
[구도] {구도 유형}. {키 비주얼 설명 — 오브젝트, 개수·관계, 크기·비율, 위치, 시선 방향, 디테일 수준, 질감 명시}.
       상단 1/3에 제목 "{제목}" 배치 ({폰트 스타일}), 하단에 저자명 "{저자명}" 배치.
[스타일] {스타일 키워드}
[조건]
 - 제목, 부제, 저자명을 표지 이미지에 포함할 것
 - 세로형 비율 ({비율 — 2:3/1:1.6/3:4 등})
 - 배경은 {단색/그라데이션}
 - 고해상도로 생성
 - {금지 요소}
```

## 간편 테스트용 프롬프트 예시

방향 테스트용으로 핵심 블록만 포함한 간편 버전. 결과를 보면서 풀 버전으로 정밀화한다.

### 예시 1: 에세이/경험서

```
담담하고 진솔한 분위기의 책 표지 이미지를 만들어주세요.

[색감] 감색(#2C3E6B)과 앤티크골드(#C8A96E), 베이지(#F5E6D0) 배경
[구도] 미니멀형. 넓은 베이지 배경 중앙에 작은 만년필 실루엣 1개.
       표지 면적의 1/5 크기.
       상단 1/3에 제목 "{제목}" (세리프체), 하단에 저자명 "{저자명}" 배치.
[조건] 제목과 저자명을 포함할 것. 세로 비율 2:3. 고해상도.
```

### 예시 2: 실용서/비즈니스

```
전문적이면서 친근한 분위기의 책 표지 이미지를 만들어주세요.

[색감] 블루(#3366CC)와 골드(#F5A623), 흰색(#FFFFFF) 배경
[구도] 중앙 집중형. 흰 배경 중앙에 미니멀 플랫 아이콘 1개.
       표지 면적의 1/4 크기.
       상단 1/3에 제목 "{제목}" (굵은 고딕체), 하단에 저자명 "{저자명}" 배치.
[조건] 제목과 저자명을 포함할 것. 세로 비율 2:3. 고해상도.
```

### 예시 3: IT/테크

```
세련되고 미래지향적인 분위기의 책 표지 이미지를 만들어주세요.

[색감] 딥네이비(#1A237E)와 네온그린(#00E676), 블랙(#0D1117) 배경
[구도] 패턴형. 어두운 배경 전면에 미세한 기하학적 패턴.
       중앙에 제목 "{제목}" (굵은 산세리프체, 흰색), 하단에 저자명 "{저자명}" 배치.
[조건] 제목과 저자명을 포함할 것. 세로 비율 2:3. 고해상도.
```
