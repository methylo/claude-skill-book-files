# 장르별 표지 패턴 + 3색 조합 (genre-patterns.md)

Step 2(장르 문법 파악)와 Step 4(블록 3 색감) 작성 시 참조한다.

---

## 장르별 표지 패턴 레퍼런스

### 실용서/비즈니스
- 색감: 파란+흰, 깔끔한 톤. 또는 네이비+골드
- 구도: 아이콘/도식 중심, 여백 많음, 큰 제목
- 타이포: 큰 제목, 부제 강조, 굵은 산세리프

### 자기계발
- 색감: 따뜻한 톤(주황, 노랑), 또는 감성적 파스텔
- 구도: 인물 또는 상징 이미지, 감성적 카피
- 타이포: 감성적 카피 + 저자명 강조

### IT/테크
- 색감: 진한 파랑, 네온 계열, 블랙 배경
- 구도: 디지털 패턴, 회로 이미지, 기술 키워드
- 타이포: 기술 키워드 강조, 굵은 산세리프

### 에세이/경험서
- 색감: 톤 다운 — 네이비+베이지, 감색+크림, 차분한 회색+포인트 1색
- 구도: 넓은 여백, 중앙에 작은 심볼 1개 또는 미니멀 일러스트
- 타이포: 제목이 여백 안에서 호흡. 세리프 또는 손글씨 계열

### 교육/학습
- 색감: 구조적 색상 조합, 아이콘 조합
- 구도: 구조적 레이아웃, 명확한 정보 전달
- 타이포: 명확하고 읽기 쉬운 폰트

### 소설/문학
- 색감: 장르에 따라 다양 — 순문학은 절제된 단색, 장르소설은 강렬한 색 대비
- 구도: 분위기를 압축한 단일 이미지, 추상적 심볼, 여백 활용
- 타이포: 세리프 기반, 제목이 표지의 주인공. 저자명이 제목보다 클 수도 있음 (유명 작가)

### 시집/산문집
- 색감: 극도로 절제된 1~2색. 흰+검정, 단색 배경+포인트 1색
- 구도: 최소 요소. 여백이 곧 디자인. 작은 일러스트 또는 없음
- 타이포: 손글씨 또는 세리프. 제목 자체가 비주얼

### 요리/라이프스타일
- 색감: 따뜻한 톤 — 크림, 베이지, 아이보리 기반 + 음식 색상
- 구도: 사진 중심(음식·공간), 전면 사진 또는 상하 분할
- 타이포: 가독성 좋은 폰트, 부제로 내용 설명

### 아동/그림책
- 색감: 선명하고 채도 높은 다색 조합
- 구도: 캐릭터 중심, 전면 일러스트
- 타이포: 둥글고 친근한 폰트, 큰 크기

## 분위기 형용사 조합 레퍼런스

프롬프트 블록 2(분위기)에서 장르에 맞는 형용사를 선택할 때 참조한다.

| 조합 예시 | 적합한 장르 |
|---------|---------|
| 전문적 + 친근한 + 현대적 | 실용서, 비즈니스 |
| 따뜻한 + 진솔한 + 편안한 | 에세이, 자기계발 |
| 세련된 + 미래지향적 + 임팩트 있는 | IT/테크 |
| 담담한 + 절제된 + 따뜻한 | 경험서 |
| 고요한 + 서정적 + 여백이 있는 | 시집, 문학 |
| 선명한 + 활기찬 + 친근한 | 아동서, 요리 |
| 긴장감 + 몰입적 + 어둡고 강렬한 | 장르소설(스릴러, 미스터리) |

## 구도 유형 테이블

프롬프트 블록 4(구도)에서 적합한 구도를 선택할 때 참조한다.

| 구도 유형 | 설명 | 적합한 장르 |
|---------|------|---------|
| 중앙 집중형 | 중앙에 키 비주얼 1개, 상하 여백 | 실용서, 가이드 |
| 상하 분할형 | 상단 이미지 + 하단 색면 | 자기계발, 에세이 |
| 좌우 분할형 | 좌측 이미지 + 우측 색면 | 비즈니스 |
| 패턴/텍스처형 | 전면 패턴 + 중앙 타이틀 박스 | IT/테크 |
| 미니멀형 | 넓은 단색 배경 + 작은 심볼 1개 | 에세이, 문학, 시집 |
| 추상형 | 선·점·형태만으로 구성 | 문학, 에세이 |
| 전면 사진형 | 사진이 표지 전체를 차지, 텍스트 오버레이 | 요리, 라이프스타일, 사진집 |
