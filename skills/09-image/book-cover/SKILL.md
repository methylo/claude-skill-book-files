# 책 표지 프롬프트 설계 워크플로우 (Book Cover Prompt Workflow)

원고(또는 기획서)에서 출발하여 AI 이미지 생성 도구용 구조화된 표지 프롬프트를 만드는 6단계 프로세스.

## 참조 파일 로딩 규칙

이 스킬의 보조 파일은 `references/` 디렉토리에 있다. **필요한 Step에서만** 해당 파일을 로딩한다.

| 파일 | 로딩 시점 |
|------|---------|
| `genre-patterns.md` | Step 2 진입 시 (장르 문법 파악) |
| `prompt-templates.md` | Step 4 진입 시 (프롬프트 구조화) |
| `tool-guide.md` | Step 4 진입 시 (나노바나나 생성 가이드) |
| `font-typography-guide.md` | Step 6 진입 시 (편집·완성) |

Step 3(비주얼 콘셉트)의 키 비주얼 묘사 체크리스트는 본 파일에 포함되어 있다.

---

## 전체 흐름

```
Step 1: 원고 핵심 추출(What)
  → Step 2: 장르 문법 파악(Where)
    → Step 3: 비주얼 콘셉트 설계(How)
      → Step 4: 프롬프트 구조화(Build)
        → Step 5: 생성·선별(Select)
          → Step 6: 편집·완성(Finish)
```

사용자의 상태에 따라 적절한 단계부터 시작한다.
- 원고 파일 제공 → Step 1부터
- 장르·톤·독자가 이미 정해진 상태 → Step 2부터
- 비주얼 콘셉트가 있음 → Step 4부터
- 이미지가 이미 생성됨 → Step 5부터

### Step 간 전환 규칙

각 Step 완료 후, 다음 Step으로 넘어가기 전에 사용자 확인을 받는다.

| 전환 | 확인 방식 |
|------|----------|
| Step 1 → 2 | 추출된 5가지 항목(장르/메시지/서사/톤/독자)을 요약 제시하고 확인 |
| Step 2 → 3 | 장르 문법 분석 결과와 "따라야 할 패턴 / 피해야 할 패턴"을 제시하고 확인 |
| Step 3 → 4 | 2~3개 비주얼 콘셉트를 비교표로 제시하고 선택 확인 |
| Step 4 → 5 | 나노바나나 프로용 프롬프트를 제시하고 확인 |
| Step 5 → 6 | 선별 평가 결과와 수정 방향을 제시하고 확인 |

### 연속 진행 모드

사용자가 "끝까지 진행해줘" 또는 "한 번에 해줘"라고 요청한 경우, Step 1~4까지 연속 진행한다.
Step 5~6은 사용자의 이미지 생성 결과가 필요하므로 반드시 중간 확인을 받는다.

**연속 진행 시 축약 출력 규칙:**
- Step 1: 5가지 항목을 각 1줄로 압축 (표 없이 항목명: 값 형식)
- Step 2: "따라야 할 패턴" 3줄 + "피해야 할 패턴" 3줄로 축약
- Step 3: 비교표는 유지하되, 각 콘셉트 설명을 2줄 이내로 압축
- Step 4: 나노바나나 프로용 프롬프트 전문 제공 (축약하지 않음)

## Step 1: 원고 핵심 추출 (What)

### 목적
원고(또는 기획서)를 읽고 표지에 반영해야 할 핵심 정보를 추출한다.

### 추출 항목 (필수 5가지 + 선택 2가지)

| 순서 | 항목 | 추출 질문 | 출력 형식 |
|------|------|---------|---------|
| 1 | 장르 | 이 책은 실용서인가, 에세이인가, 경험서인가? | 장르명 + 1줄 설명 |
| 2 | 핵심 메시지 | 이 책을 한 문장으로 요약하면? | 1문장 (서문 또는 에필로그에서 추출) |
| 3 | 서사 구조 | 시작과 끝에서 무엇이 달라지는가? | Part/챕터별 변환 궤적 표 |
| 4 | 톤 | 이 책의 목소리는 어떤 느낌인가? | 형용사 3~4개 + 구체적 특징 |
| 5 | 독자 | 이 책을 집어들 사람은 누구인가? | 독자 프로필 1문단 |
| 6 | 저자 정체성 (선택) | 저자의 경력·전문성이 표지에 반영되어야 하는가? | 경력 키워드 + 부제 활용 여부 |
| 7 | 비주얼 키워드 (선택) | 원고에서 반복 등장하며 시각화 가능한 개념은? | 키워드 + 비주얼 가능성 표 |

### 추출 방법

1. 원고가 제공된 경우:
   - 서문과 에필로그를 우선 읽는다 (핵심 메시지가 가장 집중된 곳)
   - 목차(Part/챕터 제목)에서 서사 구조를 파악한다
   - 본문 첫 3챕터에서 톤과 문체를 분석한다
   - 독자 정보는 서문에서 직접 언급된 경우가 많다

2. 기획서만 제공된 경우:
   - 기획 의도, 타깃 독자, 목차에서 1~5번 항목을 추출한다
   - 톤은 "어떤 책을 참고했는가" 또는 "어떤 느낌의 책인가"를 사용자에게 질문한다

3. 아무것도 없는 경우:
   - 사용자에게 5가지 항목을 순서대로 질문한다
   - 최소 장르 + 핵심 메시지 + 톤 3가지는 확보해야 Step 2로 진행 가능

### 출력 형식

```markdown
## Step 1 결과: 원고 핵심 추출

### ① 장르
{장르명} — {1줄 설명}

### ② 핵심 메시지
"{한 문장}"
보조 메시지: {2~3개}

### ③ 서사 구조
| Part | 서사 위치 | 저자/주인공의 상태 |
|------|---------|--------------|
| ... | ... | ... |

### ④ 톤
{형용사 3~4개}. {구체적 특징 2~3줄}

### ⑤ 독자
{독자 프로필 1문단}

### ⑥ 비주얼 키워드 (표지 반영 가능)
| 키워드 | 맥락 | 비주얼 가능성 |
|-------|------|----------|
| ... | ... | ... |
```

## Step 2: 장르 문법 파악 (Where)

> **이 Step 진입 시 `genre-patterns.md`를 로딩한다.**

### 목적
Step 1에서 확정된 장르에 해당하는 기존 베스트셀러 표지 패턴을 분석하여, "따라야 할 문법"과 "피해야 할 패턴"을 정리한다.

### 분석 항목 3가지

| 항목 | 분석 질문 |
|------|---------|
| 색감 경향 | 이 장르의 책들이 주로 쓰는 색은? 어두운 톤인가, 밝은 톤인가? |
| 구도 경향 | 인물 중심인가, 오브젝트 중심인가, 추상인가? 여백이 많은가? |
| 타이포 경향 | 제목이 크고 강한가, 작고 여백이 많은가? 세리프인가 산세리프인가? |

`genre-patterns.md`에서 해당 장르의 패턴과 3색 조합 세트를 참조하여 분석한다.

### 교차 장르 처리

한 책이 여러 장르에 걸치는 경우 (예: "AI 경험서" = IT + 에세이):
1. 서점에서 이 책이 **물리적으로 놓일 서가**의 장르를 1차 기준으로 삼는다
2. **표지의 톤**은 책의 실제 성격에 맞는 장르를 따른다
3. 두 장르의 교차점에서 "따라야 할 것"과 "피해야 할 것"을 각각 정리한다

### 출력 형식

```markdown
## Step 2 결과: 장르 문법 파악

### 이 책의 장르 위치
{서가 장르} 서가에 놓이지만, 표지 톤은 {실제 장르}를 따른다.

### 따라야 할 패턴
| 요소 | 방향 | 근거 |
|------|------|------|
| 색감 | ... | ... |
| 구도 | ... | ... |
| 타이포 | ... | ... |

### 피해야 할 패턴
| 요소 | 피해야 할 것 | 이유 |
|------|-----------|------|
| ... | ... | ... |

### 레퍼런스 수집 가이드
- 교보문고: "{검색어}"
- 알라딘: "{검색어}"
- Pinterest: "{검색어}"
```

## Step 3: 비주얼 콘셉트 설계 (How)

### 목적
Step 1(원고 핵심)과 Step 2(장르 문법)를 결합하여 2~3개의 비주얼 콘셉트를 설계한다.

### 설계 전 교차 검증

콘셉트를 만들기 전에 아래 4가지를 확정한다:

| 확인 항목 | 질문 |
|---------|------|
| 첫인상 | 이 표지를 보고 독자가 3초 안에 떠올릴 단어는? |
| 핵심 감정 | 이 책의 톤을 색과 형태로 번역하면? |
| 전달할 관계/구조 | 표지 중앙에 놓일 "한 장면"은 무엇인가? |
| 신뢰 신호 | 전문성을 어떻게 전달하는가? (비주얼 vs 타이포 vs 부제) |

### 콘셉트 설계 — 각 안에 포함할 요소

| 요소 | 설명 |
|------|------|
| 콘셉트명 | 2~3단어의 직관적 이름 (예: "나란히", "두 줄의 궤적") |
| 핵심 아이디어 | 1문장 — 무엇을 시각화하는가 |
| 키 비주얼 | 표지 중앙에 놓일 이미지의 구체적 설명 (→ 키 비주얼 묘사 체크리스트 참조) |
| 색감 방향 | HEX 코드 포함한 색감 조합 |
| 스타일 | 라인 드로잉 / 플랫 일러스트 / 추상 / 사진풍 등 |
| 타이포 방향 | 제목 폰트 스타일 + 배치 위치 |
| 원고 연결 | 원고의 어떤 부분과 연결되는가 |
| 서점 차별화 | 같은 서가의 다른 책과 어떻게 구별되는가 |

### 키 비주얼 묘사 체크리스트

콘셉트의 키 비주얼을 서술할 때 아래 7가지를 반드시 포함한다. 빠진 항목이 있으면 AI 도구가 임의 해석하여 의도와 다른 결과가 나온다.

| # | 항목 | 질문 | 예시 |
|---|------|------|------|
| 1 | 오브젝트 | 무엇이 그려지는가? | "노트북과 만년필" / "사람 실루엣 2개" |
| 2 | 개수·관계 | 몇 개이며 서로 어떤 관계인가? | "나란히 놓인" / "하나가 다른 하나를 감싸는" |
| 3 | 크기·비율 | 표지 면적 대비 어느 정도 차지하는가? | "표지 중앙 1/3" / "하단 절반을 채움" |
| 4 | 위치 | 표지의 어디에 놓이는가? | "정중앙" / "좌측 하단" / "상단에서 아래로 내려오며" |
| 5 | 시선 방향 | 보는 사람의 시선을 어디로 이끄는가? | "위에서 아래로" / "중앙에서 바깥으로 확산" |
| 6 | 디테일 수준 | 단순화 수준은? | "실루엣만" / "윤곽선+최소 내부 디테일" / "세밀하게" |
| 7 | 질감·재질 | 어떤 느낌의 표면인가? | "종이 질감" / "매끈한 벡터" / "수채화 번짐" |

### 콘셉트 비교 — 반드시 비교표 제공

| 비교 항목 | 안 A | 안 B | 안 C |
|---------|------|------|------|
| 전달 메시지 | ... | ... | ... |
| 원고 연결 | ... | ... | ... |
| 장르 신호 | ... | ... | ... |
| 서점 차별화 | ... | ... | ... |
| 썸네일 가독성 | ... | ... | ... |
| 타이포 자유도 | ... | ... | ... |
| 제작 난이도 | ... | ... | ... |

→ 비교표 제시 후 사용자에게 1~2개 선택을 요청한다.

## Step 4: 프롬프트 구조화 (Build)

> **이 Step 진입 시 `prompt-templates.md`와 `tool-guide.md`를 로딩한다.**

### 목적
선택된 콘셉트를 6블록 프레임워크로 구조화하여 나노바나나 프로(Gemini)에 입력할 프롬프트를 만든다.

### 대상 도구
나노바나나 프로(Gemini) 기준으로 프롬프트를 작성한다. 한글 자연어 대화체로 6블록 전체를 입력하는 형식이다.

### 6블록 프레임워크

`prompt-templates.md`의 6블록 프레임워크와 장르별 템플릿을 참조하여 프롬프트를 구성한다.

```
[블록 1: 역할 지정 + 책 정보]
[블록 2: 분위기 (형용사 2~3개)]      ← 필수
[블록 3: 색감 (HEX 코드 포함)]       ← 필수
[블록 4: 구도 (키 비주얼 + 텍스트 영역)] ← 필수
[블록 5: 스타일]
[블록 6: 출력 조건 + 제약]
```

### 블록별 핵심 규칙

- **블록 2(분위기)**: Step 1 톤에서 추출한 형용사 2~3개. 서로 모순되지 않는 조합
- **블록 3(색감)**: 주조색+보조색+배경색 3색을 HEX 코드로 명시. `genre-patterns.md`의 3색 조합 세트 참조
- **블록 4(구도)**: Step 3 키 비주얼 묘사 체크리스트 7항목을 반드시 반영. 텍스트 배치 영역 명시
- **블록 6(출력 조건)**: 비율, 해상도, 금지 요소 지정. 텍스트(제목·부제·저자명)는 프롬프트에 포함하여 이미지에 함께 생성한다.

`tool-guide.md`에서 나노바나나 프로 생성 가이드를 참조한다.

### 출력 — 나노바나나 프로 버전

나노바나나 프로(Gemini) 기준 한글 프롬프트 1개를 제공한다. 6블록 전체를 자연어 대화체로 구성한다.

→ `prompt-templates.md`의 장르별 템플릿과 축약 예시를 참조한다.

## Step 5: 생성·선별 (Select)

### 목적
사용자가 AI 이미지 도구에서 생성한 결과물을 업로드하면, 선별 기준으로 평가하고 수정 방향을 제안한다.

### 선별 기준 4가지

| 순위 | 기준 | 질문 | 비중 |
|------|------|------|------|
| 1 | 메시지 부합 | 원고의 핵심 메시지가 이미지에서 느껴지는가? | 최우선 |
| 2 | 장르 신호 | 서점에서 이 표지를 보면 장르가 즉시 읽히는가? | 높음 |
| 3 | 텍스트 공간 | 제목·저자명을 배치할 여백이 확보되어 있는가? | 높음 |

## 공통 원칙

### AI 이미지 생성 시 주의사항
1. **텍스트는 프롬프트에 포함한다** — 제목·부제·저자명을 프롬프트에 명시하여 이미지에 함께 생성한다. 한글 렌더링이 부정확할 수 있으므로 생성 후 확인하고, 필요 시 편집 도구에서 보정한다
2. **축약 버전으로 먼저 테스트한다** — 풀 버전 투입 전에 방향을 확인
3. **10~20장 생성 후 3~5장 선별한다** — 1장만 생성하지 않음
4. **프롬프트 수정은 블록 단위로 한다** — 전체 재작성 아님, 해당 블록만 변경
5. **콘셉트 변경은 3회 재생성 후에 판단한다** — 요소 조정으로 해결 안 될 때만

### 표지의 핵심 원칙
1. **좋은 표지는 '예쁜 이미지'가 아니라 '장르의 문법을 따르는 이미지'다**
2. **독자는 디자인을 보는 것이 아니라 신호를 읽는다** — 3초 안에 장르 판단
3. **제목이 표지의 주인공이다** — 비주얼은 제목을 돕는 역할
4. **온라인 서점 썸네일(200×300px)에서의 가독성이 최우선이다**
