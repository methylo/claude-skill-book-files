# write-facebook-essay

페이스북 친구들에게 이야기하듯 쓰는 일상 에세이형 1단계 스킬.

## 핵심 원칙

1. **장면 우선**: 도입 1~2문장은 일상의 한 장면·상황으로 시작. 감정·해석은 그 뒤에 배치.
2. **종결어미 ~다**: 모든 문장의 끝맺음은 '~다'로 고정. ~합니다체·~요체 금지.
3. **단락 호흡**: 한 단락은 2~3문장으로 끊는다. 모바일 화면에서 한눈에 읽히는 호흡.
4. **묘사 중심**: 과장된 형용사·감탄형·추상어 배제. 구체적인 장면·행동·감각 묘사 우선.
5. **잔잔한 톤**: 외치지 않는다. 가르치지 않는다. 친구에게 가만히 건네는 결.

## 작동 방식

사용자가 [원고]를 입력하면 곧바로 완성된 페이스북 일상 에세이 1편을 대화창 텍스트로 출력한다. 중간 분석 단계·옵션 제시 없이 1회 출력한다.

단, 입력 분량과 결 신호에 따라 처리 방식이 분기된다.

## 입력 분량별 처리

| 입력 분량 | 처리 방식 |
|----------|----------|
| **한 줄~3문장** (~100자) | 장면 단서 추출 후 확장. 추출 어려우면 1줄 질문 |
| **짧은 단락** (100~500자) | 입력 그대로 골격 삼아 결 적용. 구조 재배치 가능 |
| **긴 단락·일기** (500~2,000자) | 핵심 장면 1개 선별 후 6~12문장으로 압축 |
| **2,000자 초과** | 작업 중단. "어느 장면 하나만 고르면 좋을지 알려주십시오" |

## 4가지 결 모드

같은 일상 에세이도 결이 갈린다. 트리거 키워드로 결을 결정한다.

| 모드 | 트리거 | 특징 | 예시 상황 |
|------|--------|------|----------|
| **R1 잔잔형** | 잔잔, 조용히, 가만히, 일상 (기본값) | 조용한 일상 그대로 묘사 | 카페에서 글쓰기, 출근길, 저녁 산책 |
| **R2 발견형** | 발견, 깨달음, 문득, 알게 됨 | 일상에서 작은 깨달음 추출 | 우연한 대화, 사소한 관찰의 의미 |
| **R3 관찰형** | 관찰, 봤다, 옆에서, 누군가 | 타인·상황을 거리 두고 묘사 | 카페 옆자리 손님, 지하철 풍경 |
| **R4 회상형** | 회상, 기억, 예전, 그때 | 과거 한 장면을 현재로 불러옴 | 옛 동네, 오래된 메모, 사진 한 장 |

### 모드 신호 없을 때 자동 추천

입력 원고에서 다음 신호를 보고 모드를 추천한다.

| 신호 | 추천 모드 |
|------|----------|
| 입력에 "오늘", "지금", 현재 시제 위주 | R1 잔잔형 |
| 입력에 "알았다", "보였다", 깨달음 표현 | R2 발견형 |
| 입력에 타인(그/그녀/누가) 등장 | R3 관찰형 |
| 입력에 "예전", "옛날", "어릴 때" | R4 회상형 |
| 어느 쪽도 명확하지 않음 | R1 잔잔형 (기본값) |

## 글 구조 템플릿 (4모드 공통 골격)

```
[장면 도입: 1~2문장]
시간·장소·행동·감각이 드러나는 구체 장면.

[장면 확장: 2~3문장]
그 장면 안에서 일어난 작은 변화·움직임·생각의 시작.

[감정·해석: 2~3문장]
장면에서 출발한 감정 또는 해석. 단정하지 않고 머무는 방식.

[마무리: 1~2문장]
정리하지 않는 마무리. 작은 여운 또는 다음 장면으로 열어두기.
```

**총 분량**: 6~12문장, 4단락 내외. 첫 3줄 안에 장면이 보여야 한다.

## 문장 규칙

- 모든 문장 종결어미는 `~다` (예: 본다, 들었다, 걸었다, 남는다)
- 능동·단문 우선. 두 문장으로 끊을 수 있으면 끊는다.
- 추상명사 중심 → 행동·상태 중심으로 변환
- 금지어: 매우, 정말, 너무, 완벽한, 혁신적인, 획기적인, 놀라운, 환상적인
- 금지 표현: ~할 수 있다, ~인 것 같다 (단정 회피형). 단, 본인의 머뭇거림을 의도적으로 드러낼 때는 허용.
- 감탄사·이모지 사용 금지

## 자가 점검 체크리스트

응답 직전 다음 8가지를 점검한다. 하나라도 어긋나면 수정 후 출력한다.

1. 입력 분량 처리 분기를 올바르게 적용했는가 (한 줄/단락/긴 일기/초과)
2. 선택한 결 모드(R1~R4)에 맞는 톤과 시점인가
3. 첫 1~2문장이 시간·장소·행동·감각이 드러나는 구체 장면인가
4. 모든 문장이 `~다`로 끝났는가
5. 한 단락이 2~3문장으로 끊겼는가
6. 금지어가 없는가
7. 감정·해석이 장면 뒤에 배치되었는가
8. 마무리가 교훈·다짐·정리로 닫히지 않고 여운으로 열려 있는가

## 검증 예시

### 예시 1: R1 잔잔형 (입력=짧은 단락)

**입력**:
```
오후 3시 카페. 글이 안 써져서 한참 빈 화면만 봤다.
커피가 식어가는 동안 한 줄도 못 적었다.

→ 페북 일상 에세이로 써줘
```

**출력**:
```
오후 3시, 창가 자리에 앉았다. 커피잔에서 김이 올라오고 노트북 화면은 비어 있다.

한 문장을 적었다가 지웠다. 다시 적었다가 또 지웠다. 그러는 사이 커피가 식었다.

빈 화면을 보다가 문득, 글이 안 써지는 날이 글에 대해 가장 많이 생각하는 날이라는 걸 알았다.

식은 커피를 한 모금 마셨다. 다시 한 문장을 적었다.
```

### 예시 2: R3 관찰형 (입력=한 줄)

**입력**:
```
지하철에서 책 읽는 사람을 봤다

→ 관찰형으로
```

**출력**:
```
저녁 7시 지하철 2호선. 맞은편 자리에 한 여자가 앉아 있다.

손에는 두꺼운 책이 들려 있다. 손가락이 페이지를 천천히 넘긴다. 사람들이 타고 내리는 동안에도 시선은 책에서 떠나지 않는다.

문이 열리고 닫힐 때마다 차가운 바람이 들어왔다. 그녀는 한 번도 고개를 들지 않았다.

내 손에는 스마트폰이 들려 있었다. 화면을 껐다.
```

### 예시 3: R2 발견형 (입력=긴 일기 압축)

**입력**:
```
오늘 카페에서 옆자리 손님이 통화를 했다. 친구한테 화내고 있었다.
들어보니 자기가 한 약속을 친구가 못 지켰다는 거였다. 한참 듣다 보니
나도 비슷한 일이 있었던 게 떠올랐다. 그때 나도 화를 냈었다.
근데 지금 생각해보면 친구도 사정이 있었을 거다. 결국 우리는 자기 입장만
보는 것 같다. 옆자리 손님 통화가 끝났고, 그도 한참 멍하니 있었다.

→ 발견형으로 써줘
```

**출력**:
```
카페 옆자리에서 통화 소리가 들렸다. 친구한테 화를 내고 있었다.

약속을 못 지킨 친구를 탓하는 목소리였다. 듣다 보니 작년에 비슷한 일로 화냈던 내 모습이 떠올랐다.

그때 나도 친구의 사정은 보지 않았다. 우리는 자기 자리에서만 상대를 본다.

통화가 끝났다. 옆자리 손님도 한참 창밖을 봤다.
```

## 출력 형식

대화창에 본문만 출력한다. 제목·해시태그·머리말·꼬리말 없이 본문 텍스트만 제공한다.

선택한 결 모드는 본문 출력 후 한 줄로 표시한다.
```
---
적용 모드: R1 잔잔형
```

사용자가 다른 결로 다시 요청하면 변형을 추가 출력한다.
