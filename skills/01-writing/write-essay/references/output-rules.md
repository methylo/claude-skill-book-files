# 산출물 규칙 (Output Rules)

각 Step의 산출물 명세와 파일·포맷 규칙.

---

## 단계별 산출물

| Step | 산출물 | 형식 | 저장 |
|------|--------|------|------|
| Step 1 주제 탐색 | 소재·정서·쓰려는 이유·분량 요약 | 대화창 텍스트 | 저장 안 함 |
| Step 2 시선 설계 | 시선 한 문장 + 시선 유형 + 구조 골격 | 대화창 텍스트 | 저장 안 함 |
| Step 3 초안 | 에세이 초안 | 대화창 텍스트 | 명시 요청 시 `draft.md` |
| Step 4 리라이팅 | 점검 리포트 + 수정본 + 변경 요약 | 대화창 텍스트 | 명시 요청 시 `revised.md` |
| Step 5 최종 출력 | 제목 + 최종 본문 | 대화창 텍스트 + 파일 | `final.md`(기본) / `final.docx`(요청 시) |

---

## 기본 원칙

- 에세이는 1회 게시 단위의 단편 콘텐츠다. **대화창 텍스트 제공을 우선한다.**
- 중간 산출물(초안·수정본)은 사용자가 명시 요청한 경우에만 파일로 저장한다.
- 최종본은 사용자가 채널을 지정하지 않으면 `final.md`가 기본값이다.

---

## 산출물 제시 형식

### Step 2 시선 설계안 형식

```
시선 한 문장: (소재를 통해 무엇을 어떤 태도로 보는지)
시선 유형: (관찰자 / 회고자 / 질문자 / 대조자 / 동행자 / 발견자)
주 축: (거리 / 시간 / 초점 / 태도)

구조 골격:
[진입] (어떤 장면으로 열지)
[전개] (시선을 따라 무엇을 펼칠지)
[전환] (시선이 어디서 꺾일지)
[여운] (어떻게 닫을지)
```

### Step 4 변경 요약 형식

```
**주요 변경 사항:**
- 시선: (변경 내용)
- 장면·감각: (변경 내용)
- 문장: (변경 내용)
- 마무리: (변경 내용)
```

## 파일·포맷 규칙

| 항목 | 규칙 |
|------|------|
| 기본 포맷 | `.md` (마크다운) |
| 워드 요청 시 | `.docx` — 생성 전 반드시 `/mnt/skills/public/docx/SKILL.md`를 읽고 따른다 |
| 파일명 | `draft.md`, `revised.md`, `final.md` / 제목이 확정되면 제목 기반 파일명 허용 |
| 본문 외 메타 | 제목, (선택) 한 줄 소개. 해시태그·SEO 메타는 에세이 본문에 넣지 않는다 |

---

## 채널 연계 시

브런치·블로그·페이스북 등 특정 채널 발행이 목적이면, 이 스킬은 본문을 완성한 뒤 해당 채널 스킬(write-brunch / write-blog / write-facebook)로 넘긴다. 채널별 제목 규칙·해시태그·노출 구조·줄바꿈 규칙은 채널 스킬이 처리한다. 이 스킬에서 채널 최적화를 임의로 적용하지 않는다.
