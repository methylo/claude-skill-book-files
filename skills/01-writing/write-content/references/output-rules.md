# write-content 출력 규칙 (Output Rules)

이 파일은 write-content 스킬의 단계별 산출물 명세와 파일·포맷 규칙을 정의한다. SKILL.md의 각 Step에서 산출물을 만들기 직전에 참조한다.

## 단계별 산출물 명세

### Step 1 산출물 — 목적 정의 요약

- 형식: 대화창 텍스트
- 내용: 목적·독자·채널·콘텐츠 유형 4가지 항목 요약
- 사용자 확인 후 Step 2 진입

### Step 2 산출물 — 아웃라인

- 형식: 대화창 텍스트 (기본) / 요청 시 `outline.docx`
- 내용: 유형별 구조에 따른 소제목 위계
- 사용자 확인 후 Step 3 진입

### Step 3 산출물 — 초안

- 형식: 대화창 텍스트 (기본)
- 명시 요청 시: `draft.docx` 또는 `draft.md`
- 필수 구성: 출력 슬롯 템플릿(칼럼형 4슬롯 또는 문서형 5슬롯)을 모두 채운다. 슬롯을 건너뛰거나 순서를 바꾸지 않는다
- 자가 점검 6항목을 통과한 뒤 출력
- 사용자 확인 후 Step 4 진입

### Step 4 산출물 — 점검 리포트 + 수정본

- 점검 리포트: 4가지 영역(구조·문장·스타일·채널)을 표 형태로 제시
- 수정본: 전체 텍스트 + 하단에 변경 요약 박스

변경 요약 포맷:

```
**주요 변경 사항:**
- 구조: (변경 내용)
- 문장: (변경 내용)
- 스타일: (변경 내용)
- 채널: (변경 내용)
```

### Step 5 산출물 — 최종 완성본

- 기본: `final.docx`
- 선택: `final.md` (텍스트 원본), `final.html` (웹 게시용)
- 제목: 후보 3~5개 제시 후 사용자 선택
- 문서 생성 전 반드시 `/mnt/skills/public/docx/SKILL.md`를 읽고 따른다

## 파일명·포맷 규칙

| 단계 | 파일명 | 비고 |
|------|--------|------|
| Step 2 | `outline.docx` | 요청 시 |
| Step 3 | `draft.docx` 또는 `draft.md` | 명시 요청 시 |
| Step 5 | `final.docx` / `final.md` / `final.html` | 기본은 .docx |

## 산출물 총괄

| 단계 | 산출물 | 형식 |
|------|--------|------|
| Step 1 | 목적 정의 요약 | 대화창 텍스트 |
| Step 2 | 아웃라인 | 대화창 텍스트 / `outline.docx` (요청 시) |
| Step 3 | 초안 | 대화창 텍스트 / `draft.docx` (요청 시) |
| Step 4 | 점검 리포트 + 수정본 | 대화창 텍스트 |
| Step 5 | 최종 완성본 | `final.docx` / `final.md` / `final.html` |
