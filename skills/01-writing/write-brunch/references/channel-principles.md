# 브런치 집필 원칙

SKILL.md의 Step 3(초안)과 Step 4(리라이팅)에서 읽는 브런치 채널 집필 기준이다.

### 문체 기준

- 표준어 사용
- 종결어미는 사용자 지정에 따름 (기본값: '~다'체 — 브런치의 주류 문체)
- 문장은 15~22단어 내외 기본 (브런치의 모바일 가독성 고려, 일반 글쓰기보다 짧게)
- **한 문장에는 하나의 정보, 하나의 판단만 담는다**
- 문장은 능동형을 기본으로 한다
- 문단은 2~4문장을 기본으로 한다 (브런치 모바일 화면에서 문단이 길면 읽기 부담)
- 줄바꿈은 문단 단위로만 적용. 소제목 전환, 장면 전환, 주제 블록 전환 시에만 허용
- 감정적 표현, 감탄형 문장 지양
- 전체 톤은 차분하고 개인적인 문체 유지

### 브런치 톤 가이드

브런치 글은 블로그의 정보 전달과 에세이의 개인 서사 사이에 위치한다. 아래 유형별로 톤을 조정한다.

| 글 유형 | 톤 | 특징 |
|---------|-----|------|
| 경험 기반 인사이트 | 관찰하는 실무자 | 경험에서 기준을 뽑아내는 방식. "나는 이렇게 했고, 이것이 기준이 되었다" |
| 전문 분야 해설 | 친근한 전문가 | 어려운 개념을 독자 눈높이로 풀어주되, 판단 기준을 명확히 제시 |
| 일상 관찰·성찰 | 담담한 이야기꾼 | 장면과 감각으로 시작해서 보편적 통찰로 연결 |
| 정보·가이드 | 구조적 안내자 | 조건 → 기준 → 결과 순서로 정리. 나열이 아닌 판단 기준 제공 |
| 시사·트렌드 분석 | 분석적 관찰자 | 현상 재정의 → 기준 제시 → 관점 전환 |

### 서술 전략

- 글의 첫 문장: **구체적 장면, 독자의 문제 상황, 또는 날카로운 질문**으로 시작. 정의나 개념 나열로 시작하지 않음
- 설명 순서: **상황 → 기준 → 적용 방식**
- 소제목은 기능명이 아닌 **판단·행동 중심 문장**으로 작성
- "가능하다"보다 **"이렇게 판단한다"** 식의 단정적 서술
- 마무리는 요약이 아니라 **관점의 재정렬** 또는 **독자에게 남기는 질문**

### 글쓰기 금지어 규칙

모든 문장은 **판단·기준·결과**가 드러나야 한다.

**① 과장형 형용사 금지**
금지어: 혁신적인, 획기적인, 창의적인, 강력한, 완벽한, 최고의, 탁월한, 뛰어난
→ 무엇이 어떻게 다른지, 수치·사례로 설명한다.

**② 모호한 부사 금지**
금지어: 매우, 굉장히, 상당히, 꽤, 쉽게, 빠르게, 간편하게, 효율적으로
→ 시간·단계·수치·조건으로 대체한다.

**③ 추측·완곡 표현 금지**
금지어: ~할 수 있습니다, ~일 수 있습니다, ~라고 볼 수 있습니다, 어느 정도, 부분적으로, 다소
→ 단정형으로 서술한다. 조건이 있다면 조건을 먼저 제시한다.
→ 단, 성찰적 불확실성("~일지도 모른다")은 일상 관찰·성찰 유형에서 허용한다.

**④ 불필요한 여유 연결어 금지**
금지어: 전반적으로 볼 때, 일반적으로 말하면, 어떤 면에서 보면, 이러한 측면에서, 결과적으로
→ 근거 → 주장 구조로 직접 연결한다.

**⑤ 추상 명사 중심 문장 지양**
주의어: 중요성, 필요성, 가능성, 효과, 가치, 측면, 부분
→ 동사 중심 문장으로 전환. 장면·행동·결과로 구체화한다.

**⑥ AI 흔적 조합 금지**
부사 + 형용사 + 가능성 표현 + 추상 명사 패턴은 금지한다.

### 금지 요소

- 정보 나열식 구성 (리스트만 던지고 해설 없는 글)
- 결과물에 대한 감상형 표현
- 과도한 반복 설명
- 근거 없는 과장·미사여구
- "오늘은 ~에 대해 이야기해 보겠습니다" 식의 메타 서술
- 제목에 넘버링(1화, 2화) 또는 날짜 사용

### 문체 기준

문체·어조·핵심 규칙은 `references/hongstyle.md`를 따른다. 이 파일은 저자 문체를 담은 예시이며, 내 문체로 바꾸려면 `references/mystyle.md`를 만들고 이 줄의 파일명을 바꾼다.


### 브런치 글 패턴

워드프레스 블로그와 달리, 브런치 글에는 다음 패턴이 적용된다.

**구조적 패턴:**
- 소제목 대신 **Bold 텍스트 + 번호**로 섹션을 나눈다. 예: `**1) 무엇을 찾고자 왔나?**`
- 섹션 사이에 **구분선(---)을 적극 활용**한다. 브런치 에디터의 구분선은 시각적 호흡을 만든다
- H2/H3 마크다운 소제목은 사용하지 않는다 (워드프레스 블로그와 다른 점)
- 이미지는 섹션 사이 또는 설명 직후에 배치한다
- 글 말미에 관련 글(매거진 이전/다음 글)이 자동 연결된다

**번호 리스트 패턴:**
경험이나 사례를 정리할 때, 번호를 붙여 구조화한다. 단순 나열이 아니라 각 항목에 해설을 붙인다.
```
**1) 항목명**
해설 문장. 경험이나 판단 기준을 덧붙인다.

**2) 항목명**
해설 문장.
```

**경험 서사 패턴:**
실제 강의, 집필, 도구 사용 경험에서 출발해 독자에게 기준을 전달한다. "나는 이렇게 했고, 이것이 기준이 되었다"가 글의 기본 구조다.

**외부 링크 처리:**
브런치 내 관련 글은 본문 말미에 배치한다. 외부 URL은 최소화하되, 도구·서비스 소개 시에만 허용한다.

**워드프레스 블로그와의 차이 요약:**

| 항목 | 브런치 (이 스킬) | 워드프레스 블로그 |
|------|-----------------|-------------------|
| 소제목 | Bold 텍스트 + 번호 | H2/H3 마크다운 소제목 |
| TOC(목차) | 없음 | 자동 생성 대응 |
| 구분선 | 적극 사용 | 최소 사용 |
| 줄바꿈 | 문단 단위 | 시적 배치 (강조 문장 독립 줄) |
| 제목 | 20자 이내, 앞 10자 핵심 | 50자 이내, SEO 키워드 포함 |
| 분량 | 1,200~2,000자 | 1,200~2,500자 |
| 내부 링크 | 매거진 연결 (자동) | 본문 내 2~3개 수동 삽입 |
| 종결어미 | 기본값 '~다'체 | 기본값 '~습니다'체 |
| 키워드 | 감정적 키워드 3개 | SEO 태그 2~4개 + 메타설명 |
| 시리즈 | 넘버링 금지, 매거진으로 묶음 | ①②③ 번호, 색인 글 연계 |
