# 네이버 검색 알고리즘 레퍼런스 (naver-search.md)

네이버 블로그 정보글의 검색 노출을 결정하는 핵심 기준을 정리한다. 2026년 기준이며, 알고리즘 세부는 비공개이므로 공개된 일반 원리만 다룬다.

## 목차
- 1. 세 가지 평가 축
- 2. 키워드 선정 절차
- 3. 제목 작성 규칙
- 4. 저품질 회피 규칙
- 5. 체류시간 관리

---

## 1. 세 가지 평가 축

### C-Rank — 출처 신뢰도

블로그(출처)가 특정 주제에서 얼마나 신뢰받는지를 평가한다.

- 한 주제를 꾸준히 다룬 블로그가 그 주제에서 유리하다
- 방문자 반응(체류, 공감, 댓글)이 신뢰도에 반영된다
- 한 글 안에서도 주제 집중도가 평가된다. 한 글에 여러 주제를 섞지 않는다

작성 시사점: 글 하나는 하나의 주제·검색 의도에 집중한다.

### D.I.A.+ — 제목-본문 일관성과 경험

글의 내용이 제목·검색어와 얼마나 일치하는지, 직접 경험·정보가 담겼는지를 평가한다.

- 제목이 약속한 정보를 본문이 충실히 제공하는가
- 단순 키워드 삽입이 아니라 실제 정보·경험이 포함되었는가
- 문서 흐름이 논리적인가

작성 시사점: 제목과 본문 의도를 일치시키고, 직접 경험·실측·후기를 본문에 명시한다.

### 스마트블록 — 검색 의도 세분화

네이버 통합검색은 키워드를 의도별 블록으로 쪼개 보여준다.

- "제주도 카페" → "오션뷰 카페", "디저트 카페", "애견동반 카페" 등으로 분화
- 대형 키워드 하나가 아니라 세분화된 의도 하나를 정확히 겨냥해야 블록에 진입한다
- 경쟁이 낮은 롱테일 의도부터 공략하는 편이 진입에 유리하다

작성 시사점: 핵심 키워드를 네이버에 직접 검색해 스마트블록 주제를 확인하고, 그중 하나를 글의 검색 의도로 확정한다.

## 2. 키워드 선정 절차

1. 주제에서 독자가 실제 검색할 핵심 키워드 후보를 3~5개 뽑는다
2. 각 후보를 네이버 통합검색에 넣고 스마트블록 구성을 확인한다
3. 경쟁 강도와 검색 의도 적합도를 따져 핵심 키워드 1개를 확정한다
4. 핵심 키워드를 보조하는 연관어 2~3개를 보조 키워드로 정한다
5. 키워드 배치 계획을 세운다

### 키워드 배치 위치

| 위치 | 핵심 키워드 | 보조 키워드 |
|------|------------|------------|
| 제목 | 앞부분에 1회 | 가능하면 1개 |
| 첫 단락(도입) | 1회 | - |
| 소제목 | 1곳 이상 | 분산 배치 |
| 본문 | 자연스러운 문맥 내 | 자연스러운 문맥 내 |

밀도 목표를 정해 기계적으로 채우지 않는다. 문맥에 맞을 때만 넣는다.

---

## 3. 제목 작성 규칙

- 핵심 키워드를 제목 앞부분에 포함한다
- 25~35자 권장(모바일 검색 결과에서 잘리지 않는 범위)
- 제목이 약속한 정보를 본문이 반드시 제공한다(낚시 금지)
- 숫자·연도·대상 조건을 넣으면 클릭률이 오른다

### 제목 유형

| 유형 | 예시 | 적합한 글 |
|------|------|----------|
| 방법형 | "테슬라 모델3 집에서 완속충전하는 순서" | 방법·튜토리얼 |
| 숫자형 | "클로드 코워크 초보가 먼저 할 3가지" | 정리·가이드 |
| 비교형 | "클로드와 챗GPT, 글쓰기엔 뭐가 나을까" | 비교·선택 |
| 후기형 | "책쓰기 강의 9주 직접 들어본 후기" | 후기·체험 |
| 질문형 | "코워크로 보고서 쓰면 시간이 줄어들까" | 검색 의도 일치형 |

---

## 4. 저품질 회피 규칙

다음은 검색 노출에서 불이익으로 이어진다.

- 키워드를 부자연스럽게 반복 삽입
- 제목과 본문 의도 불일치(낚시성 제목)
- 직접 경험 없이 타 글을 짜깁기한 내용
- 정보 없이 사진·감탄사만 채운 구성
- 광고성 문구 과다
- 한 글에 무관한 여러 주제 혼합

작성 시사점: AI가 생성한 일반론만으로 채우지 말고, 직접 경험·실측·현장 관찰을 반드시 섞는다.

---

## 5. 체류시간 관리

독자가 글에 머무는 시간은 평가에 반영된다.

- 도입부에서 검색 의도를 즉시 적중시켜 이탈을 막는다
- 사진과 소제목으로 스크롤 호흡을 만든다
- 독자가 이 글을 읽은 뒤 같은 주제로 다시 검색하지 않도록 의도 하나를 완결한다
- 글 끝에 관련 글이나 다음 단계를 안내해 추가 체류를 유도한다
