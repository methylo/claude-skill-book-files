# 문체·톤 가이드 (tone-guide.md)

네이버 정보글의 문체·어휘 기준. 공통 집필 원칙(SKILL.md)을 보강한다.

## 목차
- 1. 기본 문체
- 2. 정보글 톤
- 3. 금지어와 대체
- 4. 좋은 문장 / 나쁜 문장

---

## 1. 기본 문체

- 종결어미는 '~합니다'체로 고정한다
- 축약형을 쓰지 않는다 ("됐습니다" → "되었습니다", "안 됨" → "되지 않음")
- 한 문장에 하나의 정보·하나의 판단만 담는다
- 능동형을 기본으로 한다
- 감탄형·감정 과잉 표현을 쓰지 않는다 ("정말 너무 좋아요!" 금지)

---

## 2. 정보글 톤

네이버 정보글은 설명과 경험의 결합이다. 유형별로 톤을 조정한다.

| 글 유형 | 톤 | 특징 |
|---------|-----|------|
| 방법·튜토리얼 | 안내자 | 순서를 나누고 각 단계의 기준을 명시한다 |
| 비교·선택 | 평가자 | 비교 기준을 먼저 세우고 상황별 선택을 제시한다 |
| 후기·체험 | 기록자 | 직접 경험을 좋았던 점·아쉬운 점으로 나눠 기록한다 |
| 정보 정리 | 정리자 | 흩어진 정보를 기준으로 묶어 정돈한다 |
| Q&A 해설 | 응답자 | 독자의 질문을 그대로 받아 답을 명확히 한다 |

공통: 가르치지 않되 이끈다. 독자와 같은 문제를 함께 보는 위치를 취한다.

---

## 3. 금지어와 대체

| 분류 | 금지어 | 대체 방향 |
|------|--------|----------|
| 과장 형용사 | 혁신적인, 획기적인, 완벽한, 최고의, 강력한, 탁월한 | 수치·비교·사례로 설명 |
| 모호한 부사 | 매우, 굉장히, 쉽게, 빠르게, 간편하게, 효율적으로 | 시간·단계·수치·조건으로 대체 |
| 추측·완곡 | ~할 수 있습니다, ~일 수 있습니다, 어느 정도, 다소 | 단정형. 조건은 앞에 제시 |
| 여유 연결어 | 전반적으로 볼 때, 결과적으로, 이러한 측면에서 | 근거→주장 직접 연결 |
| 추상 명사 중심 | 중요성, 필요성, 가능성, 효과, 가치 | 동사 중심 문장으로 전환 |

위반 발견 시 자가 수정 후 응답하고, 응답 말미에 1줄 자가 수정 메모를 남긴다.

## 4. 좋은 문장 / 나쁜 문장

### 나쁜 문장

```
이 도구는 매우 강력하고 혁신적이어서 업무 효율을 크게 높여줄 수 있습니다.
```

문제: 과장 형용사(강력한·혁신적인), 모호한 부사(매우·크게), 완곡 표현(높여줄 수 있습니다), 추상 명사(효율).

### 좋은 문장

```
이 도구로 보고서 초안 작성 시간이 2시간에서 40분으로 줄었습니다.
```

개선: 수치로 결과를 제시. 단정형 종결. 동사 중심.

### 나쁜 문장

```
전반적으로 볼 때 완속충전이 어느 정도 경제적인 측면이 있다고 볼 수 있습니다.
```

### 좋은 문장

```
완속충전은 심야 요금 기준 1회 충전에 약 5,000원입니다. 급속충전보다 절반 이하입니다.
```
