# 예시: 방법·튜토리얼형 완성 글 (sample-howto.md)

아래는 방법·튜토리얼형 정보글의 완성 예시다. 평문 형식, 모바일 문단 분리, 사진 마커, 검색 의도형 소제목, 경험 근거를 모두 반영했다. 분석 포인트가 뒤에 붙는다.

---

## 완성 글 (평문)

```
제목: 테슬라 모델3 집에서 완속충전하는 순서 (2026 초보용)

테슬라 모델3를 받고 가장 먼저 막히는 건 충전입니다.

급속충전소는 알겠는데, 집에서 완속으로 어떻게 충전하는지가 막막합니다. 저도 인도받은 첫 주에 같은 고민을 했습니다.

이 글은 아파트 지하주차장 완속충전기 기준으로, 앱 연결부터 충전 시작까지 순서대로 정리했습니다.

[이미지: 모델3 충전 포트와 완속충전 커넥터]

시작 전 알아둘 것

완속충전은 7kW 기준 0%에서 80%까지 약 8시간이 걸립니다. 심야에 걸어두고 아침에 빼는 방식이 기본입니다.

요금은 심야 기준 1회 충전에 약 5,000원입니다. 급속의 절반 이하입니다.

회원카드 또는 앱이 필요합니다. 저는 환경부 카드와 단지 충전기 앱 두 가지를 씁니다.

1단계 — 충전기 회원 인증

충전기 화면에 카드를 태그하거나 앱에서 충전기 번호를 입력합니다.

인증이 끝나면 화면에 '커넥터를 연결하세요'가 뜹니다.

[이미지: 충전기 인증 화면]

2단계 — 커넥터 연결

차량 충전 포트 커버를 손으로 누르면 열립니다. 커넥터를 끝까지 밀어 넣습니다.

딸깍 소리와 함께 포트 주변 표시등이 녹색으로 깜빡이면 정상 연결입니다.

[이미지: 커넥터 연결 후 녹색 표시등]

3단계 — 충전 시작 확인

차량 화면 또는 테슬라 앱에서 충전 시작과 예상 완료 시간을 확인합니다.

앱에서 충전 한도를 80%로 설정해 두면 배터리 관리에 낫습니다.

[이미지: 테슬라 앱 충전 화면]

자주 막히는 지점과 해결

인증을 했는데 충전이 시작되지 않으면, 커넥터가 끝까지 들어가지 않은 경우가 대부분입니다. 한 번 빼서 다시 끝까지 밀어 넣습니다.

표시등이 빨간색이면 충전기 자체 오류입니다. 다른 충전기로 옮기는 편이 빠릅니다.

마무리

순서는 인증, 연결, 시작 확인 세 가지입니다.

처음 한 번만 해보면 다음부터는 1분이면 끝납니다. 심야 요금 시간대에 맞춰 예약 충전을 걸어두면 요금이 더 줄어듭니다.
```

## 분석 포인트

- 제목: 핵심 키워드("모델3 완속충전") 앞부분 배치, 숫자·연도·대상("2026 초보용") 포함, 32자
- 도입: 인사말 없이 검색 의도("집에서 완속 충전 방법")로 즉시 진입
- 경험 근거: "저도 첫 주에", "환경부 카드와 단지 앱 두 가지" — D.I.A.+ 경험 평가 충족
- 소제목: 모두 평문·행동형("1단계 — 충전기 회원 인증")
- 문단: 2~3문장, 의미 단위 빈 줄 분리
- 사진: 소제목 블록마다 1장씩 마커 배치
- 평문: 마크다운 기호 없음. 단계는 "1단계 —"로 평문 표기
- 금지어: 과장 형용사·모호한 부사·완곡 표현 없음. 수치("약 8시간", "5,000원")로 대체
- 마무리: 요약이 아니라 핵심 3단계 압축 + 다음 행동(예약 충전)
