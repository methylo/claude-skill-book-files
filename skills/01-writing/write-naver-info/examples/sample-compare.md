# 예시: 비교·선택형 완성 글 (sample-compare.md)

비교·선택형 정보글의 완성 예시. 평문 환경에서 표 대신 대조 문장으로 비교를 처리한 점에 주목한다.

---

## 완성 글 (평문)

```
제목: 클로드와 챗GPT, 글쓰기엔 뭐가 나을까 (실사용 비교)

글쓰기 작업에 AI를 쓰려는데 클로드와 챗GPT 중 뭘 골라야 할지 검색하는 분이 많습니다.

저는 강의 자료와 책 원고를 두 도구로 1년 넘게 써봤습니다. 결론부터 말하면, 긴 글의 일관성은 클로드, 빠른 초안과 검색 결합은 챗GPT가 낫습니다.

이 글은 글쓰기 한 가지 기준으로만 비교합니다.

[이미지: 두 도구 화면 나란히]

비교 기준

세 가지로 봤습니다. 긴 글의 문맥 유지, 문체 지정 반영, 수정 지시 정확도입니다.

가격이나 이미지 생성 같은 다른 기능은 이 글에서 다루지 않습니다.

클로드의 특징과 적합한 상황

긴 원고에서 앞 내용을 끝까지 기억하는 정도가 안정적입니다. 책 한 장(章)을 통째로 다듬을 때 문맥이 흔들리지 않았습니다.

문체를 지정하면 그 결을 끝까지 유지하는 편입니다.

[이미지: 클로드로 책 원고 수정한 화면]

긴 글, 일관된 문체가 필요한 작업에 맞습니다.

챗GPT의 특징과 적합한 상황

짧은 초안을 여러 개 빠르게 뽑을 때 반응이 가볍습니다. 검색을 붙여 최신 정보를 끌어오는 작업이 매끄럽습니다.

다만 긴 글에서는 앞부분 지시를 놓치는 경우가 있었습니다.

[이미지: 챗GPT로 초안 여러 개 뽑은 화면]

짧은 글 여러 개, 자료 조사 결합 작업에 맞습니다.

상황별 선택 가이드

책 원고나 보고서처럼 길고 문체가 중요한 글은 클로드를 권합니다.

블로그 초안을 여러 버전으로 빠르게 만들거나 최신 자료를 함께 찾아야 하면 챗GPT를 권합니다.

둘 다 쓴다면, 초안은 챗GPT, 마무리 다듬기는 클로드로 나누는 방식도 됩니다.

마무리

선택 기준은 글의 길이와 문체 일관성입니다.

긴 글은 클로드, 빠른 초안은 챗GPT로 나누면 둘 중 하나를 고르는 고민이 줄어듭니다.
```

---

## 분석 포인트

- 제목: 핵심 키워드("클로드 챗GPT 글쓰기") + 비교형, "실사용" 신뢰 신호, 28자
- 도입: 결론 먼저 제시("긴 글은 클로드, 빠른 초안은 챗GPT") — 체류시간 관리
- 비교 처리: 평문 환경이므로 표 대신 "A는 ~, B는 ~" 대조 문장 사용
- 경험 근거: "1년 넘게", "책 한 장을 통째로" — D.I.A.+ 충족
- 범위 한정: "글쓰기 한 가지 기준으로만" — 주제 집중(C-Rank)
- 소제목: 평문, 검색 의도형
- 문단: 2~3문장, 빈 줄 분리
- 금지어 없음, 수치·경험으로 단정
- 마무리: 판단 기준(길이·문체 일관성)으로 정렬
```
