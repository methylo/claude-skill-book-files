# 정보글 유형별 구조 템플릿 (post-structure.md)

네이버 정보글 5개 유형의 구조 템플릿. 소제목은 모두 평문·검색 의도형으로 작성한다. 사진 마커 위치를 함께 표시했다.

---

## 유형 1. 방법·튜토리얼형

독자가 "어떻게 하는가"를 검색할 때.

```
도입 (3~4문장): 검색 의도 확인 + 이 글이 답하는 범위
[이미지: 대표 사진]

소제목: 시작 전 알아둘 것
  - 전제 조건, 준비물

소제목: 1단계 — (행동)
[이미지: 1단계 화면]
소제목: 2단계 — (행동)
[이미지: 2단계 화면]
소제목: 3단계 — (행동)
[이미지: 3단계 화면]

소제목: 자주 막히는 지점과 해결
  - 실제 겪은 문제 + 해결법

마무리 (3~5문장): 핵심 단계 압축 + 다음 행동
```

---

## 유형 2. 비교·선택형

독자가 "A vs B, 뭐가 나은가"를 검색할 때.

```
도입: 무엇과 무엇을 왜 비교하는가
[이미지: 비교 대상 나란히]

소제목: 비교 기준 제시 (가격·기능·난이도 등)

소제목: A의 특징과 적합한 상황
[이미지: A 화면/제품]
소제목: B의 특징과 적합한 상황
[이미지: B 화면/제품]

소제목: 상황별 선택 가이드
  - "이런 사람은 A, 이런 사람은 B"

마무리: 결론 한 줄 + 판단 기준
```

비교 항목이 많으면 표 대신 평문으로 "A는 ~, B는 ~" 대조 문장을 쓴다(에디터 평문 환경).

---

## 유형 3. 후기·체험형

독자가 "써본 사람 후기"를 검색할 때. D.I.A.+ 경험 평가에 가장 유리한 유형.

```
도입: 어떤 상황에서 이걸 쓰게 됐는가
[이미지: 대표 사진]

소제목: 실제 사용·방문 과정
[이미지: 과정 사진 2~3장]

소제목: 좋았던 점
  - 직접 경험 근거
소제목: 아쉬운 점
  - 직접 경험 근거

소제목: 이런 사람에게 추천

마무리: 종합 평가 + 추천 기준
```

---

## 유형 4. 정보 정리형

독자가 "~ 총정리, ~ 종류"를 검색할 때.

```
도입: 흩어진 정보를 왜 정리하는가
[이미지: 대표 사진]

소제목: 분류 기준
소제목: 항목 1 정리
소제목: 항목 2 정리
소제목: 항목 3 정리
[각 항목마다 이미지]

소제목: 정리 요약 (핵심만 다시)

마무리: 독자가 가져갈 판단 기준
```

---

## 유형 5. Q&A 해설형

독자가 구체적 질문을 검색할 때.

```
도입: 독자의 질문을 그대로 제시
[이미지: 관련 사진]

소제목: 결론부터
소제목: 왜 그런가 (근거)
소제목: 예외·주의할 상황

마무리: 한 줄 답 + 적용 기준
```

---

## 공통 규칙

- 소제목 3~6개
- 소제목과 소제목 사이 본문 3~5단락
- 소제목 블록마다 사진 1장 이상
- 문단 2~3문장, 의미 단위 빈 줄 분리
- 핵심 키워드를 제목·첫 단락·소제목 1곳 이상에 배치
- 본문 전체 평문(마크다운 기호 없음)
