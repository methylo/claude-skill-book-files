# 발행 메타 템플릿 (meta-template.md)

Step 5 발행 준비에서 사용한다.

---

## 발행 메타 정보 양식

```
제목: (핵심 키워드 포함, 25~35자)

핵심 키워드: 
보조 키워드: , , 

검색 의도(스마트블록): 

태그 (5~10개): #___ #___ #___ #___ #___

카테고리: 

대표 사진 방향: (콘셉트 한 줄. 직접 생성하지 않음)

본문 사진 수: 약 ___장

분량: 약 ___자
```

---

## 네이버 블로그 발행 체크리스트

```
- 제목 (핵심 키워드 포함, 25~35자, 제목-본문 의도 일치)
- 대표 사진 (썸네일)
- 본문 사진 5~15장 배치
- 태그 5~10개 (핵심·보조 키워드 + 연관어)
- 카테고리 지정
- 키워드 제목·첫단락·소제목 배치 확인
- 키워드 과다 반복 없음 (저품질 회피)
- 직접 경험·실측·후기 포함 (D.I.A.+)
- 평문 확인 (마크다운 기호 #, **, - 없음)
- 종결어미 '~합니다'체 통일
- 분량 1,500~2,500자
- [이미지] 마커 → 실제 사진 삽입 안내로 정리
- 발행
```

---

## 태그 선정 기준

- 핵심 키워드 1개 + 보조 키워드 2~3개를 태그에 포함한다
- 연관 검색어·동의어를 추가한다
- 5~10개 범위. 무관한 인기 태그를 끼워 넣지 않는다(저품질 신호)

---

## 대표 사진(썸네일) 방향 제안 규칙

- 글의 핵심 장면·제품·결과를 담은 사진을 권장한다
- 텍스트 오버레이가 필요하면 제목 핵심 키워드를 넣는다
- 콘셉트만 제안하고 직접 생성하지 않는다(요청 시 image-thumbnail 스킬 안내)
