# bizplan-research — K-Startup 사업계획서 사전 리서치 스킬

## 스킬 목적

사업계획서 본문을 작성하기 전 단계에서, 평가위원이 요구하는 표준 데이터(시장 규모·경쟁사·정책·자금 규모 등)를 체계적으로 수집합니다. 산출물은 `bizplan-kstartup`의 12개 소항목 슬롯에 바로 들어가도록 구조화된 5종 카드 + 고정 스키마 JSON입니다.

## 참조 파일

- `references/card-templates.md` — P·R·S·C·U 5종 카드 고정 양식 (v1.1)
- `references/slot-mapping.md` — 카드 → bizplan-kstartup 12개 소항목 매핑 + 교차 검증 규칙
- `references/search-prompts.md` — 카드별 web_search 질의문 템플릿
- `references/bizplan-input-schema.md` — bizplan-kstartup 입력 JSON 스키마 (v1.1 신규)

## 전체 흐름 (v1.1 개편 — 5단계)

```
Step 1. 사업 아이템 정의 + U-카드 체크리스트 제시
   ↓
Step 2. P·R·S·C 4종 카드 리서치 생성 (병렬) + U-카드 사용자 입력 수집
   ↓
Step 2.5. 교차 검증 (필수 3항목 + 권장 2항목) + 충족률 리포트
   ↓
Step 3. 사용자 검토·보강 (누락 슬롯 재검색·재입력)
   ↓
Step 4. bizplan-kstartup 입력 JSON 변환 (bizplan-input-schema 준수)
```

각 Step 완료 시 결과물을 대화창 텍스트로 제공하고, 사용자 확인 후 다음 Step으로 진행합니다.

## 5종 카드 구조

### P-카드 (Problem & Market)

목표: 문제의 규모와 시장을 수치로 뒷받침합니다.

```
슬롯:
  1. 시장 규모 (TAM/SAM/SOM) — 등급 A 1건 이상 필수
  2. 고객 통계 — 타깃 인구·분포, 핵심 수치 3건
  3. 정책·규제 환경 — 관련 정책 2~3건 (명칭·시행 시기·영향)
  4. 문제 사례 — 실제 사례 2~3건
```

### R-카드 (Reference Case)

목표: 유사 사업의 성공·실패 사례로 실현 가능성을 보강합니다.

```
슬롯:
  1. 국내 유사 사례 3건 — 기업명·사업 내용·매출·사용자 규모
  2. 해외 유사 사례 2건 — 기업명·국가·사업 내용·규모
  3. 성공 요인 3가지
  4. 실패·리스크 요인 2가지
```

### S-카드 (Scale-up Reference)

목표: 자금 계획과 시장 진입 전략의 외부 근거를 확보합니다.

```
슬롯:
  1. 동종 업계 평균 자금 규모 (초기·마케팅·인건비·총액)
  2. 정부지원 사업 매칭 후보 3건 — 사업명·주관기관·상한·접수 시기
  3. 시장 진입 채널 사례 3건
  4. 수익 모델 벤치마크 2건
```

### C-카드 (Competitor Analysis)

목표: 경쟁사 3~5개를 동일한 축으로 비교해 차별점을 명확히 합니다.

```
슬롯:
  1. 경쟁사 목록 3~5개
  2. 비교 축 6가지 — 가격 / 기능 / 타깃 / 채널 / 강점 / 약점
  3. 자사 위치 분석
  4. 차별점 3가지
```

### U-카드 (User Input Required) — v1.1 신규

목표: 리서치로 알 수 없는 사용자 전용 정보를 선제 수집합니다.

```
슬롯:
  1. 대표자 정보 — 이력·학력·창업 동기
  2. 팀 구성 — 역할·역량·합류 시기
  3. 보유 자산 — 특허·MVP·개발 단계
  4. 외부 네트워크 — 자문·협력·MOU
  5. 사업 선호 — 희망 정부지원·사업 기간
  6. 리스크 인식 — 위험 요소·검증된 강점
```

U-카드는 Step 1에서 체크리스트로 먼저 제시하고, Step 2 리서치와 병렬로 사용자가 답합니다.

## 출처 등급 시스템 (v1.1 신규)

| 등급 | 출처 | 활용 범위 |
|------|------|-----------|
| A | 공공·정부 통계 (통계청·KOSIS·중기부·KDI·산업연구원) | 핵심 수치 필수 |
| B | 민간 리서치·협회 자료 | A 없을 때 대체 |
| C | 언론·IR 자료 | 보조 근거 (단독 사용 금지) |

핵심 수치(TAM·고용·정책)는 등급 A 1건 이상 확보를 강제합니다. 확보하지 못한 슬롯은 `critical_slots_missing_A`에 기록해 bizplan-kstartup에 경고로 전달합니다.

## 교차 검증 규칙 (v1.1 신규)

Step 2.5에서 자동 실행. 카드 간 논리 모순을 탐지합니다.

### 필수 3항목 (위반 시 실행 중단)

1. **규모 정합성**: P-SAM ≥ C-경쟁사 매출 합 × 1.2
2. **타깃 정합성**: P-고객 통계(연령·직군) ∩ C-경쟁사 타깃 ≠ ∅
3. **정책 정합성**: P-정책 시행 시기 ≤ S-정부지원 접수 시기

### 권장 2항목 (경고만 출력)

4. **자금 정합성**: S-평균 자금 ≥ U-희망 지원금 × 0.6
5. **단계 정합성**: U-개발 단계 = R-벤치마크 사례의 유사 단계

결과는 인덱스 파일과 JSON `cross_validation` 필드 양쪽에 기록합니다.

## 충족률 리포트 (v1.1 신규)

Step 2·Step 2.5·Step 3 종료 시마다 출력합니다.

```
P-카드: 12/13 (TAM 출처 A등급 1건 부족)
R-카드: 10/10 ✓
S-카드: 8/10 (정부지원 2건·채널 1건 부족)
C-카드: 15/18 (비교 축 3행 공란)
U-카드: 17/20 (대표자 이력 2건·특허 번호 1건 부족)

전체: 62/71 (87.3%) → 임계 90% 미만. 재검색 권장
```

90% 미만이면 bizplan-kstartup 진입 전 재검색·재입력을 제안합니다.

## Step 간 전환 규칙

- Step 1 완료 → 리서치 계획 + U-카드 체크리스트 제시 → 사용자 승인 후 Step 2
- Step 2 완료 → 5종 카드 초안 + 충족률 리포트 출력 → Step 2.5로 자동 연결
- Step 2.5 완료 → 교차 검증 결과 + 수정 필요 항목 보고 → 사용자 확인 후 Step 3
- Step 3 완료 → 보강 리서치·재입력 반영 후 최종 5종 카드 확정 → Step 4
- Step 4 → `bizplan-input-schema.md` 구조대로 JSON 변환해 저장

## 문서 구조 규칙

### 카드 .md 파일 구성

```
# BR_P-카드_{사업명}_{YYMMDD}.md

> 사업 아이템 / 타깃 / 업종 / 작성일 / 주요 출처 등급

## 1. 시장 규모 (TAM/SAM/SOM)
- 표 (등급 컬럼 포함)

## 2. 고객 통계
## 3. 정책·규제 환경
## 4. 문제 사례

## 참고 자료 (등급 병기)
```

P·R·S·C·U 카드 모두 동일한 구조를 따릅니다.

### 파일명 규칙

```
BR_{카드종류}-카드_{사업명}_{YYMMDD}.md

예: BR_P-카드_돌봄앱_260424.md
    BR_U-카드_돌봄앱_260424.md
```

## 문체·서술 기준

- 종결어미: **~합니다체** (본문 작성 시 카드 내용을 옮길 때 `bizplan-kstartup`의 `~함·~임` 체로 변환)
- 문장: 사실 기반 서술. 추론·의견 최소화
- 수치: 반드시 출처 + 등급 병기 (`(출처: 통계청 2024, 등급: A)`)
- 금지 표현: 혁신적인·획기적인·완벽한·매우·쉽게·빠르게
- 추상 형용사·모호 부사 사용 금지

## Step별 작성 지침

### Step 1. 사업 아이템 정의 + U-카드 체크리스트

입력받는 정보:
- 사업 아이템 한 줄 정의 (30자 이내)
- 핵심 키워드 3~5개
- 타깃 고객군 초안 (연령·직군·상황)
- 창업 유형 (예비·초기·재도전)
- 업종 (IT서비스·제조·소상공인·기술기반 등)

출력:
- 리서치 범위 요약 + 4종 카드별 예상 검색 키워드
- **U-카드 체크리스트 (6개 섹션)** — 사용자가 Step 2 기간 중 병렬로 답변

### Step 2. 5종 카드 생성

P·R·S·C 4종: web_search·web_fetch 실행. 카드별 검색 질의문은 `references/search-prompts.md` 템플릿 사용.

**검색 전략**
- P-카드: 통계청·정부 보고서·산업 협회 → A등급 우선
- R-카드: 투자 정보 사이트·뉴스·IR 자료 → B·C등급 혼합
- S-카드: K-Startup 포털·중진공·지자체 창업지원 공고 → A등급
- C-카드: 기업 홈페이지·앱스토어·리뷰 사이트 → B·C등급

**검증 기준**
- 수치는 최근 3년 이내만 채택
- 출처는 기관명 + 도메인 + 등급 명시
- 상호 모순되는 수치는 양쪽 병기 후 등급 높은 쪽 채택

U-카드: 사용자 입력 수집. Step 1에서 제시한 체크리스트의 답변을 카드 형식으로 정리.

출력: 5종 카드 초안 + **충족률 리포트**

### Step 2.5. 교차 검증 (v1.1 신규)

slot-mapping.md의 교차 검증 규칙 실행:

- 필수 3항목 중 하나라도 실패 → **실행 중단**, 사용자에게 수정 요청
- 권장 2항목 실패 → 경고 출력 후 계속

결과를 `BR_인덱스_*.md` 교차 검증 섹션에 기록.

### Step 3. 사용자 검토·보강

카드별 검토 체크리스트:
- [ ] 모든 슬롯이 채워졌는가 (충족률 90% 이상)
- [ ] 수치에 출처 + 등급이 있는가
- [ ] 핵심 수치에 A등급 1건 이상인가
- [ ] 경쟁사는 최소 3개인가
- [ ] U-카드 필수 항목이 모두 입력되었는가
- [ ] 교차 검증 필수 3항목이 모두 통과인가

부족 항목이 있으면 해당 슬롯만 재검색·재입력·보강.

### Step 4. bizplan-kstartup 입력 JSON 변환

`references/bizplan-input-schema.md`의 스키마를 그대로 따라 JSON 생성.

필수 필드:
- `meta`, `slots` (12개), `tables` (T-NN), `source_grades`, `cross_validation`, `fulfillment_report`, `missing_slots`

출력 파일: `bizplan_input_{사업명}_{YYMMDD}.json`

### Step 5. 다음 단계 안내 (자동 출력)

JSON 변환 완료 후, 사용자에게 다음 메시지를 자동 출력합니다.

```
리서치가 완료되었습니다.
산출물 위치: {작업 폴더}
- BR_*.md 5종 카드
- bizplan_input_{사업명}_{YYMMDD}.json (다음 단계 입력)

본문 작성을 이어서 하시려면 다음 트리거를 입력하세요:
"bizplan-kstartup 스킬로 이어서 진행해줘"

같은 폴더의 bizplan_input_*.json 파일을 자동으로 읽어
PSST 12개 소항목 슬롯을 자동 매핑한 뒤 본문 작성을 시작합니다.
```

## 사용자 입력 부족 대응

각 Step에서 필수 정보가 누락되면:
1. 누락 항목을 구체적으로 질문 (선택지 3개 이내, 한 번에 하나)
2. 업종 프리셋(IT서비스·소상공인·기술기반) 중 가장 가까운 것 제시
3. 사용자 확정 후 플레이스홀더 처리 (`[⚠ 추가 리서치 필요: {항목}]` 또는 `[⚠ 사용자 입력 필요: {항목}]`)
4. `missing_slots` 배열에 항목 추가

## 최종 출력

- 경로: 사용자 지정 폴더 또는 `00 일정별 강의/` 하위 강의별 폴더
- 파일 5개: `BR_P-카드_*.md`, `BR_R-카드_*.md`, `BR_S-카드_*.md`, `BR_C-카드_*.md`, `BR_U-카드_*.md`
- 통합 인덱스: `BR_인덱스_*.md` (5종 카드 링크 + 충족률 + 교차 검증 결과)
- bizplan-kstartup 입력: `bizplan_input_*.json` (스키마 v1.1 준수)

## 스킬 파이프라인

```
bizplan-research v1.1 (BR_ 카드 5종 + input JSON)
     ↓ 스키마 계약
bizplan-kstartup (.docx 본문)
     ↓ 핵심 추출
bizplan-kstartup-pitch (.pptx 피치덱)
     ↓ 변환 (필요 시)
hwpx (제출용 .hwpx)
```

각 단계는 이전 단계 산출물을 **스키마 기반 계약**으로 받아 다음 단계로 넘깁니다. 중간 개입 없이 자동 연결됩니다.

## 자가 평가 체크리스트 (v1.1)

산출물 완성 후 아래 항목을 점검합니다. 미달 항목이 있으면 해당 항목만 수정 후 재점검(최대 2회).

### 콘텐츠 품질
- [ ] 금지어 위반 0건 (혁신적인·획기적인·완벽한·매우·쉽게·빠르게 등)
- [ ] 추상 형용사·모호 부사 0건
- [ ] AI 흔적 조합 0건
- [ ] 모든 수치에 출처 + 등급 병기
- [ ] 한국어 산출물은 한국어로 작성

### 구조 완성도
- [ ] 5종 카드 모두 생성 (P·R·S·C·U)
- [ ] 경쟁사 최소 3개 확보
- [ ] 시장 규모 3계층(TAM/SAM/SOM) 모두 확보
- [ ] 핵심 수치에 A등급 출처 1건 이상
