# slot-mapping.md — 5종 카드 → bizplan-kstartup 12개 소항목 매핑 (v1.1)

bizplan-research가 생성한 5종 카드(P·R·S·C·U)를 bizplan-kstartup의 PSST 12개 소항목 슬롯에 자동 매핑하는 규칙.

## 매핑 개요

```
P-카드 → 1-1, 1-2, 1-3
R-카드 → 1-3 보강, 2-2 보강
S-카드 → 3-1, 3-2, 3-3
C-카드 → 2-1, 2-3
U-카드 → 2-1 보강, 4-1, 4-2, 4-3 (사용자 입력 전용)
```

## 매핑 우선순위

### 자동 채움 (리서치로 충족)

- 1-2 외부 환경: 5개 슬롯 모두
- 1-3 목표시장: 6개 슬롯 중 5개
- 2-3 차별화: 전체
- 3-1 자금 계획: 대부분 (1순위 희망은 U-카드)
- 3-2 진입 전략: 4개 슬롯 중 3개

### 보강 채움 (리서치 + U-카드 혼합)

- 1-1 동기·목적: 배경 서사는 U-카드 1, 근거는 P-카드
- 2-1 현황: 기술 수준은 C-카드, 특허·MVP는 U-카드
- 2-2 실현 방안: 패턴은 R-카드, 단계는 U-카드

### U-카드 전용 (사용자 입력)

- 4-1 대표자·팀원 (U-카드 1·2)
- 4-2 외부 협력 네트워크 (U-카드 4)
- 4-3 중장기 인력 운용 (U-카드 4·5)

## 교차 검증 규칙 (v1.1 신규)

Step 2 완료 후 Step 3 진입 전, 카드 간 모순을 자동 점검합니다.

### 필수 3항목

1. **규모 정합성**: P-SAM ≥ C-카드 경쟁사 매출 합 × 1.2
   - 위반 시: 시장 규모 재산출 또는 SAM 재정의
2. **타깃 정합성**: P-카드 고객 통계(연령·직군) ∩ C-카드 경쟁사 타깃 ≠ ∅
   - 위반 시: 경쟁사를 재선정하거나 타깃 재정의
3. **정책 정합성**: P-카드 정책 시행 시기 ≤ S-카드 정부지원 접수 시기
   - 위반 시: 시행 예정 정책 또는 최신 공고로 교체

### 권장 2항목

4. **자금 정합성**: S-카드 총 초기 자금 평균 ≥ U-카드 1순위 희망 사업 지원금 상한 × 0.6
5. **단계 정합성**: U-카드 개발 단계 = R-카드 벤치마크 사례의 유사 단계

검증 결과는 `BR_인덱스_*.md`의 "교차 검증 결과" 섹션에 체크 상태로 기록합니다.

## 충족률 리포트 (v1.1 신규)

Step 2·Step 3 종료 시마다 출력합니다.

```
[충족률 리포트 — YYYY-MM-DD]
P-카드: 12/13 (TAM 출처 A등급 1건 부족)
R-카드: 10/10 ✓
S-카드: 8/10 (정부지원 2건·채널 1건 부족)
C-카드: 15/18 (비교 축 3행 공란)
U-카드: 17/20 (대표자 이력 2건·특허 번호 1건 부족)

전체 충족률: 62/71 (87.3%)
권장 조치: 90% 미만 → 해당 슬롯 재검색 또는 사용자 추가 입력
```

카드별 분모는 템플릿의 표 행 수·불릿 수 기준이며, 고정값입니다.

## 변환 규칙

### 종결어미 변환

```
bizplan-research: ~합니다체 (~합니다, ~있습니다)
bizplan-kstartup: ~함·~임 체 (사업계획서 서술체)

변환 예:
"시장 규모는 5조 원입니다" → "시장 규모는 5조 원임"
"고객이 증가하고 있습니다" → "고객이 증가하고 있음"
```

### 출처 처리

리서치 카드의 출처는 bizplan-kstartup으로 넘어갈 때 각주 또는 본문 괄호 처리:

```
리서치: "5조 원 (출처: 통계청 2024, 등급: A)"
본문: "시장 규모는 5조 원임(통계청, 2024)."
```

등급 정보는 본문에 노출하지 않고 `missing_sources_check` 내부 필드로만 보관합니다.

### 표 삽입

카드의 표는 bizplan-kstartup의 T-NN 표 양식에 그대로 삽입. 열·행 순서와 헤더 라벨은 표 양식의 정의를 따릅니다.

## 누락 슬롯 처리

Step 3 검토 시 매핑되지 않은 슬롯은 `[⚠ 추가 리서치 필요: {슬롯명}]` 또는 `[⚠ 사용자 입력 필요: {슬롯명}]`으로 구분 표기. Step 4 JSON 변환 시 `missing_slots` 배열에 포함합니다.
