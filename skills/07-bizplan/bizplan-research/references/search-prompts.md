## 검색 실행 규칙

### 순서

1. 카드별 1·2·3·4 슬롯을 차례로 검색
2. 각 슬롯당 최소 3개 소스 교차 확인
3. 수치·날짜가 다를 경우 가장 최근 + 가장 공신력 있는 소스 채택

### 필터

- 3년 이상 오래된 자료는 보조 참고로만 사용
- 블로그·위키 단독 출처는 재검증 필요
- 광고·홍보성 자료는 제외

### 기록

각 카드 하단 "참고 자료" 섹션에 다음 형식으로 정리:

```
## 참고 자료
- {제목}: {URL} (조회 {날짜})
- {제목}: {URL} (조회 {날짜})
```

### 실패 대응

검색 결과가 부족한 슬롯은 `[⚠ 자료 부족: {슬롯명}]`으로 표기하고 Step 3에서 사용자에게 대안을 제안:

- 대안 1: 사용자 직접 입력
- 대안 2: 유사 업종 데이터로 추정
- 대안 3: 해당 슬롯 생략 (본문에서 정성 서술로 대체)
