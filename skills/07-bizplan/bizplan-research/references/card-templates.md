# card-templates.md — 5종 카드 고정 양식 (v1.1)

bizplan-research가 생성하는 P·R·S·C·U 5종 카드의 상세 양식. 각 카드는 독립된 .md 파일로 저장됩니다.

## 공통 헤더

```markdown
# BR_{카드종류}-카드_{사업명}_{YYMMDD}

> 사업 아이템: {한 줄 정의}
> 타깃 고객: {연령·직군·상황}
> 업종: {IT서비스·제조·소상공인·기술기반}
> 작성일: YYYY-MM-DD
> 리서치 출처: web_search / web_fetch
> 주요 출처 등급: A / B / C
```

## 출처 등급 규칙

| 등급 | 출처 종류 | 예시 | 허용 기준 |
|------|-----------|------|-----------|
| A | 정부·공공기관 통계 | 통계청·KOSIS·중기부·KDI·산업연구원 | 핵심 수치(TAM·고용·정책)에 1건 이상 필수 |
| B | 민간 리서치·협회 자료 | 한국리서치·업종 협회·글로벌 리서치펌 | A가 없을 때 대체 가능 |
| C | 언론 보도·기업 IR | 주요 일간지·업계지·IR 자료 | 보조 근거. 단독 사용 금지 |

각 수치에는 `(출처: 기관명·연도, 등급: A/B/C)` 형식으로 등급을 병기합니다.

## U-카드 (User Input Required) — v1.1 신규

사용자만 알고 있는 정보로, 리서치 대상이 아니지만 bizplan-kstartup 입력에 필수인 항목을 선제 수집합니다. Step 1에서 체크리스트로 제시하고, Step 2 리서치와 병렬로 사용자 입력을 받습니다.

```markdown
## 1. 대표자 정보

- [ ] 대표자 성명·연령·직군
- [ ] 관련 분야 주요 이력 3건 (최근 순)
- [ ] 학력·자격·수상 이력 (해당 시)
- [ ] 창업 동기 (개인 서사 한 문단)

## 2. 팀 구성

| 이름 | 역할 | 핵심 역량 | 합류 시기 | 고용 형태 |
|------|------|-----------|-----------|-----------|
| {이름 1} | {역할} | {역량} | {월} | 정규/파트 |
| {이름 2} | (동일 구조) |
| {이름 3} | (동일 구조) |

## 3. 보유 자산

- [ ] 특허·상표 출원·등록 (번호·상태)
- [ ] MVP·프로토타입 존재 여부 + 테스트 결과
- [ ] 개발 단계 (기획 / 개발 중 / 베타 / 정식 출시)
- [ ] 기존 사용자·매출 (있으면 수치)

## 4. 외부 네트워크

- [ ] 자문·멘토 명단 (소속·관계)
- [ ] 협력 예정 기업·기관
- [ ] 기 보유 계약·MOU

## 5. 사업 선호

- [ ] 1순위 희망 정부지원 사업
- [ ] 희망 창업 유형 (예비/초기/재도전)
- [ ] 희망 사업 기간 (개월)
- [ ] 사업 추진 일정 제약 조건 (졸업·퇴사 등)

## 6. 리스크 인식

- [ ] 본인이 생각하는 최대 위험 요소 2가지
- [ ] 이미 검증된 강점 2가지

## 참고 자료
- 사용자 입력 전용 카드 — 외부 리서치 출처 없음
```
