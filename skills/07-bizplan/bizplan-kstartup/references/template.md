# template.md — PSST 12개 소항목 서술 프레임

K-Startup 표준양식 본문 12개 소항목(1-1 ~ 4-3)에 대한 고정 서술 프레임. 각 프레임은 슬롯({ }) 구조로 구성되어 사용자 입력값을 채워 완성한다.

분량 기준: 각 소항목 본문 300~500자. 표·그림은 분량 산정에서 제외.

---

## 1. 문제인식 (Problem)

### 1-1. 창업 아이템 개발 동기·목적

```
[배경 서사]
{개인 경험 또는 관찰 1~2문장}. 그 과정에서 {문제 인식 1문장}.

[문제 정의]
{타깃 고객}은 {상황·조건}에서 {구체적 불편·손실}을 겪고 있음.
{수치 또는 사례 1건}.

[개발 목적]
{서비스명}은 {핵심 해결 방식}으로 {기대 성과}를 달성하고자 함.

[요약표] → T-02 목표고객 세분화 삽입
```

### 1-2. 외부 환경 (정책·기술·사회)

```
[정책 환경]
{관련 정책·법제도 명칭} ({발표 시기})에 따라 {변화 방향}이 진행되고 있음.

[기술 환경]
{관련 기술 트렌드}가 확산되면서 {기회 요인}이 형성됨.

[사회 환경]
{인구·생활·문화 변화}로 {수요 증가 근거}가 나타남.

[종합]
위 환경 변화는 {서비스명}의 {차별적 포지션}에 {유리/불리} 요인으로 작용함.
```

### 1-3. 목표시장(고객) 현황 및 문제점

```
[목표 고객 정의]
주 타깃: {연령·성별·직업·생활 패턴}.
보조 타깃: {파생 고객군 1개}.

[시장 규모]
→ T-03 TAM/SAM/SOM 표 삽입

[문제 심각도]
{구체 사례 1개 + 수치}. {기존 대안의 한계}.

[기회 포인트]
{해결되지 않은 지점}이 {서비스명}의 진입 기회임.
```

## 프레임 활용 규칙

1. 사용자 입력이 들어오면 슬롯({ })을 채운다
2. 슬롯을 채우지 못하면 업종별 프리셋(`sample-*.md`)에서 대체 예시를 가져온다
3. 표 자리(`→ T-NN`)는 `tables.md`의 표 양식을 호출한다
4. 서술체는 **~함·~임** 종결어미로 고정한다
5. 금지어(혁신적인·획기적인·완벽한·매우·쉽게·빠르게) 사용 금지
