# bizplan-kstartup — K-Startup 표준양식 사업계획서 작성 스킬

## 스킬 목적

예비·초기 창업자(1인 사업자·소기업 포함)가 정부지원사업(K-Startup 포털 공고 사업)에 제출하는 사업계획서 본문 문서를 생성한다. 표준양식의 PSST(Problem-Solution-Scale-up-Team) 구조를 그대로 따라 심사 기준에 정합된 문서를 작성한다.

본 스킬은 **본문 문서(.docx 기본, .hwpx 변환 옵션)** 전용이다. 발표자료(.pptx)는 `bizplan-kstartup-pitch` 스킬을 사용한다.

## 참조 파일

- `references/template.md` — K-Startup 표준양식 PSST 구조 템플릿
- 폰트·색상·여백·표 스타일은 이 문서의 "폰트·스타일 체계" 절을 따른다
- 심사 평가 체크리스트는 Step 6에서 PSST 4개 영역(문제인식·실현가능성·성장전략·팀구성)별로 `references/template.md`의 프레임 충족 여부를 점검한다

## 전체 흐름

```
Step 1. 일반현황 정리 (표지 + 기본정보 표)
   ↓
Step 2. 문제인식 작성 (P: Problem)
   ↓
Step 3. 실현가능성 작성 (S: Solution)
   ↓
Step 4. 성장전략 작성 (S: Scale-up)
   ↓
Step 5. 팀구성 작성 (T: Team)
   ↓
Step 6. 통합점검·최종출력 (.docx + .hwpx)
```

각 Step 완료 시 결과물을 대화창 텍스트로 제공하고, 사용자 확인 후 다음 Step으로 진행한다.

## Step 간 전환 규칙

- Step 1 완료 후 → 일반현황 표 초안을 대화창에 출력 → 사용자 승인 후 Step 2 진입
- Step 2~5 완료 후 → 각 섹션 초안을 대화창에 출력 → 수정 사항 반영 → 다음 Step 진입
- Step 6에서 전체 섹션을 통합하고 평가 체크리스트 검증 후 .docx 생성

## 문서 구조 규칙

### 1. 표지

- 상단: 공고명·접수번호(사용자 입력)
- 중앙: **사업계획서 제목** (28pt Bold)
- 중하단: 신청기업명·대표자명·제출일자
- 하단: 주관기관 로고 자리(선택)

### 2. 목차

- 1쪽 이내 자동 생성
- PSST 대항목 + 중제목까지 표시

### 3. 본문 (PSST 구조)

#### 1. 문제인식 (Problem) — 배경 및 필요성

- 1-1. 창업 아이템 개발 동기·목적
- 1-2. 창업 아이템 실현 가능성에 영향을 미치는 외부 환경
- 1-3. 목표시장(고객) 현황 및 문제점

#### 2. 실현가능성 (Solution) — 실현·현황

- 2-1. 창업 아이템 현황(준비 정도)
- 2-2. 창업 아이템 실현·구체화 방안
- 2-3. 창업 아이템 차별화 방안

#### 3. 성장전략 (Scale-up) — 성장·자금계획

- 3-1. 자금 소요 및 조달 계획
- 3-2. 시장 진입 및 성과 창출 전략
- 3-3. 사업 추진 일정(종합)

#### 4. 팀구성 (Team) — 역량·팀 구성

- 4-1. 대표자 및 팀원 현황·역량
- 4-2. 외부 협력 네트워크·파트너
- 4-3. 중장기 인력 운용 계획

### 4. 첨부

- 증빙서류 목록(사업자등록증·특허증 등) — 목록만 자동, 파일은 사용자 첨부

## 문체·서술 기준

- 종결어미: **~함·~임** 사업계획서 서술체 (공통 합니다체 예외 규정 적용)
- 문장: 간결한 개조식 + 근거 수치 병기
- 금지 표현: 혁신적인·획기적인·완벽한·매우·쉽게·빠르게 (공통 금지어)
- 추상명사 중심 문장 금지 (행동·상태·결과 동사 우선)
- 문단 분량: 각 소항목 본문 300~500자 권장. 초과 시 표·그림으로 분리
- 숫자: 천 단위 콤마, 단위 명시(원·명·%)

## 폰트·스타일 체계 (Noto Sans KR 기반)

모든 텍스트는 **Google Fonts Noto Sans KR** 사용. Weight 3종 운용.

- 표 테두리: `#D1D5DB` (그레이 300)

## Step별 작성 지침

### Step 0. 사전 입력 인식 (자동 실행)

스킬 호출 시 다음 순서로 입력을 자동 탐색합니다.

1. 작업 폴더에서 `bizplan_input_*.json` 파일 검색
2. 파일이 있으면 `bizplan-research` 스킬의 `references/bizplan-input-schema.md` 구조에 따라 검증 (bizplan-research가 설치되어 있으면 그 파일을 읽고, 없으면 항목명만 대조)
3. 검증 통과 → PSST 12개 소항목 슬롯에 자동 매핑 후 Step 1 일반현황만 사용자에게 입력받고 Step 2부터 시작
4. 검증 실패 또는 파일 없음 → 일반 모드로 Step 1부터 사용자 입력 진행

사용자에게 다음과 같이 안내합니다.

```
같은 폴더에서 bizplan_input_{사업명}_{YYMMDD}.json 파일을 발견했습니다.
이 데이터로 본문을 시작할까요?

- 예: 5종 카드 데이터를 자동 매핑하고 일반현황만 추가 입력합니다
- 아니오: 처음부터 사용자 입력 모드로 진행합니다
```

JSON이 없는 경우 안내 없이 곧바로 Step 1로 진입합니다.

### Step 1. 일반현황 정리

입력받는 정보:
- 공고명 / 접수번호(선택) / 신청유형(예비·초기·재도전 등)
- 신청기업명 / 대표자 / 설립일(예비창업자는 생략) / 업종 / 주소
- 창업 아이템 한 줄 정의 (30자 이내)
- 핵심 키워드 3~5개

출력: 표지 + 일반현황 표 초안 (대화창 텍스트)

### Step 2. 문제인식 (Problem)

입력받는 정보:
- 창업 동기·배경 (개인 경험·관찰한 문제)
- 목표고객 정의 (연령·직군·상황)
- 목표고객이 겪는 구체적 문제 (수치·사례)
- 시장 규모·성장률 (가능하면 출처 포함)

출력 구성:
- 1-1 개발 동기·목적 (배경 서사 + 문제 정의)
- 1-2 외부 환경 (정책·기술·사회 변화)
- 1-3 목표시장 현황 (TAM/SAM/SOM 표 자동 생성)

### Step 3. 실현가능성 (Solution)

입력받는 정보:
- 현재 준비 수준 (아이디어 / 프로토타입 / 시제품 / 시장출시)
- 핵심 기술·자원·지식재산권
- 경쟁자·대체재 목록
- 차별점 3가지 이상

출력 구성:
- 2-1 현황 (준비 정도 체크리스트 표)
- 2-2 실현·구체화 방안 (단계별 실행 계획)
- 2-3 차별화 방안 (경쟁자 비교표 자동 생성)

### Step 4. 성장전략 (Scale-up)

입력받는 정보:
- 필요 자금 총액·용도별 배분
- 조달 계획 (자부담·정부지원·투자)
- 시장 진입 전략 (MVP → Beta → 정식 출시)
- 매출 목표 (1·2·3년 차)

출력 구성:
- 3-1 자금 소요·조달 계획 (표 2종: 소요 / 조달)
- 3-2 시장 진입·성과 창출 전략
- 3-3 사업 추진 일정 (간트 차트 형식 표)

### Step 5. 팀구성 (Team)

입력받는 정보:
- 대표자 이력·역량·담당 업무
- 팀원 구성 (1인 사업자는 외부 협력자로 대체 가능)
- 외부 파트너·자문·멘토
- 중장기 채용 계획

출력 구성:
- 4-1 대표자·팀원 현황 (역할·경력 표)
- 4-2 외부 협력 네트워크
- 4-3 중장기 인력 운용 계획

### Step 6. 통합점검·최종출력

점검 항목:
- PSST 4개 대항목 누락 없음
- 모든 소항목 본문 300자 이상
- 수치·근거가 최소 1회 이상 포함
- 평가 기준 체크리스트 통과 (PSST 4개 영역별 `references/template.md` 프레임 충족)
- 공통 하네스 (금지어·추상형용사·AI 흔적 0건)

출력물:
1. **.docx 파일** (기본 산출물)
2. **.hwpx 변환 옵션** 안내 (사용자 요청 시 `hwpx` 스킬 호출)
3. 평가 기준 체크리스트 리포트

### Step 7. 다음 단계 안내 (자동 출력)

본문 .docx 생성 완료 후, 사용자에게 다음 메시지를 자동 출력합니다.

```
사업계획서 본문이 완성되었습니다.
산출물: {기업명}_사업계획서_{공고명}_{YYMMDD}.docx

발표용 피치덱(.pptx)을 이어서 만드시려면 다음 트리거를 입력하세요:
"bizplan-kstartup-pitch 스킬로 이어서 진행해줘"

같은 폴더의 본문 .docx를 자동으로 읽어 17장 슬라이드 덱을 생성합니다.

정부 제출용 .hwpx 파일이 필요한 경우:
"이 사업계획서를 한글파일로 변환해줘"
```

## 사용자 입력 부족 대응

각 Step에서 필수 정보가 누락되면:
1. 누락 항목을 구체적으로 질문 (선택지 3개 이내, 한 번에 하나)
2. 유사 사례 프리셋 제시 (예: "1인 IT 서비스 창업자 프리셋으로 채워드릴까요?")
3. 사용자 확인 후 플레이스홀더로 채우고 진행 (후속 편집 가능하도록 `[⚠ 입력 필요: ~~~]` 표기)

## 최종 출력

- 경로: `10 외부 강의/...` 또는 사용자 지정 폴더
- 파일명: `{기업명}_사업계획서_{공고명}_{YYMMDD}.docx`
- 분량: A4 기준 10~15쪽
- 사용자 요청 시 `.hwpx` 변환 파일 추가 제공

## 스킬 체인

```
(사전) bizplan-research (BR_ 카드 4종)
         ↓ 슬롯 매핑
(본문) bizplan-kstartup (docx 본문)
         ↓ 핵심 추출
(발표) bizplan-kstartup-pitch (pptx 피치덱)
         ↓ 변환 (필요 시)
(제출) hwpx (.hwpx 제출용)
```

본 스킬은 파이프라인 2단계에 해당한다. 이전 단계(`bizplan-research`)의 4종 카드(P·R·S·C) 입력값을 자동 매핑해 12개 소항목 슬롯을 채운다. 사전 리서치 없이 본 스킬만 단독 호출도 가능하다.
