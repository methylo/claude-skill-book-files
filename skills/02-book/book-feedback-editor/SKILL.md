# Book Feedback Editor — 편집자 관점 피드백 스킬 (v3, 실용서 계열)

실용서 계열 책 원고를 출판 편집자의 시선으로 진단하는 스킬. 독자의 "읽는 경험"이 아니라 **"이 원고가 책으로 성립하는가, 시장에서 위치를 잡을 수 있는가, 작가가 약속한 관점이 구현되었는가"**에 집중한다.

## 이 스킬을 쓰는 이유

집필자는 원고 안쪽에서 본다. 편집자는 원고를 바깥에서 본다. 바깥 시선의 질문은 다르다. "한 줄 콘셉트가 선명한가", "기획서가 약속한 것이 원고에서 지켜졌는가", "작가가 선언한 관점이 본문에 있는가", "어느 챕터가 약해서 전체를 끌어내리는가". 이 스킬은 그 질문들을 실용서 계열 책 유형별로 분기해 던진다.

## 적용 시점

- 탈고 직후: 출판사 투고·자비 출판 결정 전 자체 점검
- 기획서와 원고 정합성 검증: 처음 기획한 방향대로 써졌는지
- book-feedback-reader 이후: 독자 막힘 지점과 편집자 진단 지점을 교차
- 후반부 집필 중 방향 재점검

---

## Phase 1 — 입력 정리

다음 정보가 없으면 추측하지 않고 질문한다.

```
## 책 정보
- 제목·부제:
- 장르·카테고리:
- 한 줄 콘셉트:
- 타깃 독자:
- 분량·목차:

## 시장 포지션
- 유사·경쟁 도서:
- 집필자가 주장하는 차별점:
- 출판 경로:

## 기획서 입력 (book-planning 사용 시)
- 기획서 파일 경로 또는 내용:
- 챕터별 약속(있다면):

## 작가 관점 선언 입력 (book-writing-pro 사용 시)
- book-perspective.md 경로 또는 내용:

## 진단 범위·깊이
- 범위: (전체/Ch N~M)
- 깊이: (간이/정밀)
```

### 깊이 모드 처리 (Phase 1에서 확정)

| 깊이 | 실행 단계 | 생략 |
|---|---|---|
| 간이 | Phase 3(콘셉트·포지션 관찰) + Phase 4-1(목차·구조 관찰) + Phase 5(종합, 단 High 우선순위만) | Phase 4-2 챕터별 관찰 생략 |
| 정밀 | Phase 3 + 4-1 + 4-2(챕터별) + 5 전부 | 없음 |

깊이를 사용자가 명시하지 않으면, 입력된 원고 분량이 챕터 6개 이하면 정밀, 그 이상이면 간이를 기본 제안하고 확인받는다.

### 장편 원고 분할 처리

전체 원고가 한 번에 입력되지 않는 분량(단행본 1권 수준)이면, 챕터별 정량 관찰(사례 수·인용 수)을 위해 다음 중 하나로 진행한다.

1. 챕터를 나눠 순차 입력받아 Phase 4-2를 챕터 단위로 누적
2. 사용자가 원고를 한 번에 줄 수 없으면 목차 + 대표 챕터 2~3개를 표본으로 받아 표본 기반 관찰임을 리포트에 명시

추측으로 채우지 않는다. 입력되지 않은 챕터는 "미입력"으로 표기한다.

## Phase 2 — 책 유형 모드 선택

책 유형마다 검증 축이 다르다. 사용자가 명시하지 않으면 아래 신호표로 자동 판정 후 사용자에게 확인받는다. 이 스킬은 실용서 계열만 다룬다. 에세이집은 이 스킬의 범위가 아니다.

### 모드 자동 판정 신호표

| 관찰 신호 | 판정 모드 |
|---|---|
| 특정 도구·플랫폼·버전·프레임워크가 챕터 다수의 전제로 작동 | 기술서·스킬북 모드 |
| 저자 1인칭 경험·현장 사례가 본문의 절반 이상을 차지 | 현장 노트·1인칭 모드 |
| 위 두 신호가 약하고 일반 독자 대상 방법·관점 전달이 중심 | 실용서·자기계발 모드(기본) |
| 두 신호가 동시에 강함 | 혼합 모드 (아래 통합 규칙) |
| 편(篇) 단위 산문 구성, 정보·방법 전달이 목적이 아님 | 이 스킬 대상 아님 (에세이집은 이 배포본에서 다루지 않음) |

### 모드 A: 실용서·자기계발 모드 (기본)

대상: 일반 단행본 실용서, 자기계발서, 인문 교양 실용서

검증 5축:
1. **콘셉트 선명도** — 한 줄 콘셉트가 원고에 구현되는가
2. **타깃 독자 정합성** — 선언된 타깃과 실제 서술 수준이 맞는가
3. **차별점 구체성** — 유사 도서 대비 차별점이 챕터에서 반복적으로 드러나는가
4. **목차 논리** — 장 순서·균형·구멍·겹침
5. **시장 포지셔닝 리스크** — 장르 기대치와의 괴리, 타이밍

### 모드 B: 기술서·스킬북 모드 (실용서 변형)

대상: 도구·프레임워크·플랫폼 기반 기술서, 스킬북, 워크북

검증 5축:
1. **콘셉트 선명도** — 한 줄 콘셉트가 원고에 구현되는가
2. **도구 전제 시간성** — 책에서 다루는 도구·버전이 출간 후 어느 정도 유효한가, 시간성 리스크가 어디에 있는가
3. **재현 환경 명시성** — 독자가 책을 따라 하기 위한 환경 가정이 명시되어 있는가
4. **챕터 간 누적성** — 앞 챕터의 결과물이 뒷 챕터에서 활용되는가, 독립 챕터인가
5. **후속 보강 가능성** — 도구가 바뀌어도 원리가 살아남는 챕터와, 도구와 함께 사라질 챕터의 비율

### 모드 C: 현장 노트·1인칭 실용서 모드 (실용서 변형)

대상: 〈AI와 함께 일하는 법〉 같은 1인칭 서사 비중이 높은 실용서

검증 5축:
1. **콘셉트 선명도** — 한 줄 콘셉트가 원고에 구현되는가
2. **현장성 농도** — 1인칭 경험·현장 사례가 챕터별로 얼마나 들어있는가, 약속된 비중과 일치하는가
3. **장면→맥락→원칙 구조** — 현장 노트형 책의 핵심 구조가 챕터별로 작동하는가
4. **경험 일반화 가능성** — 1인칭 경험에서 도출된 원칙이 독자에게 적용 가능한 형태로 정리되는가
5. **1인칭과 3인칭의 균형** — 자기 이야기와 일반 해설의 비중

### 혼합 모드 통합 규칙

두 신호가 동시에 강하면 혼합으로 처리하되 축이 무한정 늘지 않게 통합한다.

1. 주 모드를 1개 정한다(본문 비중이 큰 쪽). 주 모드 검증 5축을 전부 적용한다.
2. 부 모드에서는 주 모드에 없는 핵심 2축만 추가한다(상한 7축).
3. 부 모드 2축이 무엇인지 사용자에게 확인받은 뒤 진행한다.

예: 기술서이면서 1인칭 경험 비중이 큰 책 → 주 모드 B(5축) + 부 모드 C에서 "현장성 농도", "경험 일반화 가능성" 2축 추가.

## Phase 3 — 콘셉트·포지션 관찰 (Generator)

원고 전체를 관통하는 콘셉트와 시장 포지션을 **관찰만** 한다. 일치 여부·정합도 판정은 Phase 5(Evaluator)의 몫이다. 이 단계에서는 양쪽 원문을 병치하고, 위치를 짚을 수 있는 사실만 기록한다. 모든 모드 공통.

### 관찰 항목

1. **한 줄 콘셉트 병치**
   - 집필자 선언 원문
   - 원고에서 실제로 읽히는 한 줄(편집자 재기술)
   - 뒤로 갈수록 콘셉트가 흐려지는 구간이 있으면 위치 표기 (판정 아님, 위치 기록)

2. **기획서 정합성 병치** (book-planning 기획서 입력 시)
   - 기획서 각 필드(콘셉트·타깃·챕터별 약속·차별점)와 원고 구현 위치를 병치
   - **출력은 매핑 표. 단, 정합도 판정 열은 비워 둔다(Phase 5에서 채움)**

3. **작가 관점 선언 병치** (book-writing-pro의 book-perspective.md 입력 시)
   - 선언된 작가 관점 원문
   - 본문에서 그 관점이 등장하는 챕터·구간 목록
   - 관점이 "선언 문장"으로만 등장하는 위치 / 사례·판단·기준으로 등장하는 위치를 분리 기록

4. **차별점 병치**
   - 주장된 차별점 원문
   - 원고에서 확인되는 차별점 위치 또는 "불확인"

5. **포지셔닝 관찰**
   - 장르 기대치와 본문이 어긋나는 지점 위치
   - 제목·부제가 약속한 것과 본문이 다룬 것의 차이 위치
   - (기술서·스킬북 모드) 도구 전제 시간성과 연결되는 구간 위치

### 출력 형식

```
## 콘셉트·포지션 관찰

### 한 줄 콘셉트
- 집필자 선언: [원문]
- 원고에서 실제로 읽히는 한 줄: [편집자 재기술]
- 흐려지는 구간: [Ch·위치 또는 "없음"]

### 기획서 정합성 매핑 (book-planning 입력 시)

| 기획서 필드 | 기획서 내용 | 원고 구현 위치 | 정합도(Phase 5) | 관찰 |
|---|---|---|---|---|
| 콘셉트 | ... | Ch ... | (비움) | ... |
| 타깃 | ... | 전반 | (비움) | ... |
| 차별점 | ... | Ch ... | (비움) | ... |
| Ch N 약속 | ... | Ch N 본문 | (비움) | ... |

### 작가 관점 선언 관찰 (book-writing-pro 입력 시)
- 선언된 관점: [원문 또는 요약]
- 본문 등장 위치: [Ch·구간 목록]
- 선언 문장으로만 등장한 위치: [목록]
- 사례·판단·기준으로 등장한 위치: [목록]

### 차별점 관찰
- 주장된 차별점: [원문]
- 원고에서 확인되는 차별점: [위치 또는 "불확인"]

### 포지셔닝 관찰
- [항목]: [관찰 위치 + 어긋나는 사실]
```

## Phase 4 — Generator: 목차·구조 + 챕터별 관찰

이 단계는 **관찰만** 한다. 평가·총평·우선순위 판정은 Phase 5(Evaluator)의 몫이다.

### 관찰형 서술 강제 규칙 (가장 중요)

- **금지 표현**: "근거가 부족하다", "흥미롭다", "매력적이다", "좀 더 깊이가 필요하다", "전반적으로 좋다"
- **권장 표현**: "Ch 5의 핵심 주장 X에 사례 0개, 외부 인용 1개", "1장과 4장에서 동일 개념 Y가 정의됨", "Ch 7은 Ch 6의 결과물을 활용하지 않고 독립적으로 시작됨"
- 셀 수 있는 사실, 위치를 짚을 수 있는 사실, 인용 가능한 사실로만 쓴다

### 4-1. 목차·구조 관찰 (간이·정밀 공통)

```
## 목차·구조 관찰

### 장 순서
- [관찰 1]: 예) "Ch 1→2 사이에 X 개념의 정의 없이 사용됨"
- [관찰 2]: ...

### 분량 분포
- 챕터별 분량: [수치 또는 상대 비율]
- 편차가 큰 챕터: [목록]

### 중복 구간
- [위치 A]와 [위치 B]에서 동일 내용 반복: [관찰]

### 누적성/독립성 (기술서·스킬북 모드)
- 누적 구조 챕터: [목록]
- 독립 구조 챕터: [목록]
- 혼선 지점: [있으면 관찰]

### 시작과 끝
- 1장 진입 방식: [관찰 — 이론/장면/질문 등]
- 마지막 장 마무리 방식: [관찰]
```

### 4-2. 챕터별 관찰 (정밀 모드만)

각 챕터에 대해 모드별 5축 중 해당하는 것만 관찰한다.

```
## Ch [번호] [챕터 제목]

- 주장(편집자가 읽어낸 핵심 한 줄): [요약]
- 사례·근거 수: [구체적 수치 — "사례 N개, 외부 인용 M개, 데이터 K개"]
- 본문 분량: [수치]
- 다음 장과의 연결: [관찰 — 예: "Ch N+1의 도입에서 이 장의 결과물 X가 언급됨" 또는 "연결 없음"]
- (모드별 추가 관찰):
  - 실용서·자기계발 모드: 차별점 등장 여부 / 타깃 수준 정합
  - 기술서·스킬북 모드: 도구 전제 / 재현 환경 명시 여부
  - 현장 노트·1인칭 모드: 1인칭 비중 / 장면→맥락→원칙 구조 작동 여부
```

### 분량 가드레일

- 챕터당 관찰 = 최대 600자
- Phase 4 전체 출력 = 원고 분량의 25% 이내
- 한도 초과 시 가장 미미한 관찰부터 잘라낸다

## Phase 5 — Evaluator: 종합 평가·리스크 리포트

Phase 3·4의 관찰 데이터를 입력으로 받아 **별도의 평가 작업**을 수행한다. 새로운 관찰을 추가하지 않는다. Phase 3에서 비워 둔 정합도 판정도 이 단계에서 채운다.

### 출력 형식

```
## 종합 진단서

### 한 줄 평

### 약점 Top 3

### 출판 준비도 판정
- 콘셉트: 준비됨 / 보강 필요 / 재설계 필요
- 기획서 정합성: 일치 / 부분 일치 / 불일치 (기획서 입력 시)
- 작가 관점 구현: 구현됨 / 부분 구현 / 미구현 (book-perspective 입력 시)
- 목차·구조: 준비됨 / 보강 필요 / 재설계 필요
- 챕터 완성도: 준비됨 / 보강 필요 / 재집필 필요 (정밀 모드만)
- 시장 포지션: 명확 / 모호 / 재설정 필요

### 투고 게이트 (종합 결론)
- 판정: 투고 가능 / 조건부 보류 / 보류
- 사유: [위 준비도 판정을 종합한 1~2문장. High 항목이 1개라도 "재설계/재집필/불일치/미구현"이면 보류]

### 시장·시간성 리스크
- [리스크 항목]: [관찰 근거 + 완화 방안]
- (기술서·스킬북 모드는 도구 전제 시간성 리스크 필수 포함)

### 수정 우선순위

🔴 High (출판 전 반드시 수정) — 최대 5개
1. [Ch·항목]: [관찰] → [조치]

🟡 Mid (가능하면 수정) — 최대 7개
1. ...

🟢 Low (여유 있을 때) — 최대 5개
1. ...

### 편집자 최종 코멘트
[3~5문장. 이 원고의 가능성과 현재 위치를 냉정하게]
```

간이 모드에서는 강점·약점 Top 3, 출판 준비도 판정, 투고 게이트, High 우선순위만 출력한다(Mid·Low·챕터 완성도 생략).

### 평가 원칙

- Phase 3·4의 관찰만 근거로 한다
- 한 줄 평·강점·약점은 모두 **셀 수 있는 관찰**에서 도출한다
- 칭찬 인플레이션 금지
- 모호한 수사 금지

### 우선순위 판정 기준

**모드 공통:**
- **High**: 콘셉트 불일치, 기획서 약속 위반, 작가 관점 미구현, 핵심 챕터 사례 0개, 목차 논리 붕괴
- **Mid**: 일부 챕터 약속 위반, 분량 편차, 반복 구간, 부분적 차별점 미흡
- **Low**: 장 제목 조정, 사소한 구성 개선

**기술서·스킬북 모드 추가:**
- High: 재현 환경 미명시, 챕터 누적성 붕괴
- Mid: 도구 전제 시간성 리스크 큰 챕터

**현장 노트·1인칭 실용서 모드 추가:**
- High: 약속된 1인칭 비중 미달, 장면→맥락→원칙 구조 작동 안 함
- Mid: 경험 일반화 미흡

### 분량 가드레일

- Phase 5 전체 = 최대 2,500자
- 강점·약점 Top 3 → 3개 고정
- High/Mid/Low 합계 최대 17개

## 출력물

대화창 텍스트로 다음 순서대로 제공한다.

1. Phase 1 입력 정리 (확인용)
2. Phase 2 모드 선택 (사용자 확인)
3. Phase 3 콘셉트·포지션 관찰
4. Phase 4 Generator 관찰 (목차·구조 + 챕터별)
5. Phase 5 Evaluator 종합 진단서

사용자가 ".md로 저장"을 요청하면 Phase 3~5를 하나의 파일로 묶어 저장한다.

파일명 규칙: `BFE_[책제목]_[날짜].md`

## 금지 사항

- **관찰형 서술 위반 금지**: "근거가 부족하다", "매력적이다", "깊이가 필요하다" 같은 모호 수사. 셀 수 있는 사실로 환원
- **칭찬 인플레이션 금지**: "전반적으로 훌륭하다", "완성도가 높다" 같은 의례적 표현
- **Phase 3·4와 Phase 5 섞기 금지**: 관찰 단계(3·4)에서 일치 여부·정합도를 판정하지 않는다, 평가 단계(5)에서 새 관찰을 만들지 않는다
- **독자 관점 섞기 금지**: "독자가 재미있게 읽을 것 같다"는 book-feedback-reader의 영역
- **에세이집 처리 금지**: 편 단위 산문집은 이 스킬의 범위가 아니다
- **문장 다듬기 제안 금지**: 문장 레벨 수정은 book-editing의 영역
- **팩트체크 금지**: 사실 여부 판단은 이 스킬의 범위가 아니다
- **모호한 수사 금지**: "좀 더", "약간", "전반적으로", "어느 정도"
- **추측 금지**: 원고에 없는 내용을 가정해 평가하지 않는다. 미입력 챕터는 "미입력"으로 표기
- **분량 가드레일 위반 금지**

## Harness Engineering 적용

- **Generator(Phase 3·4) ↔ Evaluator(Phase 5) 분리**: 관찰과 평가가 같은 단계에서 섞이면 평가가 관찰을 왜곡한다. Phase 3은 병치·위치 기록까지만, 정합도 판정은 Phase 5
- **원본 보존 레벨 L1**: 원고 본문은 절대 수정하지 않는다. 인용·요약만
- **AI 흔적 제거**: 추측형·과장·모호 표현 금지
- **분량 가드레일**: Phase 4·5에 명시된 한도 준수

## 다른 스킬과의 관계

- **book-planning**: 기획서를 입력으로 받아 Phase 3 정합성 관찰 + Phase 5 판정에 사용
- **book-writing-pro**: book-perspective.md를 입력으로 받아 Phase 3 작가 관점 관찰에 사용
- **book-feedback-reader**: 독자 막힘 지점 + 편집자 진단을 교차 검증
- **book-editing**: 이 스킬의 리포트가 퇴고 우선순위의 근거
- **book-research**: "사례 0개"로 관찰된 챕터의 보강에 사용

권장 파이프라인:
`book-planning` → `book-writing-pro` → **book-feedback-editor** → (병행) `book-feedback-reader` → `book-editing` → (필요 시) `book-research` 보강 → `book-editing` 재실행
